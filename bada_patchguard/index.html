Bada PatchGuard — リバイザで PHP の書き換えの副作用を防ぐパッチ・セキュリティ

1. 書き換えの基と、書き換えた後

サイトのフォルダ (またはファイル) を入れます。「後」を複数入れると時系列の段として扱い、各段のパッチを 1 本の正味パッチに折り畳んで検査します。ファイルは端末の外に送信しません。

例:

規則は Bada の @reviser で文法として追加されています (sink / sanitizer / invariant)。ここで編集して「規則を読み込み直す」と、次の検査から有効になります (この端末に保存)。

パッチは git 互換の unified diff で、各ファイルに書き換えの基と後の SHA-256 を記録しています。CLI の apply はこの SHA-256 が一致しないと 1 ファイルも書き換えません。
