# 🧠 Bada 位相 — 思考中枢の量子回路 (位相幾何学の作り換え)

**これまでのレポートで、大域的多様体・コホモロジー・Jones 多項式と結びつけて書いてきた「思考中枢」を、数学のトポロジー(位相幾何学)の定義そのものとして、量子プログラミング言語 Bada の上に量子回路で実装したアプリケーション。**

思考中枢は**単体的複体**、思考は**鎖**(単体ひとつ = 量子ビットひとつ)、境界作用素 ∂ は **CNOT 回路**、そして**観念**とは

```
観念 = H_k = ker ∂_k / im ∂_{k+1}        (レポートの  ker / im f = ∂  をそのまま実装する)
```

── **閉じているのに、どこからも導かれない思考**である。依存ゼロ・単一 HTML・オフライン動作。

## ⚡ 境界回路と閉路フィルタ

∂ は Z<sub>2</sub> 上の線形写像なので CNOT だけで組める。k-単体 σ の量子ビットを制御、その各面 τ ⊂ σ の量子ビットを標的とする CNOT を並べれば ∂̂ である。k-単体レジスタに H<sup>⊗n</sup> を掛けて**すべての思考を同時に**載せ、∂̂ を通し、面レジスタを観測する:

```
Pr[面レジスタ = 0] = |Z_k| / 2^{n_k} = 2^{dim Z_k − n_k}     ⟹     dim Z_k = n_k + log₂ Pr
```

**閉路空間の次元が観測確率から読める。** 処理系は同じ量を古典的なガウス消去でも計算し、両者の一致を全模型・全次数で検査する。観測後の状態は閉路の一様な重ね合わせで、そこから観測した思考は「境界」か「観念」かに分類される。

思考中枢の模型(頂点 6・連想 7・理解 1)では 13 量子ビット、Pr = 1/32、dim Z₁ = 2、観念は 感覚→意味→判断→発話→行動→感覚 の環ひとつ(β₁ = 1)。

## 🌊 ホッジ分解と量子歩行 ── 観念は動かない

レポートの `e_n = ker f ⊕ im f` は、実係数では**ホッジ分解**として厳密になる:

```
C_k = im ∂_{k+1} ⊕ ker Δ_k ⊕ im ∂_kᵀ ,   Δ_k = ∂_kᵀ∂_k + ∂_{k+1}∂_{k+1}ᵀ ,   ker Δ_k ≅ H_k
```

思考中枢の動力学を Δ<sub>k</sub> をハミルトニアンとする量子歩行 ψ(t) = exp(−iΔ<sub>k</sub>t) ψ(0) とする。固有展開の各項は e<sup>−iλt</sup> = cos λt − i sin λt(オイラーの式)で回るが、λ = 0 の**調和成分 = 観念**は位相も振幅も動かない:

```
‖P_H ψ(t)‖² = ‖P_H ψ(0)‖²      (すべての t で不変 — テストで検査)
```

## 🧮 二つのオイラー

回路の位相ゲートは e<sup>iθ</sup>(オイラーの式)、複体の不変量は χ(オイラー標数)。オイラー・ポアンカレの公式 χ = Σ(−1)<sup>k</sup> n<sub>k</sub> = Σ(−1)<sup>k</sup> β<sub>k</sub> により、**単体を数えるだけで観念の総和が分かる**。全模型で両辺の一致を検査する。

## 🧩 理解と分裂

- **理解** `fill a b c` / `理解 a b c` ── 解けていない問い(環)に面を張る。環は境界になり β₁ が 1 減る。
- **分裂** `cut a b` / `切断 a b` ── 連想を切る。中枢が分かれれば β₀ が増え、環が切れれば β₁ が減る(問いは解けたのではなく、問えなくなった)。

> **語の定義。** ここでの「思考中枢」「観念」「理解」は、単体的複体・ホモロジー類・面の添加という数学的対象に付けた名前であり、神経科学上の主張ではない。本処理系が保証するのは定理(∂∂ = 0、オイラー・ポアンカレ、ホッジ分解、観念の保存)がコードの上で成り立つことである。QuantOS は Kauffman ブラケット ⟨K⟩ = (−A³)<sup>w</sup> で端末機能を写像したが、本処理系はその上位にあたる**ホモロジー**を回路にする。

## 📝 位相 Bada 方言の文法

```bada

edge 感覚 意味 · face 意味 記憶 判断   # 連想 (辺) / 理解 (面)。閉包は自動

think 感覚-意味 意味-判断 …    # 思考 = 鎖。∂ と分類 (開いた鎖 / 境界 / 観念)
```

## 🧪 テスト

```sh
node bada_topos/tools/engine-test.js
```

13 節・280 の検査。とくに以下の**定理と不変量**を全模型で毎回確かめる:

- **∂∂ = 0** ── 向き付き実係数と Z₂ の両方
- **オイラー・ポアンカレ** ── χ(単体数) = χ(ベッチ数)
- **境界回路** ── |c⟩|0⟩ ↦ |c⟩|∂c⟩ を無作為な鎖で古典の ∂ と照合
- **閉路フィルタ** ── Pr[面 = 0] = 2^{dim Z − n_k}、量子で読んだ dim Z と古典階数の一致、観測結果はすべて閉路
- **ホッジの定理** ── dim ker Δ_k = β_k、三成分の直交性と再構成、Δ(調和成分) = 0
- **観念の保存** ── 量子歩行のユニタリ性と ‖P_H ψ(t)‖² の不変性。始点が固有ベクトルなら位相だけが回ることも検査
- **理解と分裂** ── 面を張ると β₁ が減り、連想を切ると β₀ が増える
- **限界** ── 量子ビット上限 (18) を超える回路は明示的な誤りとして返り、古典の不変量は動き続ける
