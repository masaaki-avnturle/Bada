📖 原理と使い方

1. 何をするアプリか

ゴーグル型コンピュータの HUD 風画面で実写映像を再生し、 Web カメラに写った手の動きだけで時間軸を操作します。 マウス・キーボード・タッチにも同じエンジンが割り当てられているので、カメラが無い環境でも同じ操作感で使えます。

2. ジェスチャ仕様

  • かき分け (シャトル) — 画面中央が中立。手を左右へずらすと、変位に応じた速度で 巻き戻し / 早送り。速度は r = ±R·((|dx|−dz)/(span−dz))^γ で、 編集卓のデテント ×0.25 / 0.5 / 1 / 2 / 4 / 8 / 16 に吸着します。
  • 高さ = 精度 — 手を上げるほど最大速度に近づき、下げるほど微速。 scale(y) = lo + (hi−lo)·(1−y)。コマ単位の追い込みは手を下げて行います。
  • フリック (跳躍) — 素早く払うと窓内ピーク速度に応じて clamp(k·v^1.3, 2s, 120s) 秒だけ一気に飛びます。
  • ホールド — 手を握る (ブロブ充填率が上がる) と即停止。手が画面外に出た場合も安全側で停止します。

3. ハンド認識パイプライン (すべて端末内)

  • 肌色抽出 — RGB を YCbCr に変換し 77 ≤ Cb ≤ 133、133 ≤ Cr ≤ 177、 かつ彩度のある画素のみ採用 (無彩色の壁・紙を除外)。
  • 動きエネルギー — 直前フレームとの差分が閾値未満の肌色は背景とみなし棄却。
  • 連結成分ラベリング — 4 近傍フラッドフィルで領域を数え、最大面積のブロブを手とする。 面積 → 距離代理、外接矩形に対する充填率 → 握り / 開き判定。
  • One Euro Filter — 速度適応カットオフ fc = fc_min + β·|ẋ| により、 静止時のふるえを消しつつ素早い払いには遅れない。

4. 再生系

  • ×1〜×4 の順再生はブラウザ内蔵の playbackRate、 それを超える早送りとすべての巻き戻しは currentTime += r·Δt の手動シークで駆動します (HTML5 の playbackRate は負値を取れないため)。
  • 下部のフィルムストリップは、スクラブ中に通過したフレームを実際に焼き付けていきます。 手を近づけるとフィルムが左右にかき分けられ、その隙間に現在位置の拡大コマが現れます。

5. プライバシー

カメラ映像・映像ファイルはいずれも端末のメモリ内でのみ処理され、ネットワーク送信・保存は行いません。 アプリは外部 CDN も参照しない単一 HTML です (完全オフライン動作)。
