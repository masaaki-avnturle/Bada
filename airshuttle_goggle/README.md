# 🥽 エアシャトル・ゴーグル — AirShuttle Goggle

**ゴーグル型コンピュータの HUD に映した「実写映像」を、空中で手を “かき分ける” だけで巻き戻し・早送りするスクラブ卓。**
単一 HTML・依存ゼロ・完全オフライン。Android APK / Windows 10・11 EXE / Linux AppImage・deb を GitHub Actions がビルドします。

> ゴーグル型端末を着けたエンジニアが、ホログラムの映像を手で掻き分けて時間軸を操る——
> というアニメ的な演出に着想を得た**独自実装**です。特定の作品・登場人物・権利者とは一切関係がなく、
> 作品の素材も一切含みません。再生されるのは利用者自身が選んだ映像ファイルです。

## できること

| 操作 | ジェスチャ | 効果 |
|:---|:---|:---|
| **シャトル (かき分け)** | 手を中央から左右へずらす | 変位に応じて巻き戻し / 早送り。`×0.25〜×16` の編集卓デテントに吸着 |
| **精度切替** | 手を上げる / 下げる | 上げるほど高速、下げるほど微速(コマ単位の追い込み) |
| **フリック跳躍** | 素早く払う | ピーク速度に応じて `clamp(k·v^1.3, 2s, 120s)` 秒だけ一気に飛ぶ |
| **ホールド** | 手を握る | 即停止。手を見失った場合も安全側で停止 |
| **フィルムのかき分け** | 手を下部のフィルムに近づける | 通過したコマが焼き付いたフィルムストリップが左右に押し退けられる |

カメラが無い / 許可できない環境でも、**🖱 ポインタモード**(マウス・タッチ)で完全に同じジェスチャ則が使えます
(ドラッグ = 手、Shift = 握り)。キーボード: `Space` 再生/停止、`←→` コマ送り(Shift で 10 秒)、`J/K/L`、`Home/End`。

## 中身のエンジン

| # | エンジン | 内容 |
|:--|:---|:---|
| 1 | **ハンド・セグメンテーション** | RGB → YCbCr (BT.601) に変換し `77 ≤ Cb ≤ 133`、`133 ≤ Cr ≤ 177` の肌色クロマ帯 + 彩度条件で抽出。さらに**直前フレームとの差分**が閾値未満の画素を捨て、背景の肌色の壁・木目を除去 |
| 2 | **連結成分ラベリング** | 4 近傍フラッドフィルで領域を数え、最大面積のブロブを手とする。面積 → 距離代理、外接矩形の**充填率** → 握り / 開き判定 |
| 3 | **One Euro Filter** | 速度適応カットオフ `fc = fc_min + β·|ẋ|`(Casiez et al. 2012)。静止時のふるえを消しつつ、素早い払いには遅れない |
| 4 | **シャトル則** | 不感帯の外で `r = ±R·((|dx|−dz)/(span−dz))^γ`、`scale(y) = lo + (hi−lo)·(1−y)` で高さを掛け、デテントへ吸着 |
| 5 | **スワイプ / フリック検出** | 窓 260ms 内の移動量・ピーク速度・**方向一貫率**の 3 条件。往復する震えは棄却される |
| 6 | **トランスポート状態機械** | `HOLD / SHUTTLE / FLICK / NEUTRAL / LOST` を純関数 `nextTransport()` で決定 |
| 7 | **再生駆動** | `×1〜×4` の順再生は `playbackRate`、それを超える早送りと**すべての巻き戻し**は `currentTime += r·Δt` の手動シーク(HTML5 の `playbackRate` は負値を取れないため) |

## 使い方 (ブラウザ版)

[`index.html`](index.html) を開き **「Download raw file」(⬇)** で保存 → ダブルクリックで起動。
「🎬 実写映像を開く」で手元の動画を選ぶか「🌆 デモ映像」(手続き生成の 150 秒クリップ)を押し、
「📷 ハンド認識 開始」でカメラを許可してください。インストール不要・完全オフラインで動作します。

## ネイティブアプリ (APK / Windows / Linux)

[Releases](https://github.com/masaaki-avnturle/Bada/releases) から:

| プラットフォーム | ファイル |
|:---|:---|
| **Android** (APK) | `airshuttle-goggle-debug.apk` |
| **Windows 10 / 11** | `AirShuttleGoggle-*-x64.exe` (NSIS インストーラ / ポータブル) |
| **Linux** | `AirShuttleGoggle-*-x86_64.AppImage` / `AirShuttleGoggle-*-amd64.deb` |

ビルドは [`airshuttle-app-build.yml`](../.github/workflows/airshuttle-app-build.yml) が実行します:

- `airshuttle-v*` タグを push → 3 プラットフォームをビルドして **GitHub Release に添付**
- Actions の **workflow_dispatch** で手動実行 → Actions アーティファクトとして取得
  (`release_tag` を指定すれば Release にも添付)

Android 版はインカメラ使用のため実行時パーミッション (`CAMERA`) を要求します。
許可しない場合でもポインタ(タッチ)モードで全機能が使えます。

## プライバシー

カメラ映像も映像ファイルも、**端末のメモリ内でのみ**処理されます。ネットワーク送信・保存は一切行わず、
アプリは外部 CDN も参照しません(単一 HTML・完全オフライン)。
