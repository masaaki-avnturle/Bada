# Omega MedSafe

**服薬リスクの「重なり」を指摘する教育用チェッカー**

複数の薬を飲んでいるとき、別々の名前でも**同じ種類の負担**が体に重なっていることが
あります。このツールは薬剤名を薬効クラスに変換し、その重なりだけを指摘します。

## このツールがすること / しないこと

| する | しない |
|:--|:--|
| 薬効クラスへの分類 | **用量・配合比・服用スケジュールの提案** |
| 中枢抑制・降圧・QT延長などの重複指摘 | **「この組み合わせなら安全」という判定** |
| 主治医・薬剤師への相談を促す | **薬剤の製造・合成・配合に関する情報** |

安全な組み合わせや量を決められるのは、あなたの状態（体質・腎肝機能・併存疾患）を
知っている**主治医と薬剤師だけ**です。本ツールは教育目的の参考情報であり、
医療上の助言ではありません。

## 使用例

```bash
omega-medsafe フルニトラゼパム エチゾラム ブロチゾラム アムロジピン カンデサルタン セレネース リスパダール
```

```
■ 重なっているリスク
  🔴 [重大] 中枢神経抑制（眠気・意識レベル低下）
       該当 5 剤: フルニトラゼパム、エチゾラム、ブロチゾラム、セレネース、リスパダール
  🔴 [重大] 血圧低下（ふらつき・失神）
       該当 4 剤: アムロジピン、カンデサルタン、セレネース、リスパダール
  🔴 [重大] 呼吸抑制（呼吸が浅く・遅くなる）
       該当 3 剤: フルニトラゼパム、エチゾラム、ブロチゾラム
  🔴 [重大] QT延長（重篤な不整脈）
       該当 2 剤: セレネース、リスパダール
```

同じ薬効クラスが重なると、作用は**相加的**に強まります。特に中枢神経抑制薬の
重複による呼吸抑制、降圧薬の重複による失神、抗精神病薬の重複によるQT延長は、
重なることで生命に関わりうるため「重大」として表示されます。

ジェネリックのブランド接尾辞（「アメル」「サワイ」「トーワ」など）は薬剤名では
ないため、その旨を説明して一般名での再入力を促します。

## インストール

```bash
cd omega_medsafe_pkg && pip install -e .
```

依存ライブラリはゼロ。Python 3.8+。

## 使い方

```bash
omega-medsafe アムロジピン カンデサルタン    # 引数で指定
omega-medsafe                                # 引数なしで対話入力
```

```python
from omega_medsafe import check, format_report
print(format_report(check(["セレネース", "リスパダール"])))
```
