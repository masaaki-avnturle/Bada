# 🔭 Bada Relativity Lens — 相対論レンズ

**任意の画像処理を特殊相対性理論の光学に適用し、そこで生じる「見た目のズレ」を厳密な逆変換で打ち消すアプリケーション。**

中核の光時計は、原図のスケッチ — **上の鏡のバー**と**交差する 2 本の光線** — をそのまま実装しています。
依存ゼロ・単一 HTML・オフライン動作。画像は端末内だけで処理され、外部へ送信されません。

## 🌌 何をするアプリか

画面は **原画 → 観測像 → 補正像** の 3 面です。

| | 内容 |
|:---|:---|
| **① 原画** | 入力そのもの。静止系での、物体固有の幾何。 |
| **② 観測像** | β で飛ぶ観測者が実際に見る像。光行差で歪み、青方偏移し、前方が明るくなる。 |
| **③ 補正像** | **ズレ防止 ON** — 観測像に厳密な逆写像を当て、ズレを打ち消した像。 |

入力は任意の画像ファイル(端末のギャラリー / カメラ)か、内蔵サンプル
(**原図(光時計)** / 格子 / カラーバー / 星野)です。

## 📐 実装している光学

ブーストは光軸 +z(画面奥)方向。θ は視線(光源を見る向き)と進行方向のなす角で、
静止系の値を θ、観測者が見る見かけの値を θ′ と書きます。

| 量 | 式 |
|:---|:---|
| ローレンツ因子 | γ = 1/√(1−β²) |
| **相対論的光行差** | cos θ′ = (cos θ + β)/(1 + β cos θ)、横成分は 1/D 倍 |
| **相対論的ドップラー** | D = γ(1 + β cos θ) = 1/(γ(1 − β cos θ′))、観測波長 λ′ = λ/D |
| **ビーミング**(サーチライト効果) | I′ = D⁴ I |
| **同時刻の真の向き** | tan θ_now = γ tan θ(進行方向だけがローレンツ収縮) |
| **テレル回転** | Δ = θ_now − θ′(= 見た目のズレ) |
| 見かけの画角 | 原画の画角を光行差で写した値(観測フレームの自動追尾に使用) |

### ズレ防止が「厳密」である理由

光行差は **β → −β がそのまま逆写像**になります:

```
cos θ′ = (cos θ + β)/(1 + β cos θ)  に  β → −β  を代入すると
(cos θ′ − β)/(1 − β cos θ′) = cos θ(1−β²)/(1−β²) = cos θ
```

したがって「観測像を作る写像」と「ズレ防止の写像」は数学的に厳密な逆変換です。
実測でも、**補正前 90.7 px のズレが補正後 5.5×10⁻¹⁴ px** まで落ちます(β=0.6, 画角 100°)。
テストはこれを β = 0.1 / 0.6 / 0.9 / 0.99 で検証しています。

## 🎨 色モードと「戻せないもの」について

RGB 画像が持つ情報は 1 画素あたり 3 数値だけです。**波長シフトは、そこに無い情報を要求します。**
本アプリは 2 つのモデルを用意し、どちらを使っているかと、色がどこまで戻せるかを常に表示します。

| モード | 内容 | 可逆性 |
|:---|:---|:---|
| **可視域ラップ(可逆)**(既定) | 3 本の帯を動かす簡易モデル。帯が等色関数の応答が強い 440–645nm から出ないよう log D を tanh で圧縮 | **常に可逆**(条件数 < 11) |
| **分光(厳密)** | RGB から連続スペクトルを再構成(3 ローブの「1 の分割」= 遠赤外は R、遠紫外は B へ連続的に漸近)し、可視域を走査して等色関数で積分 | 低速では可逆、高速では**原理的に不可** |

分光モードで β ≳ 0.5 になると、可視域に届く光は**丸ごと赤外側から来たもの**になり、
変換行列の階数が落ちます(条件数 → ∞)。これは近似の粗さではなく物理そのもので、
RGB 3 値には存在しない情報を要求しているためです。アプリはこれを

- ズレ計測の「色の可逆性」欄に **完全 / 良好 / 劣化 / 不可** と条件数で表示し、
- 逆変換では**観測色を事前分布に置いた正則化解** `(MᵀM+λI)⁻¹(Mᵀ+λI)` を使います。

素朴な最小二乗 `(MᵀM+λI)⁻¹Mᵀ` は、情報の残っていない方向に 0 を書き込むため
G と B が消えて画面が真っ赤に潰れます(「わからない」を「0」として描いてしまう)。
事前分布を観測色にすると、**復元できる方向だけ直り、復元できない方向は観測されたまま**になります。
どちらのモードでも**幾何のズレ防止は完全に厳密**で、影響を受けるのは色だけです。

> 灰色(等エネルギースペクトル)は偏移しても色が変わりません。これは実装の不備ではなく、
> 平坦なスペクトルの形が波長シフトで不変だからです(テストでも確認しています)。

## ⚙️ そのほかの設計上の判断

- **露出は光軸方向で正規化** — ビーミングを D⁴ のまま掛けると画面全体が白飛びし、割り戻しても戻りません。
  基準 `D(θ=0)` で割ることで、視野内の相対的な明暗差は完全に保ったまま可逆になります。
- **観測画角の自動追尾**(既定 ON)— 光行差は場面を前方へ詰め込むので、同じ画角で撮り続けると
  視野に残るのは **17%** だけになります。観測フレームの画角を見かけの画角に合わせると **97%** が埋まります。
  切ると「同じカメラで撮ったら実際どれだけ溢れるか」がそのまま見えます。
- **α を運ぶ再標本化** — 画枠の外は α=0 として重みから外します。端の画素を clamp して代用すると、
  圏外が「黒い被写体」に化けて次段のワープに混ざり込みます。
- **補正目標は 2 種類** — 「静止系整合」は物体固有の幾何(= 原画)へ厳密に戻します。
  テレル回転はこの目標では扱わないため残り、表にもそう表示されます。
  「同時刻整合」を選ぶとテレル回転まで消え、いま実際にある向きへ揃います
  (そのぶん原画とはローレンツ収縮の分だけ異なります)。

## 🕰 光時計 — 原図のスケッチ

スケッチの**横棒**は上の鏡、**交差する 2 本**は上りと下りの光線です。
鏡の間隔 L は進行方向と直交するので不変。観測者から見ると光は斜辺を走るので:

```
L² + (βγL)² = (γL)²      →      1 チックは γ 倍に伸びる
```

アプリはこの三角形を β に応じて描き(交差点も実際の線分の交わりとして計算)、
検算を数値で並べます。**同じ γ が、上の像のズレ量をそのまま決めています。**
