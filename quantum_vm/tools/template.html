BadaVM Pro

量子プログラミング言語 Bada で書かれたデスクトップ・ハイパーバイザ(教育目的の VMware Workstation Pro 風オマージュ)。ゲスト OS も X サーバーも、すべて Bada 言語です。

① BadaVM Pro ハイパーバイザ

量子 vCPU (8 qubit / Hilbert 次元 256)、tuplespace メモリ、仮想ディスク wd0、 NAT ネットワーク、CD-ROM。マシン記述は .qvmx。スナップショットはイベント台帳の プレフィックスとしてコミットされます。bada/vmpro.bada

② BadaOS 12.0 — NetBSD 風ベース + Ubuntu 風 apt

CD から起動し、sysinst 風インストーラで仮想ディスク wd0 か実ディスク rd0 (RDM パススルー) へインストール。ブートローダ工程では LILO をマスター ブートレコードへ書き込み、GRUB 2 メニューモードでチェイン起動します。 ログイン後は Ubuntu 風コマンドライン: apt install ssh xinetd zsh tcsh bash で Linux 一式 (sshd / xinetd / GNU シェル群) が入り、chsh でシェル切替。 bada/badabsd.bada

③ BadaX Server — Windows 用 X サーバー

ASTEC-X 風の外部 X サーバー (ホスト側アプリ)。VM の中の xclock / xeyes / xterm が NAT 越しに DISPLAY=10.0.2.2:0 へ接続し、Windows 側に表示されます。認証は MIT-MAGIC-COOKIE-1 ならぬ JONES-KNOT-COOKIE-1 (三葉結び目の Jones 多項式鍵) + Bell 対 QKD。bada/badax.bada

ヘルプ — 最短ツアー

1. ▶ 起動 — 初回は CD (ISO) から sysinst が起動します。メニューは表示された キーを 1 文字押すだけ: a(言語) → a(インストール) → a/b(仮想 wd0 か 実ディスク rd0・RDM) → a(GPT) → a(LILO を MBR へ + GRUB メニュー) → a(最終確認)。
2. root パスワードとホスト名を入力 → 任意のキーでディスクから再起動 (LILO→GRUB メニュー経由でブートします)。
3. login: root + 設定したパスワードでログイン。
4. apt update → apt install ssh xinetd zsh tcsh bash で Ubuntu 風に Linux 一式を導入。zsh や bash でシェル切替、 chsh -s /bin/zsh でログインシェル変更、service sshd status / netstat でデーモン確認。
5. xclock & xeyes & xterm & は BadaX Server (ASTEC-X 風ウィンドウ) に表示。qstat で Bell 対の零保存、 xdpyinfo で JONES-KNOT-COOKIE-1 を確認。
6. 📷 スナップショット = イベント台帳のプレフィックス。⤺ 復元 でその時点に巻き戻ります。
