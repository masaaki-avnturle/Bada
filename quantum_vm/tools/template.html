BadaVM Pro

量子プログラミング言語 Bada で書かれたデスクトップ・ハイパーバイザ(教育目的の VMware Workstation Pro 風オマージュ)。ゲスト OS も X サーバーも、すべて Bada 言語です。

① BadaVM Pro ハイパーバイザ

量子 vCPU (8 qubit / Hilbert 次元 256)、tuplespace メモリ、仮想ディスク wd0、 NAT ネットワーク、CD-ROM。マシン記述は .qvmx。スナップショットはイベント台帳の プレフィックスとしてコミットされます。bada/vmpro.bada

② BadaBSD 11.0 — NetBSD 風 OS

CD イメージから起動し、sysinst 風フルスクリーン・インストーラで仮想ディスクへ インストール (disklabel → newfs FFSv2 → セット展開 → root パスワード → DHCP)。 ブートローダ・dmesg・/etc/rc・ログイン・シェルまで完備。 bada/badabsd.bada

③ BadaX Server — Windows 用 X サーバー

ASTEC-X 風の外部 X サーバー (ホスト側アプリ)。VM の中の xclock / xeyes / xterm が NAT 越しに DISPLAY=10.0.2.2:0 へ接続し、Windows 側に表示されます。認証は MIT-MAGIC-COOKIE-1 ならぬ JONES-KNOT-COOKIE-1 (三葉結び目の Jones 多項式鍵) + Bell 対 QKD。bada/badax.bada

ヘルプ — 最短ツアー

1. ▶ 起動 — 初回は CD (ISO) から sysinst が起動します。
   メニューは表示されたキー (a, b, j, x…) を 1 文字押すだけ。a → a → a → a → a と進むとインストールが走ります。
2. root パスワードとホスト名を入力 → 任意のキーでディスクから再起動。
3. login: root + 設定したパスワードでログイン。
4. help でコマンド一覧。xclock & xeyes & xterm & を打つと BadaX Server (ASTEC-X 風ウィンドウ) に表示されます。
5. qstat で Bell 対の零保存、xdpyinfo で JONES-KNOT-COOKIE-1 を確認。
6. 📷 スナップショット = イベント台帳のプレフィックス。⤺ 復元 でその時点に巻き戻ります。
