# ◎ Bada Baumkuchen — 優しさのソース検索・蓄積

**受けた優しさ・贈った優しさを「一層」として焼き重ね、後ろから(外側から)読み直すアプリケーション。** ノートの左ページの方程式と絵を、右ページのバームクーヘンの後ろからの意味合いで読む —— 各層には **値札** が付き、**DNA のスイッチ**が ON / OFF し、人と人の結びつきは **種数**(穴の数)として数えられます。依存ゼロ・単一 HTML・完全オフライン動作。

## ✨ できること

- **層を焼く** — 「誰から / 誰へ」「何があったか」を書くと、バームクーヘンの一層になります(内側 = 古い / 外側 = 新しい)
- **優しさのソースを検索** — 本文・ソース名・遺伝子名で全文検索。DNA マスク(ON 必須 / OFF 必須 / 不問)、値札の帯、向き、輪を閉じた層だけ、で絞り込み
- **後ろからの意味合い** — 外側から k 層を剥くと、剥いた分 P(k)・残った芯 R(k)・残りの種数 g(k)・「ここから外にしか無い優しさ」が出ます
- **値札** — 払った手間と受け取った利得、そして蓄積の中での希少性から、層ごとの価格を付けます
- **DNA スイッチのオンオフした方法** — 8 本の優しさ遺伝子の発現率と、**最後に反転した層**(いつ点いたか / いつ消えたか)
- **種数の後ろからの意味合い** — 新しい層から読み、**輪を閉じた層**(返礼が届いた層)と、その閉路を復元して表示
- **蓄積** — localStorage に保存。JSON / CSV 書き出し、JSON 取り込み、見本 14 層

## 📐 方程式(画面が実際に計算している式)

**値札**

```
price(L) = 100 · (1 + c) · (1 + b/10) · rho · (1 + k/8)
rho      = 1 + (1/k) · Σ_{j: d_j = 1} (1 − f_j / N)          1 ≤ rho ≤ 2
```

`c` = 贈った側が払った手間、`b` = 受け取った側の利得、`k` = 点いている遺伝子の数、`f_j` = その遺伝子を持つ層の数、`N` = 総層数。蓄積の中で珍しい優しさほど `rho` が 2 に近づき、値札が上がります(`N = 0` のときは測れないので `rho = 1`)。

**種数**

人を頂点、層を辺とするグラフ `G = (V, E)` を作り、その第一ベッチ数を種数とします。

```
g = b₁(G) = E − V + C          C = 連結成分の数
```

グラフを太らせた立体はハンドル体で、その種数がこれ。**同じ相手ともう一度結ばれた層**(返礼が届いた層)が輪を一つ閉じ、バームクーヘンの穴が一つ増えます。自分から自分への層は自己ループとして、それ自体で穴を一つ作ります。

**DNA スイッチの発現率**(半減期 90 日)

```
e_j = Σ_i w_i · d_ij / Σ_i w_i         w_i = 2^(−Δt_i / 90日)
```

**後ろからの意味合い**(外側から k 層を剥く)

```
P(k) = Σ_{i > N−k} price_i      剥いた分
R(k) = Σ_i price_i − P(k)       残った芯
g(k) = b₁( L_1 .. L_{N−k} )     残りの種数
```

剥くと輪はほどけるので、`g(k)` は単調に減ります。**輪は外側の層に支えられている** —— これが種数を後ろから読んだときに出てくることです。

## ⚙ 仕組み

1. 本文を正規化(全角→半角 / カタカナ→ひらがな / 小文字化。**1 文字 → 1 文字の写像**なので、正規化後の位置をそのままハイライトに使えます)
2. キーワード照合で DNA スイッチを自動判定
3. 蓄積全体の遺伝子頻度から希少性を出し、全層の値札を付け直し
4. Union-Find でグラフを組み、`E − V + C` で種数を算出。新しい層から辺を足していき、すでに繋がっている二人を結んだ辺を **輪を閉じた層** として拾い、その時点の森を BFS して閉路を復元
5. Canvas に同心円で層を描画(色 = 主となる遺伝子、厚み = 値札の対数、緑の点 = 輪を閉じた層)。剥いた層は破線で表示

外部ライブラリ・サーバーは一切使いません。書いた内容が端末の外に出ることはありません。

## 🚀 使い方

1. [`index.html`](index.html) を「Download raw file」で保存 → ダブルクリック(インストール不要)
2. 左の **⊕ 層を焼く** に書いて **⊕ この層を焼く**
3. 右の **🔍 優しさのソースを検索** で引き、スライダーで **後ろから剥いて** 読む
4. リングをクリックすると、その層まで一気に剥けます

初回は見本 14 層が入っています。**全消去** で空にでき、**見本を入れる** でいつでも戻せます。
