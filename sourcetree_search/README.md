# 🔎 Bada Search — SourceTree 付属 PDF・ソースコード検索エンジン (Windows 10/11)

Git GUI **SourceTree** の「カスタム操作」に登録して付属アプリとして使う検索エンジンです。
リポジトリを丸ごとインデックスし、**プログラミング言語のソースコード**(C/C++/JavaScript/
TypeScript/Python/Ruby/Java/Go/Rust/PHP/C#/Swift/Kotlin/Shell/SQL/HTML/CSS/Bada/OmegaScript
ほか 40 種以上)と **PDF の中身**(FlateDecode ストリームからのテキスト抽出 — 依存ライブラリ
ゼロ)を横断検索します。単体アプリとしても動きます。

## 🏥 単語補完 大画面モード (既定画面 — 広島大学病院の薬剤検索風)

起動すると、**黒い大画面の端末**が開き、検索ボックスに数文字を打つだけで、
論文(PDF)とソースコードから抽出した**単語の補完候補がポップアップメニューで出現**します
(広島大学医学部附属病院の薬剤検索システムと同じインクリメンタル補完)。

- **索引時に語彙(ボキャブラリ)を構築** — ソースの識別子(`jonesKey`, `kauffman_bracket` …)と
  論文本文の単語、和文の語(`量子多項式` …)を収集し、出現頻度と出現ファイル数を記録。
- **入力途中で候補をポップアップ** — 前方一致を最優先、足りなければ部分一致で補い、**頻度の高い順**に表示。
  各候補に「○件 / ○ファイル」と「前方/部分」タグ付き。
- **キーボード操作** — `↑`/`↓` で候補移動、`Enter` で確定(その語で全文検索)、`Esc` で閉じる。
  マウスのクリックでも選択可。
- 候補を選ぶと、その単語で本文・コードを横断検索し、**行番号つき・ハイライト付き**で大画面に表示。

> 画面右上の「**詳細ビュー →**」で、従来のフィルタ付き一覧ビュー(下記)にいつでも切り替えられます
> (詳細ビュー側の「🏥 単語補完 大画面 →」で戻れます)。

## 🎬 付属エディタ BadaCineVim (シネマ風 Vim エディタ + PDF ページ表示・編集)

検索結果の各ファイルの **🎬 CineVim** ボタンから、そのファイルを付属エディタ
**BadaCineVim** で開けます(黒い大画面に合うシネマ風オーバーレイ)。
検索語の **該当箇所へ自動ジャンプ**し、一致箇所をハイライトします。

| 開くもの | 表示 | 編集と保存 |
|:---|:---|:---|
| ソースコード / テキスト / `.tex` | Vim スタイルのモーダル エディタ | その場で編集し `:w` で保存 |
| **PDF** | **本物のページとして表示**(日本語論文も可) | **マーカー・手書き・メモを付けて `:w` で PDF に保存** |

### ⌨ ソース/テキストの編集 (Vim エディタ)

- **NORMAL**: `h j k l` 移動 / `0 $ ^` 行頭末 / `w b` 単語 / `gg G` 先頭末 /
  `x` 1字削除 / `dd` 行削除 / **`yy` ヤンク・`p` `P` 貼り付け** / **`u` 取り消し・`Ctrl-r` やり直し** /
  `Ctrl-d` `Ctrl-u` 半画面 / `n` `N` 検索送り
- **INSERT**: `i a A I o O` で挿入開始、`Enter` 改行、`Backspace`、`Esc` で NORMAL へ
- **COMMAND**: `/語` 検索、`:w` 保存、`:q` 閉じる(未保存なら `:q!` で破棄)、`:wq` 保存して閉じる、`:<行番号>` 移動
- **日本語入力に対応** — 日本語変換(IME)・Android のソフトキーボード・貼り付けの文字も
  そのまま入ります(`/語` の検索語も日本語で打てます)。NORMAL モードでの貼り付けは、
  文章がコマンドとして実行されないよう無視します。
- 保存した内容は**すぐ検索に反映**されます(再索引は不要)。

### 📄 PDF をページとして表示して編集する

PDF のヒットは **🎬 CineVim PDF** ボタンになり、PDF を**そのままのレイアウトで**開きます
(同梱の pdf.js で描画。日本語の CID フォント用 CMap も同梱しているので、フォントを
埋め込んでいない日本語論文も表示できます)。

- **検索語のあるページへ自動ジャンプ**し、ページ上の一致箇所を光らせます。
  `n` `N` で次/前のヒット、`/語` で PDF 内を再検索(日本語可)。
- **Vim のモードで編集**(下記)。文字の書き換え・削除・行の追加・置換を、カーソルとキーだけで行えます。
- **マウスでの書き込み(注釈)** — ツールバー、またはコマンドで切り替え:

  | ツール | コマンド | 操作 |
  |:---|:---:|:---|
  | 👆 選択 | `v` | 書き込みをクリックで選択、ドラッグで移動、`x` で削除。メモ・文字修正はダブルクリックで書き換え |
  | 🖍 マーカー | `m` | ドラッグした範囲にマーカー(4 色) |
  | ✎ ペン | `:pen` | ドラッグで手書き(4 色) |
  | 💬 メモ | `:note` | クリックした場所にメモを書き込む(`Enter` 確定 / `Shift+Enter` 改行、日本語可) |
  | 🔎→🖍 | `M` | そのページの検索ヒットを、そのままマーカーとして残す |

- **`:w` で PDF そのものに保存** — 標準の PDF 注釈(Highlight / Ink / FreeText + 外観
  ストリーム)として書き込むので、**Acrobat やブラウザなど他の PDF ビューアでも表示**されます。
  開き直せば同じ書き込みをそのまま**再編集**できます(移動・削除・書き換え)。
- **書き込んだメモは検索対象**になります(検索結果では `〔注釈〕 …` の行として出ます)。
- **⌨ テキスト**(`t`)で抽出テキストの Vim 表示に切り替え、**📄 PDF 表示**で戻れます。
- 同じ場所に原稿の `.tex` があれば **📝 .tex を編集** ボタンが出て、LaTeX ソースを
  CineVim で直接編集できます(文章を大きく書き直すならこちらが確実です)。

### ⌨ PDF を Vim のモードで編集する

PDF のページ表示は、ソースの編集と同じ **NORMAL / INSERT / COMMAND** の 3 モードで操作します。
ページ上の文字(1 行ぶんのまとまり)の上に**ブロックカーソル**があり、その行をその場で書き換えます
(元の文字を紙の色で隠し、同じ位置・大きさ・書体の系統で打ち直す「文字修正」になります)。

| モード | キー | 動作 |
|:---|:---|:---|
| **NORMAL** | `h` `l` / `j` `k` | 文字単位 / 行単位でカーソル移動(ページの端では隣のページへ続く) |
| | `w` `b` / `0` `$` | 次・前の文字のまとまり / 行頭・行末 |
| | `gg` `G` / `]` `[` / `:<数>` | 先頭・末尾のページ / 次・前のページ / そのページへ |
| | `Ctrl-d` `Ctrl-u` / `+` `-` | 半画面スクロール / 拡大・縮小 |
| | `x` / `dd` / `D` | 1 字削除 / 行を削除 / カーソルから行末まで削除 |
| | `yy` / `p` | 行をヤンク / 下の行として貼り付け |
| | `u` | 取り消し(ページ操作・焼き込みも含む) |
| | `n` `N` | 次・前の検索ヒットへ(カーソルもその語の上へ) |
| **INSERT** | `i` `a` / `I` `A` | カーソル位置 / その次 / 行頭 / 行末から入力 |
| | `o` `O` | 下 / 上に新しい行を足して入力 |
| | `cc` `S` | 行を空にして打ち直す |
| | (入力中) | 文字を打って **`Esc` で確定**(`Enter` は改行)。日本語変換もそのまま使えます |
| **COMMAND** | `:s/旧/新/` | カーソル行を置換(`g` 行内すべて・`i` 大小無視。旧は正規表現、新では `\1` `&` が使える) |
| | `:%s/旧/新/g` | **全ページ**を置換(1 回の `u` でまとめて戻せる) |
| | `:d` | カーソル行を削除 |
| | `:note 文` / `:hl` | カーソル行にメモ / マーカー |
| | `:marker` `:pen` `:note` `:text` `:erase` `:select` | マウスで使うツールの切り替え |
| | `:rotate` `:delpage` `:blank` `:merge` `:move N` `:flatten` | ページ操作 / 焼き込み |
| | `/語` `:w` `:q` `:q!` `:wq` `:undo` | PDF 内検索 / 保存 / 閉じる / 取り消し |

直した行を元と同じ文字に戻すと、その修正は自動的に外れます。検索から開いたときは、
カーソルが最初のヒットの語の上に置かれるので、そのまま `i` や `:s` で直せます。

### 🛠 PDF 専用の編集ツール

注釈とは別に、PDF そのものを直すためのツールを 2 段目のツールバー(**PDF 編集**)に並べています。

| ツール | キー / コマンド | できること |
|:---|:---:|:---|
| ✏ 文字修正 | `:text` | **ページ上の文字をクリックして書き換える**(元の文字を紙の色で隠し、同じ位置・大きさ・書体の系統で打ち直す)。空にして確定すれば文字を消せます。何もない所をクリックすると文字を追加。ダブルクリックで再編集 |
| ⬜ 消去 | `:erase` | ドラッグした範囲を紙の色で塗りつぶして消す |
| ⟳ 回転 | `R` | 表示中のページを右に 90° 回転 |
| ⬆ 前へ / ⬇ 後ろへ | `<` `>` | ページの並べ替え(`:move 3` で 3 ページ目へ) |
| ➕ 空白 | `:blank` | 表示中のページの後ろに空白ページ |
| 📎 結合 | `:merge` | 別の PDF を末尾に結合(その PDF に付いていた書き込みも引き継ぐ) |
| ✂ 削除 | `:delpage` | 表示中のページを削除 |
| 📌 焼き込み | `F` | 書き込みを**ページ本体に確定**する(注釈ではなくページの一部になり、どのビューアでも必ず同じに表示・印刷される。以後は動かせない) |

- **すべて `u` で取り消せます**(ページ操作・焼き込みも含む)。ページを動かすと、そのページの書き込みも一緒に動きます。
- 保存は同じく `:w`。焼き込む前の文字修正・消去は、開き直せば移動・書き換え・削除ができます。
- キーボードだけで文字を直すなら、上の **Vim モード**(`i` で入力、`:s/旧/新/` で置換)のほうが速く使えます。

> **文字修正・消去は「上から隠して打ち直す」方式です。** 見た目と印刷は直りますが、元の文字のデータは
> PDF の中に残ります(コピーや検索で拾えることがあります)。機密情報を取り除く用途(墨消し)には使えません。
> 書体は元と同じ系統(明朝/ゴシック/等幅)を選びますが、元のフォントそのものではありません。

### 💾 保存先(環境ごと)

| 環境 | ソース/テキストの `:w` | PDF の `:w` |
|:---|:---|:---|
| **Windows EXE** | その場に上書き | その場に上書き(初回だけ元の PDF を `<名前>.pdf.bak` に退避) |
| **ブラウザ(Chrome / Edge)** | 「📂 リポジトリを選択」でフォルダを読み書き可で開くので、その場に上書き | 同左(初回のみ `.bak` を作成) |
| **Android APK** | アプリの保存フォルダ(`Android/data/io.github.masaaki_avnturle.badasearch/files/`)に書き出し | 同左 |
| 上記以外のブラウザ | ダウンロードとして保存(元ファイルは変更しない) | 同左 |

EXE の書き込みは**索引したフォルダの中だけ**に制限しています。

> 由来: リポジトリの mini-Vim 実装 (`neovim/omega-vim.c`) の操作系を、Web/Electron の
> Bada Search に合わせて純 JS で作り直した付属エディタです。PDF の描画には
> [pdf.js](https://github.com/mozilla/pdf.js)、PDF への書き込みには
> [pdf-lib](https://github.com/Hopding/pdf-lib) を同梱しています(`app/www/vendor/`、
> ネットワーク不要)。検索エンジン本体 `searchcore.js` は従来どおり依存ゼロです。

## 🌳 SourceTree に付属させる手順

1. SourceTree の **ツール → オプション → カスタム操作** を開き「**追加**」
2. **メニューキャプション**: `Bada Search (PDF・コード検索)`
3. **実行するスクリプト**: インストールした `BadaSearch.exe` のフルパス
   (既定: `C:\Users\<あなた>\AppData\Local\Programs\BadaSearch\BadaSearch.exe`、
   ポータブル版は置いた場所)
4. **パラメータ**: `$REPO`

以後、SourceTree でリポジトリを開いた状態で **操作 → カスタム操作 → Bada Search** を
選ぶと、そのリポジトリを自動インデックスして検索画面が開きます
(`$REPO` がコマンドライン引数としてアプリに渡ります)。

## 使い方

- **検索語** — 空白区切りは AND 検索。`正規表現` チェックで regex、`大文字小文字` で厳密一致
- **言語フィルタ** — 検出された言語 (PDF 含む) で絞り込み / **パス絞り込み** — 例 `src/`
- 結果はファイルごとにヒット数順で並び、**行番号つき・ハイライト付き**で表示。
  「開く」で既定アプリ、📁 でエクスプローラー表示
- インデックスは `.git` / `node_modules` / `dist` などを自動除外、バイナリも自動判定で除外

## PDF 検索について

PDF は内蔵パーサーが FlateDecode / 無圧縮のコンテンツ ストリームを伸長し、
`Tj` / `TJ` / 16 進文字列のテキスト オペレータから本文を抽出します。
外部ライブラリ・ネットワーク不要。

**日本語の文字化け対策**: 日本語 PDF が使う CID フォント (Identity-H) では、
文字列の 2 バイトは Unicode ではなくグリフ ID のため、そのまま文字コード化すると
文字化けします。本パーサーは PDF 内の **`/ToUnicode` CMap** (`beginbfchar` /
`beginbfrange`) を解析して **CID → Unicode に変換**するため、日本語も正しく
索引・検索できます (Node=EXE / ブラウザ=APK 共通のロジック)。ブラウザ側 (APK) は
`DecompressionStream` で伸長し、`/Length` または末尾 EOL の調整で厳格な展開にも対応します。
画像だけのスキャン PDF や `/ToUnicode` を持たない一部 PDF はテキストを取れないことが
あります (その場合は検索対象から自動で外れます)。

## 制限事項

- **文字修正・消去は元の文字を隠して打ち直す方式**で、元の文字のデータは PDF 内に残ります
  (墨消しには使えません)。行の折り返しや前後の文字の詰め直しはしません。
- 日本語のメモは、フォントを PDF に埋め込まず日本語 CID フォントを参照する形で書き込みます
  (ファイルが大きくならない一般的な方式)。Acrobat・Chrome・Edge・macOS プレビューなどでは
  表示されますが、日本語フォント資源を持たないビューアでは文字が出ないことがあります
  (メモの内容自体は PDF に Unicode で保存されており、本アプリでは常に表示・検索できます)。
- 回転されたページでは、メモ・文字修正の文字がページの向きに合わせて回転しません。
- 焼き込んだ文字は、本アプリの索引(検索)には載りません。
- 暗号化(パスワード付き)PDF は表示のみで、注釈の保存はできません。
- 索引用のテキスト抽出は `/ToUnicode` を持たない日本語 PDF を正しく読めないことがあります
  (「PDF 検索について」を参照)。その場合も PDF 表示の中の `/語` 検索は pdf.js を使うため日本語で探せます。
- Android APK の保存処理(アプリの保存フォルダへの書き出し)は、ビルドは CI で確認していますが
  実機での動作確認はしていません。
