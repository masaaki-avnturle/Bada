🔎 Bada Search — SourceTree 付属 PDF・ソースコード検索エンジン

リポジトリを丸ごとインデックスし、プログラミング言語のソースと PDF の中身を横断検索 (依存ゼロ・オフライン)
(未選択 — SourceTree のカスタム操作から $REPO 付きで起動すると自動で開きます)
🔎
フォルダを選択するか、SourceTree から起動してください。

🌳 SourceTree (Windows 10/11) に付属させる

1. SourceTree の ツール → オプション → カスタム操作 を開き「追加」
2. メニューキャプション: Bada Search (PDF・コード検索)
3. 実行するスクリプト: インストールした BadaSearch.exe のパス
   (既定: C:\Users\<you>\AppData\Local\Programs\BadaSearch\BadaSearch.exe)
4. パラメータ: $REPO
→ 以後、SourceTree のリポジトリ上で 操作 → カスタム操作 → Bada Search を選ぶと、 そのリポジトリを自動インデックスしてこの検索画面が開きます。
