# 🧊 Yappa 3D — Bada 3D デザインアプリ

**依存ゼロの単一 HTML ファイル**で動く 3D デザイン / モデリングアプリです。
WebGL レンダラ・行列演算・ジオメトリ生成まで、すべて [`index.html`](index.html) 1 ファイル内に自前実装しています。

## 🚀 起動方法

**ブラウザで開くだけ**です。インストール不要・オフライン動作:

- GitHub Pages: **<https://masaaki-avnturle.github.io/Bada/yappa3d/>** (main マージ後)
- ローカル: [`index.html`](index.html) をダウンロードしてダブルクリック
  (GitHub のファイル表示画面右上の「Download raw file」⬇ で保存できます)

## 🖥️ 画面構成

| パネル | 内容 |
|:---|:---|
| **ツールバー** | 追加 / 複製 / 削除 / 戻す・やり直し / 視点リセット / 保存・読込 / OBJ 書き出し / PNG |
| **シーン** (左) | オブジェクト一覧。クリックで選択、👁 で表示 / 非表示 |
| **ビューポート** (中央) | WebGL 3D ビュー。グリッド + XZ 軸 + 平面射影の落ち影 |
| **インスペクタ** (右) | 名前 / 位置 / 回転 (°) / 拡大 / 色 / 光沢 / ワイヤーフレーム |

## 🧱 プリミティブ

立方体 ▣ · 球 ● · 円柱 ◍ · 円錐 ▲ · トーラス ◎ · 平面 ▬

「＋ 追加」メニューから配置します。追加したオブジェクトは自動で選択されます。

## 🖱️ 操作方法

| 操作 | 動作 |
|:---|:---|
| 何もない所をドラッグ | 視点回転 (オービット) |
| オブジェクトをドラッグ | XZ 平面上を移動 |
| **Shift** + オブジェクトをドラッグ | 上下 (Y) 移動 |
| ホイール | ズーム |
| 右ドラッグ | パン |
| 2 本指 (タッチ) | ピンチズーム + パン |
| クリック (空白) | 選択解除 |
| **F** | 選択オブジェクトへカメラフォーカス |
| **Delete** | 削除 |
| **Ctrl+D** | 複製 |
| **Ctrl+Z** / **Ctrl+Y** | 元に戻す / やり直し |

## 💾 保存と書き出し

| ボタン | 内容 |
|:---|:---|
| 💾 保存 | シーンを JSON (`scene.yappa3d.json`) でダウンロード |
| 📂 読込 | 保存した JSON を読み込み |
| ⬇ OBJ 書き出し | シーン全体を **Wavefront OBJ + MTL** で書き出し (Blender 等で読込可。ワールド変換・法線・マテリアル色付き) |
| 📷 PNG | ビューポートのスクリーンショットを PNG 保存 |

さらに **localStorage への自動保存**付き — ブラウザを閉じても、次に開いたとき前回のシーンが復元されます。

## 🔧 実装メモ

- **WebGL 1** + 自前シェーダ (2 灯ライティング + Blinn-Phong スペキュラ + 両面ライティング)
- 列優先 **mat4 / mat3 演算**を自前実装 (透視投影 / lookAt / 4x4 逆行列 / 法線行列)
- クリック選択は **GPU カラーピッキング** (オブジェクト ID を色にエンコードして readPixels)
- 落ち影は **平面射影シャドウ** (光線方向で y=0 平面へ潰す行列)
- オブジェクトのドラッグ移動は **レイ・平面交差** (スクリーン座標 → ワールドレイの逆射影)
- ワイヤーフレームは三角形インデックスから重複除去した**エッジバッファ**を `gl.LINES` 描画
- Undo / Redo は確定時スナップショット方式 (最大 120 段)
