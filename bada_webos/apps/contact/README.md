# contact — 映画『コンタクト』の輸送機（Machine）3次元設計図ジェネレータ（Bada）

添付論文（異次元ポート電話帳 IDPD・複素回転体コマ ECC・ゼータ/ガンマ大域的部分積分多様体・
Jones 多項式）の原理をつなぎ、**Bada 言語だけで** Machine の 3D 設計図（Wavefront OBJ）を生成します。

```
cd bada_webos
python3 cli.py contact                 # レポート + generated/contact/{obj,txt,html}
python3 -m contact out/                # 同じ（出力先指定）
python3 -m unittest tests.test_contact # 16 テスト（Bada の数値を Python で照合）
```

生成例は `examples/`（`contact_machine.obj` は Blender 等でそのまま開けます、
`contact_blueprint.html` はドラッグで回転できるビューア）。

## パイプライン（`contact_app.bada`）

| 段 | 論文の原理 | Bada での計算 | 出力値 |
|:--|:--|:--|:--|
| 1. 扉の方向 | 衝突で「粒子が消えた方向」 | 欠損横運動量 `MET = −Σ p_T`、方位 `atan2` | 51.3 GeV, −2.43 rad（サンプル事象） |
| 2. 時間 | 地球 1 秒 ↔ ポッド 18 時間（ベガ） | `γ = 64800`、`1−v/c`、ラピディティ `φ = acosh γ` | `γ=64800`, `1−β=1.19e−10`, `φ=11.772` |
| 3. コマ | ローレンツ変換＝虚数回転、歳差/章動/自転 | 3 本のジンバルリング、`|ψ|² = a` 保存検査 | 残差 5e−16（OK） |
| 4. ガンマ/Jones | ガンマ関数・Jones 多項式 | 半径 `Γ(k+½)/(Γ(k+1)Γ(½))` = 1, ½, ⅜；自転比 `|V(e^{ikπ/2})|`（三葉結び目 `V=t+t³−t⁴`） | 15 / 7.5 / 5.625 m；1 : 3 : 1 |
| 5. 異次元ポート | IDPD の 5 座標アドレスと反射 R | ワープ `e^{−2πT}` が `1/γ` に最も近いポート → #5 (H²×ℝ)；R で鏡像 → S²×ℝ, `P*_W = e^{4π} = 286751.3`（論文 表7 と一致）；`R² = id` | |
| 6. 設計図 | — | 3 リング + ポッド（球）+ 落下軸 + ガントリーを OBJ で出力 | 5 部品 / 216 頂点 |

ライブラリ `lib/contact.bada` は数学核（Lanczos ガンマ、範囲縮小付き exp/ln、atan2、sin/cos）も
含めてすべて Bada で書かれています。

## 正直な注記

- 数値計算そのもの（Γ、acosh、ポート表、反射 R、OBJ の幾何）はすべて検証済みで正確です。
  しかし「これで異次元への扉が開く」という物理的解釈は論文の仮説であり、確立した物理ではありません。
  これは**デザイン・フィクション**としての設計図です。
- ジュネーブ（CERN）の LHC は線形ではなく**円形**加速器（周長 27 km）です。
  衝突で「消えた」エネルギー（欠損横運動量）は、実際に ATLAS/CMS が余剰次元（ADD 模型の重力子）を
  探索する手がかりとして使っていますが、現在まで余剰次元の証拠は見つかっていません。
- 特殊相対性理論では**動いている側の時計が遅れる**ので、ポッド内 18 時間・地球 1 秒という映画の状況は
  そのままの向きでは SR と逆になります。本コードは `γ = 18h/1s` の大きさだけを用いています。
  また SR の範囲では光速を超えられないため、ベガ（25 光年）までは地球系で約 25 年かかります
  （レポートの `[25, 25.000000003]`）。
