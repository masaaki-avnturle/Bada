# 🕯 Bada Requiem — requiem × fuga ミックス

**提出された 8 本の録音を素材に、「requiem と fuga の曲調で、ミックスで、requiem の曲を作り換えた」1 本の MP4。** 遅く暗いレクイエム側の録音を主題に、フーガの提示部の形(主題 → 完全 5 度上の応答 → 1 オクターブ下の第 3 声)で時間差をつけて重ね、聖堂風の残響とオルガン風ドローンで包んで 5 楽章・約 5 分のレクイエムに作り換えました。

上のリンクを開き **「Download raw file」(⬇ アイコン)** で保存(1280×720 / 25 fps / H.264 + AAC 160 kbps / 4 分 56 秒 / 約 23 MB)。

## 🎼 構成

| 楽章 | 時間 | 素材と処理 |
|:---|:---|:---|
| **I. Introitus — 入祭唱** | 0:00 – 0:52 | requiem A(F / B♭ 系の静かな録音)を深い残響で。F・B♭ のドローンが下で鳴る |
| **II. Fuga — 主題・応答・第三声** | 0:52 – 2:00 | requiem B(F 短調のいちばん重い録音)を**主題**に、**応答**(完全 5 度上 +7 半音、8 秒遅れ・左)と**第 3 声**(1 オクターブ下 −12 半音、16 秒遅れ・右)を重ねてフーガの提示部の形にする |
| **III. Dies irae — ストレッタ** | 2:00 – 3:04 | fuga 側の明るく音数の多い 2 本(X をテンポ 1.08 倍、Y を −5 半音)を 4 秒間隔で近接して重ね(ストレッタ)、requiem C を低域で下支え |
| **IV. Lacrimosa — 涙の日** | 3:04 – 4:02 | requiem A の後半を 0.85 倍に引き延ばし、いちばん深い残響 + E♭・C♯・B♭ のドローン |
| **V. Lux aeterna — 永遠の光** | 4:02 – 4:56 | fuga Z の高声(+12 半音)を遠くに、requiem B の冒頭を 0.8 倍で敷き、F・B♭ のドローンで閉じる |

ドローンの音(F・B♭・E♭・C♯)は、リポジトリ内の [`octave74.tex`](../Kauffman_omega/reports/octave74.tex) の「バッハのフーガは … 音階は、B♭とE♭とC♯である」から取りました。いずれも F 短調(主題の調)に含まれる音です。

## 🎙 素材の割り当て

各録音(Android 録音・モノラル AAC)を、鍵・テンポ・音の密度(音/秒)・スペクトル重心で解析して役割を決めました。

| 役割 | 録音 | 長さ | 特徴 |
|:---|:---|---:|:---|
| requiem **A** | `20260925_124643` | 3:50 | F / B♭ 系、重心 ≈ 600 Hz、0.5 音/秒、静かな導入と終結 |
| requiem **B** | `20260924_084937` | 3:34 | F 短調が中心、重心 ≈ 540 Hz、いちばん重い |
| requiem **C** | `20260924_085314` | 3:22 | B 短調 / D 長調、旋律的 |
| fuga **X** | `20260924_112131` | 1:36 | 重心 ≈ 1 400 Hz、いちばん明るい |
| fuga **Y** | `20260924_111846` | 2:37 | 1.1 音/秒、動きの多い中声域 |
| fuga **Z** | `20260925_125053` | 4:24 | 重心 ≈ 1 000 Hz、G / D 系 |
| (未使用) | `20260924_112313`, `20260925_130431` | | 短い / 録音レベルが低くノイズが多いため今回は不使用 |

## ⚙ 仕組み

1. `ffmpeg` で各素材を切り出し、`rubberband` フィルタでピッチ(半音)とテンポを独立に変える
2. `numpy` / `scipy` で、パン・ハイパス / ローパス・フェードを付けてタイムラインに配置(dry バスと残響 send バス)
3. 残響は自前の聖堂風インパルス応答(RT60 ≈ 3.6 秒、左右で別の雑音 → 広がるステレオ)を FFT 畳み込み
4. オルガン風ドローン(倍音 4 つ、ゆっくりした揺れ)を加算
5. ソフトリミッタ → ピーク −1 dBFS → `showcqt` ビジュアライザと楽章名の字幕を付けて H.264 + AAC の MP4 に書き出し

## 🔁 作り直す

```
pip install numpy scipy            # ffmpeg(rubberband 入り)も必要: apt install ffmpeg
python3 requiem_mix/make_mix.py --src <録音 8 本のフォルダ> --out requiem_mix/output
```

`--src` には提出された録音(ファイル名にタイムスタンプ `20260924_084937` などを含むもの)が入ったフォルダを指定します。楽章の長さ・素材・ピッチ・残響量は [`make_mix.py`](make_mix.py) の `build()` にまとめてあり、数値を変えるだけで作り換えられます。
