# riemann_prover — リーマン予想 / 深リーマン予想 検証エンジン

> **重要**: リーマン予想 (RH) と深リーマン予想 (DRH) は未解決問題であり、このアプリは
> **どちらも証明しません**。計算機で確かめられる有限の主張を検証し、予想そのものには
> 「未解決（経験的証拠のみ）」と判定を出します。これは未知事前エンジンの健全性規約
> （証明できるものだけ証明完了とし、未解決は未解決と明示する）と同じ方針です。

## 何を検証するか

1. **高さ T までの RH**（判定: 数値検証完了）
   偏角の原理で帯領域内の零点総数 `N(T) = θ(T)/π + 1 + S(T)` を求め、臨界線上の
   Hardy `Z(t)` の符号変化の個数と比較する。一致すれば `0 < Im ρ < T` の零点はすべて
   `Re ρ = 1/2` 上にあり単純。
2. **Schoenfeld 不等式**（判定: 数値検証完了）
   RH は「すべての `x ≥ 73.2` で `|ψ(x) − x| < √x·log²x/(8π)`」と同値。これを有限の
   `x ≤ X` で全数検査する。
3. **深リーマン予想の数値的証拠**（判定: 未解決）
   Dirichlet 指標 χ に対し、臨界線上のオイラー積 `Π_{p≤x}(1 − χ(p)p^{-s})^{-1}` が
   `L(s,χ)`（`s = 1/2` かつ `χ² = 1` のときは `√2·L(s,χ)`）へ近づく様子を表にする。

## 擬似量子コンピュータによる反例探索（`qsim.py`）

「すべての n で P(n)」型の予想について、n を量子レジスタの基底状態に載せ、反例に印を
付けるオラクルで Grover 探索を行う。測定結果は必ず古典的に再検査する。

| 問題 | 探索する反例 |
|:--|:--|
| リーマン予想（Lagarias の同値形） | σ(n) > H_n + exp(H_n)·log(H_n) となる n |
| ゴールドバッハ予想 | 2 素数の和で書けない偶数 |
| コラッツ予想 | 1 に到達しない n |
| ルジャンドル予想 | n² と (n+1)² の間に素数がない n |
| 対照実験 `n² + n + 41 は常に素数`（偽） | 合成数になる n（n = 40 など。実際に見つかる） |

- 反例が見つかれば、その予想は**反証**される（健全）。
- 見つからなければ「その範囲に反例なし」が確定するだけで、予想は**未解決**のまま。
- シミュレーションではオラクルを作るために 2^k 個すべてを古典的に評価しているので、
  量子的な高速化は得られない。高速化は実機でのみ意味を持つ。

## 数学的帰納法・証明の修正・補集合の解析（`induction.py`）

1. **帰納法（厳密）** — `Σ_{k=1}^n f(k) = g(n)`（f, g は多項式）を、基底 `g(0)=0` と
   段 `g(n+1) − g(n) − f(n+1) ≡ 0` で判定する。有理数の厳密演算なので、成り立てば
   本当に**証明完了**、成り立たなければ最小の反例を返す。
2. **証明の修正** — `I(n) = g(n) − Σ f(k)` を保存量とみなし、段の残差をそのドリフトとして
   測る。誤った g を `I ≡ 0` の等位集合へ射影して正しい閉形式に直し、あらためて帰納法で
   証明する（コマの誤り訂正が軌道を |L|² の等位集合へ戻すのと同じ形）。
3. **補集合の解析** — 反例の集合（真である n の補集合）が空であることと帰納法は同値
   （整列性）。コラッツ予想について「最小反例は 2^k 以上で、特定の剰余類に属する」を
   降下補題として証明する（生き残る剰余類の個数は既知の数列 1, 1, 2, 3, 4, 8, 13, 19, …
   と一致）。**予想そのものは未解決のまま**。
4. **限界の明示** — RH・DRH・ゴールドバッハには既知の帰納の段がないことを記録する。

## 証明書 PatchGuard（書き換えの門）

証明書を書き換えるとき、基と後を比べて次の不変量を検査する。高以上は REJECT、中は REVIEW。

| ID | 検査 | 重大度 |
|:--|:--|:--|
| RG01 | RH / DRH の判定を「未解決」以外へ書き換える | 致命的 |
| RG02 | 「検証済み」なのに零点総数と線上の個数が一致しない | 致命的 |
| RG03 | `--recompute` で再計算した N(T) が記載と違う | 致命的 |
| RG04 | Schoenfeld 不等式が検証済みなのに最大比が 1 以上 | 高 |
| RG05 | DRH の証拠（有限の部分積）を「未解決」以外にする | 致命的 |
| RG06 | 健全性の注記の削除・変更 | 高 |
| RG07 | 封印がない（中）／封印が内容と不一致（高） | 中 / 高 |
| RG08 | 検証の高さ・上限の縮小 | 中 |
| RG09 | DRH の証拠の削除 | 中 |
| RG11 | 帰納法の項目の判定が再導出と一致しない（予想を「証明済み」にする等） | 致命的 |
| RG10 | 量子探索の結果を「証明」とする／再検査を通らない反例で「反証」とする | 致命的 |

複数回の書き換えは折り畳み、正味の 基 → 最終 で判定する（途中の段だけの指摘は「相殺」として記録）。

## 使い方

```bash
python3 -m riemann_prover.cli run --height 1000 --qubits 12 --out certificate.json
python3 -m riemann_prover.cli check certificate.json           # 封印の検査
python3 -m riemann_prover.cli induct --f 0 0 1 --g 0 1/5 3/5 2/5   # Σk² の誤った式を判定して修正
python3 -m riemann_prover.cli guard certificate.json --recompute   # 単体を門で検査
python3 -m riemann_prover.cli guard base.json after.json --out tuples.jsonl   # 書き換えを検査 (終了コード 0/1/2)
python3 -m unittest riemann_prover.tests.test_riemann_prover
```

## 限界

- 計算は倍精度浮動小数点であり、区間演算による厳密な証明ではない。
- 有限範囲の検証は、いくら範囲を広げても予想全体の証明にはならない。
- DRH のオイラー積の収束は非常に遅く、`x = 10^6` でも数 % の揺らぎが残る。
