# riemann_prover — リーマン予想 / 深リーマン予想 検証エンジン

> **重要**: リーマン予想 (RH) と深リーマン予想 (DRH) は未解決問題であり、このアプリは
> **どちらも証明しません**。計算機で確かめられる有限の主張を検証し、予想そのものには
> 「未解決（経験的証拠のみ）」と判定を出します。これは未知事前エンジンの健全性規約
> （証明できるものだけ証明完了とし、未解決は未解決と明示する）と同じ方針です。

## このリポジトリ内の関連アプリケーションとの関係

| 既存コード | ここでの使い方 |
|---|---|
| 未知事前エンジン `bada_ruby/lib/bada/prover/` | 判定体系（証明完了 / 反証 / 未解決）と健全性注記をそのまま踏襲 |
| ゼータ関数 `bada_webos/apps/discover/lib/zeta.bada`, `bada_ruby/lib/bada/special.rb` | 実数 s > 1 の級数だった ζ を、Euler–Maclaurin 展開で複素平面全体（臨界線上）へ拡張 |
| ミレニアム分解 `bada_ruby/lib/bada/millennium.rb` | RH を対象問題として実際に数値検証する部分を担当 |
| 量子暗号 `jones_quantum_crypto/` | 検証結果の証明書を、組みひもの Jones 多項式から導出した鍵で封印・改ざん検知 |
| BadaPatchGarde | リポジトリ内に該当する名前のコードは見つからなかったため、未接続 |

## 何を検証するか

1. **高さ T までの RH**（判定: 数値検証完了）
   偏角の原理で帯領域内の零点総数 `N(T) = θ(T)/π + 1 + S(T)` を求め、臨界線上の
   Hardy `Z(t)` の符号変化の個数と比較する。一致すれば `0 < Im ρ < T` の零点はすべて
   `Re ρ = 1/2` 上にあり単純。
2. **Schoenfeld 不等式**（判定: 数値検証完了）
   RH は「すべての `x ≥ 73.2` で `|ψ(x) − x| < √x·log²x/(8π)`」と同値。これを有限の
   `x ≤ X` で全数検査する。
3. **深リーマン予想の数値的証拠**（判定: 未解決）
   Dirichlet 指標 χ に対し、臨界線上のオイラー積 `Π_{p≤x}(1 − χ(p)p^{-s})^{-1}` が
   `L(s,χ)`（`s = 1/2` かつ `χ² = 1` のときは `√2·L(s,χ)`）へ近づく様子を表にする。

## 使い方

```bash
python3 -m riemann_prover.cli run --height 1000 --out certificate.json
python3 -m riemann_prover.cli check certificate.json           # 封印の検査
python3 -m unittest riemann_prover.tests.test_riemann_prover
```

## 限界

- 計算は倍精度浮動小数点であり、区間演算による厳密な証明ではない。
- 有限範囲の検証は、いくら範囲を広げても予想全体の証明にはならない。
- DRH のオイラー積の収束は非常に遅く、`x = 10^6` でも数 % の揺らぎが残る。
