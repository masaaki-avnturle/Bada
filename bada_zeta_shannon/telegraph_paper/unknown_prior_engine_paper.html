要旨

本稿は、量子プログラミング言語 Bada のランタイムである「未知事前エンジン」(Unknown-Prior Engine) を報告する。エンジンは、何も知らない状態を最大エントロピーの一様分布で表し、証拠を追記専用の台帳に積むことで確信を得る。推論の中心は位相コア ψi = √ai·exp(iθi) であり、確実な零は復活しないことと、位相は確率を変えないことが定理として成り立つ。

本稿の作成には、Telegraph のレポート (BadaGPT電信) の「全体把握 → 設計 → 生成 → 検証 → 論文」のパイプラインを用いた。依頼文を節に分け、節ごとにエンジンの推論で台帳の事実へ対応付け、章を決め、文を選んで並べる処理を、すべて Bada のプログラムとして実行した。ひな形の穴埋めは行わず、文の選択は事後確率で、並べ方は隣接する文の類似度で決める。これを抽出的生成と呼ぶ。第 6 章はその出力をそのまま載せたものである。

評価では三つの実験を行った。手稿の参照実行 (語彙 8、除外 2) を再現し、零の保存と最大偏差 5.55×10−17 を確認した。乱数による 200 試行で、加法型の結合は全 200 試行で除外済みのトークンに確率を戻し (平均 5.79%)、位相コアは 0 試行であった。学習則の比較では、処理系の既定の学習率 0.5 は真の分布から離れ (KL 3.44)、学習率 1/(t+1) は近づいた (KL 0.021)。エントロピーは 36〜45% の更新で増加し、単調には減らなかった。生成では節の網羅率 100% を得たが、4 節のうち 1 節は誤った事実へ対応付けられていた。

キーワード: 未知事前分布, 最大エントロピー, 位相コア, 零の保存, 追記専用台帳, 節網羅率, 抽出的生成, Bada 言語

1. 序論

1.1 背景

Bada は、追記専用の台帳 (TupleSpace)、確率ベクトルの型 dist、位相の型、文法を書き換える @reviser を持つプログラミング言語である。量子ゲートに倣った演算 (qubit・H・CNOT・Measure) を備えるため、本リポジトリでは量子プログラミング言語と呼んでいる。その実行時の中核が未知事前エンジンであり、次トークンの分布のような確率ベクトルを受け取り、複数の情報源を重ねて出力する。

一方、Telegraph のレポートが報告する BadaGPT電信は、利用者の依頼文からアプリケーションを生成し、生成の過程を論文にまとめるシステムである。その中心は、依頼文のすべての節を仕様の要素へ対応付け、対応付けられなかった節を捨てずに残す「全体把握」にある。

1.2 課題

生成系には二つの失敗がある。一つは、根拠のない内容を確信を持って出すことである。もう一つは、依頼の一部を黙って落とすことである。前者はエンジンの側の問題で、後者はパイプラインの側の問題である。未知事前エンジンは前者に、BadaGPT電信の全体把握は後者に、それぞれ答えを与えている。本稿はこの二つを一つの Bada プログラムの中で組み合わせ、どこまでが保証で、どこからが保証でないかを測る。

加えて、BadaGPT電信の論文の段は章立てのひな形に数値を埋める方式であり、文章の段は潜在表現に駆動されたひな形の展開である。本稿ではひな形を使わず、エンジンの推論そのもので文を選ぶ方式を試みる。

1.3 本研究の貢献

  1. 未知事前エンジンの定義と、その二つの定理 (零の保存、位相の不変性)、および学習則についての二つの命題 (第 4 章)。
  2. BadaGPT電信の五段のパイプラインを Bada の文法拡張として実装し、節の対応付け・章の設計・文の選択と配列をエンジンの推論で行う抽出的生成 (第 5 章)。
  3. その出力 (節の対応表、章の設計、生成された本文) の無修正の掲載 (第 6 章)。
  4. 参照実行の再現、乗算と加法の対照、学習率の比較という三つの実験と、生成結果の誤りの分析 (第 7 章)。

2. 関連する取り組み

未知事前エンジンの手稿 — エンジンを Bada の記法と Python の参照実装の二つで与え、語彙 8・除外 2 の実行で二つの性質を確かめた。手稿は、利点の広い主張は加法型の残差ヘッドとの比較で評価する必要があると述べている。本稿の実験 E2 はその比較である。

Bada の処理系 (bada_gui_ide/) — 字句解析器・パーサ・インタプリタ・Bada から C へのコンパイラを持つ。位相コアは組み込み関数 cognitive_system として提供される。

BadaGPT電信 (Telegraph のレポート) — 全体把握・設計・生成・検証・論文の五段を持つ。節の網羅率を定義し、未見の依頼 10 件で網羅率 100%・モジュール選択 F1 81.5% を報告した。網羅率は取りこぼしがないことを示すが、正しく解釈したことは示さない、という知見が本稿の出発点の一つである。

ゼータ・シャノン言語エンジン (bada_zeta_shannon/) — 未知事前エンジンの上に作った検索応答エンジンである。台帳の事実を、ジップの法則 (ゼータ分布) のもとでの自己情報量で重み付けして選ぶ。本稿のパイプラインは、この検索を節の対応付けと文の選択に用いる。

最大エントロピー原理 — 制約のもとでエントロピーを最大にする分布を事前分布に採るという考え方は Jaynes による。一様分布から始めることは、その最も単純な場合である。

4. 未知事前エンジンの理論

4.1 位相コア

候補の数を V とする。ロジット z から基底分布 a = softmax(z) を作る。情報源 (モジュール) m は確率分布 q(m) と位相ベクトル φ(m) の組であり、利得を βm、エントロピーを Hm = −Σj qj(m) log qj(m) とする。

θi = Σm βm Hm φi(m),　ψi = √ai · exp(iθi),　q̂i = |ψi|² / Σj |ψj|²

定理 1 (零の保存)　ai = 0 ならば、情報源と利得をどう選んでも q̂i = 0 である。
証明: ψi = 0·exp(iθi) = 0。∎
定理 2 (位相の不変性)　すべての i について q̂i = ai である。
証明: |exp(iθi)| = 1 より |ψi|² = ai、Σj aj = 1。∎

定理 1 は、除外したものが後の段で戻ってこないことを意味する。定理 2 は、位相がどれだけ重なっても分布は元のままであることを意味する。したがって位相コアは、情報源を壊さずに記録するための仕組みであり、分布を良くする仕組みではない。位相が確率に現れるのは、振幅どうしを足し合わせる操作 (干渉) を加えたときに限られる。

4.2 未知事前分布と学習則

事前分布は p0 = u = (1/V, …, 1/V) から始める。t 回目の証拠 et (確率ベクトル) と学習率 λt ∈ (0, 1) に対し、更新は

pt = (1 − λt)·pt−1 + λt·et

である。処理系の既定は λt = 0.5 である。

命題 3 (無知は零にならない)　すべての t とすべての i について pt(i) ≥ (1/V)·Πk≤t(1 − λk) > 0 である。
証明: et(i) ≥ 0 より pt(i) ≥ (1 − λt)·pt−1(i)。帰納法による。∎

命題 3 は定理 1 と対になる。確実な零は、ロジットで明示的に除外したときにだけ生じる。証拠が来なかったというだけでは、事前分布は零にならない。「見ていない」と「ありえない」が区別される。

命題 4 (学習率と収束)　証拠 et が、隠れた分布 p* から独立に引いた 1 標本の one-hot ベクトルであるとする。
(i) λt = 1/(t+1) のとき pt = (u + e1 + … + et)/(t+1) であり、t → ∞ で pt → p* (確率 1)。
(ii) λt = λ (定数) のとき pt は収束せず、定常状態での各成分の分散は λ/(2 − λ)·p*(i)(1 − p*(i)) である。
証明: (i) は漸化式を解いて大数の強法則を用いる。(ii) は pt が独立な項の指数加重和であることから、分散 λ²·Σk≥0(1 − λ)2k·p*(i)(1 − p*(i)) を計算する。∎

λ = 0.5 では分散の係数が 1/3 になり、事前分布は直近の数標本をほぼそのまま写す。エントロピーが更新のたびに減るという性質は一般には成り立たない。証拠が現在の事前分布より平らなとき、あるいは別のトークンを指すとき、エントロピーは増える。

4.3 乗算と加法

情報源 m を加法で重ねる残差ヘッド q = normalize(a + λ·m) を考える。ai = 0 かつ mi > 0 のとき qi = λ·mi/(1 + λ) > 0 となり、除外したトークンに確率が戻る。乗算 (位相) ではこれが起きない。零を保存するのは非零の因子による乗算であり、加法ではない。実験 E2 はこの差を数える。

5. 全体把握・設計・生成・検証

5.1 全体把握

依頼文を句点で文に、読点で節に分ける。各節 c について、台帳のすべての事実 Di との重み付きコサインをロジットにし、位相コアを通して事後分布 r(c) を得る。節と証拠を共有しない事実のロジットは −800 であり、確率は厳密に 0 である。

節の対応付けは次の順に行う。

  1. 被覆率 (節の重みのうち、最もよく合う事実と共有する割合) が 0.2 以上なら、その節を「台帳の事実」へ対応付ける。仕様の要素は、最上位の事実が属する話題である。
  2. そうでなく、節が pdf を含むなら「出力形式」、「ください」を含むなら「作成依頼の意図」へ規則で対応付ける。
  3. どちらでもなければ、未解釈の節として残す。

網羅率は、1 か 2 で対応付けられた節の数を全節の数で割った値である。

5.2 設計

事実 i の得点を、台帳へ対応付けられた節の事後確率の和 si = Σc ri(c) とする。これを話題ごとに合計し、節の数で割ったものを話題の質量とする。質量が 0.05 以上の話題を、大きい順に 3 つまで章にする。章立ては固定されておらず、依頼文が変われば変わる。

5.3 抽出的生成

章ごとに、その話題に属し、かつ si > 0 である事実を候補とする。si = 0 の事実、すなわちどの節とも証拠を共有しなかった事実は、候補に入らない (定理 1 の利用)。候補から得点の上位 5 文を選ぶ。先頭は得点が最大の文とし、以降は直前の文とのコサインが最大の文を順に置く。

この方式には、あらかじめ書かれた文章の骨組みも、穴も、穴に入れる語の表もない。どの文がどの順で現れるかは、依頼文と台帳から推論で決まる。ただし、現れる文は台帳に書かれた事実そのものであり、新しい文を作り出しているわけではない。

5.4 検証

生成のあとで次を機械的に確かめる。(1) 生成したすべての文が台帳の事実番号を持ち、重複がない。(2) 除外された事実が 1 文も現れていない。(3) 全節を通じて位相コアの偏差 max|q̂ − a| が 10−15 未満である。(4) 網羅率が 50% 以上である。(5) 各文の標識 (証明済・検証済・学習など) が保持されている。

7.4 生成結果の誤りの分析

6.4 節の検査は 5 つとも合格し、網羅率は 100% であった。しかし、対応付けが正しかったのは 4 節のうち 3 節である。

節 2 の誤り。「独自のテンプレートではない生成AIの量子プログラミング言語のBadaで」は、話題「このエンジン」の事実 #70 (「あなたは誰ですかと尋ねられたら、私は量子プログラミング言語で書かれた言語エンジンだと答えます」) に対応付けられた。「量子プログラミング言語」という語の一致が決め手になっている。この節が実際に求めているのは、ひな形によらない生成という方式の指定と、Bada という言語の指定である。前者に当たる事実 #79 は台帳にあったが、選ばれなかった。その結果、第 3 章には挨拶と自己紹介の文が並び、論文の章として意味をなしていない。

第 1 章の先頭の文。事実 #10 は「証拠が台帳に追記されるたびにエントロピーが減少する」と述べる。実験 E3 は、これが一般には成り立たないことを示した。エンジンは台帳の文をそのまま出すので、台帳の文が言い過ぎていれば、生成された本文も言い過ぎる。標識「検証済」は、その文が正しいことの保証ではなかった。

網羅率についての知見。Telegraph のレポートは、網羅率は取りこぼしがないことを示すが、正しく解釈したことは示さない、と述べた。本稿の結果はこれを再現した。節 2 は「対応付けられた」ので網羅率に数えられ、未解釈の節としても残らなかった。誤った対応付けは、取りこぼしよりも見つけにくい。6.1 節の対応表を必ず載せるのは、このためである。

8. 考察と限界

抽出的生成の限界。第 6 章の本文は、台帳の事実を選んで並べたものである。ひな形は使っていないが、文と文をつなぐ言葉も、段落としての論の運びもない。これは文章の生成というより、根拠の一覧に近い。ひな形を使わないことと、良い文章が書けることは別である。本稿の地の文 (第 6 章以外) は、著者が Claude の支援を受けて書いた。エンジンだけで論文を書いたわけではない。

保証されることと、されないこと。エンジンが保証するのは、除外したものが戻らないこと (定理 1)、位相が分布を壊さないこと (定理 2)、見ていないものを零にしないこと (命題 3) である。保証しないのは、対応付けが正しいこと、台帳の文が正しいこと、学習が収束すること (既定の学習率では収束しない) である。

既定の学習率。実験 E3 から、処理系の既定値 0.5 は、同じ分布を繰り返し与える用途には使えるが、標本から学ぶ用途には向かないことがわかった。標本から学ぶ場合は 1/(t+1) を明示的に渡すべきである。既定値そのものは変更していない。

量子という語。Bada の量子演算は古典計算機上の計算であり、量子計算機を駆動しない。位相コアのゲートは確率ベクトルと対角位相を扱い、干渉を表さない。本稿の結果はすべて古典的な確率の計算である。

評価の規模。生成の評価は依頼文 1 件である。実験 E2 と E3 は語彙 8 の小さな設定であり、実際の言語モデルの語彙での挙動は測っていない。

9. 結論

未知事前エンジンは、一様分布から始まり、追記専用の台帳に証拠を積み、位相コアで情報源を重ねる推論の核である。除外の不可逆性と、無知が零にならないことが、初等的な定理として成り立つ。BadaGPT電信の五段のパイプラインをこのエンジンの上で動かすと、ひな形によらずに、依頼文から章と文を選ぶことができた。

同時に、三つの限界が数値として現れた。位相は分布を変えないので、位相コアだけでは情報源の内容は出力に届かない。既定の学習率は標本からの学習に向かず、エントロピーは単調に減らない。網羅率 100% のもとで、4 節のうち 1 節は誤って対応付けられていた。未解釈の節と対応表を捨てずに残すという Telegraph の設計は、ここでも誤りを見つける手段として働いた。
