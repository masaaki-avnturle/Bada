# ゼータ・シャノン言語エンジン（Bada 製）

**シャノンの公式をゼータ関数に利用した言語化**を、量子プログラミング言語 Bada
（`../bada_gui_ide` の Unknown-Prior Engine 方言）で実装したものです。
質問に対して台帳の事実を根拠つきで答え、会話から学習し、文章を生成します。

エンジン本体 `zeta_shannon.bada` は純 Bada です。複素数演算、リーマンゼータ、
ナッシュ・シャノンゼータ、ジップ＝ゼータ則、検索索引、n-gram 生成器、干渉する量子レジスタ
を Bada 自身で書いています。処理系のネイティブ機能は `softmax` `cognitive_system`
`update` `unknown_prior`（位相コア）と文字列プリミティブだけを使います。

## 実行

```sh
node ../bada_gui_ide/cli/bada-cli.js run zeta_shannon.bada   # 認証 13 項目 + デモ
node chat.js                                                  # 対話
./test.sh                                                     # テスト一式
```

対話ドライバ `chat.js` は入出力だけを担当し、1 行を Bada の文に変換して評価します。

| 入力 | Bada の文 | 動作 |
|:--|:--|:--|
| ふつうの文 | `Ask "…"` | 台帳から根拠を選んで答える |
| `/learn 文` | `Learn "…"` | 事実を台帳に追記（次の質問から使える） |
| `/speak 書き出し` | `Speak "…"` | 文章を生成 |
| `/zeta σ t` | `zeta(σ, t)` | ζ(σ+it) と ζ_NS(σ+it) を計算 |
| `/trace on\|off` | — | 標識・確信度・エントロピーの表示切替 |

`Ask` `Learn` `Speak` は `@reviser : grammar` が台帳に commit した構文です。

```
問: リーマン予想は証明されましたか
答: リーマン予想は未解決である。論文集でも、証明できたことと証明できていないことを分けて記している。
    [標識 未解決 | 出典 リーマン予想 | 確信度 0.92 | H = 0.53 bit | Grover P = 0.996]
問: 明日の株価はどうなりますか
答: わかりません。その質問に答える証拠が台帳にありません。Learn 文で事実を教えてください。
```

## シャノンの公式をゼータ関数に使う 3 か所

1. **ナッシュ・シャノンゼータ** `ζ_NS(s) = ζ(s)·exp(iβH(Re s))`
   素数ゲームの均衡分布 `q_k = p_k^(-σ)/Z(σ)` のシャノンエントロピー
   `H(σ) = −Σ q_k log q_k` を位相に載せます。絶対値 1 の因子なので零点と `|ζ|` は厳密に保存されます。
2. **ジップ＝ゼータ則による単語の重み** `P(r) = r^(-s)/Z_V(s)`
   台帳の語彙に指数 `s` を最尤法で当てはめ、順位 `r` のトークンの自己情報量
   `I(r) = s·log r + log Z_V(s)` の、最頻トークンに対する超過分 `I(r) − I(1) = s·log r`
   を検索の重みにします。これが「言語化」の中身です。
3. **生成のナッシュ温度** `w_k = count_k · p_k^(-σ)`
   順位 `k` の続きの候補に素数ゲームの均衡重みを掛けます。非零因子なので、
   一度も現れなかった続きは確率 0 のままです（零の保存）。

## 答えが出るまで

```
質問 → トークン化（ASCII 単語 + 全角文字のバイグラム）
     → ゼータ則の自己情報量で重み付けしたコサイン → ロジット z
       （証拠を 1 つも共有しない事実は −800 = 確実な零）
     → a = softmax(z)
     → 位相コア cognitive_system(a, [ナッシュ・シャノン位相, 会話の信念], β)
       |ψ|² = a が成り立ち、零は復活しない
     → 会話の信念（話題の事前分布）との積 → 事後分布 r
     → 被覆率が閾値未満なら「わかりません」
     → グローバー探索で選んだ根拠を増幅（量子レジスタのシミュレーション）
     → 標識と出典を付けて出力、@reviser が信念を更新（エントロピー減少）
```

## 正直な範囲

- **ChatGPT の水準ではありません。** 「ChatGPT の version 10 レベル」は、数千億パラメータを
  大規模データで学習した言語モデルの水準を指しますが、ソースコードだけでそこに届く方法は
  ありません。これは約 75 個の事実を持つ、小さく監査可能な検索応答エンジンです。
  台帳にない話題には「わかりません」と答えます。
- **生成は文字 4-gram です。** コーパスが小さいので、`Speak` の出力は台帳の文の断片を
  つないだものになります。新しい内容を作り出す能力はなく、つなぎ方によっては
  事実と違う文になります（`Speak` の出力には標識が付きません。根拠つきの答えは `Ask` だけです）。
- **量子計算機では動きません。** 量子レジスタとグローバー探索は古典計算機上の
  シミュレーションです。オラクルは位相コアが選んだ根拠に印を付けるので、
  探索は答えを決めておらず、増幅を示しているだけです。
- **位相は答えを変えません。** `|ψ|² = a` なので、ナッシュ・シャノン位相は記録されますが
  確率には現れません（論文集 第VI部 6.1 の指摘どおり）。順位を決めているのは
  ゼータ則の重みと会話の信念です。
- **リーマン予想について何も証明しません。** Z2〜Z5 は既知の事実の数値再現です。
- **日本語の扱いは簡易です。** 形態素解析はせず、文字バイグラムとひらがなの減衰係数で
  代用しています。言い換えや否定の理解はできません。
- **ネイティブコンパイルは未対応です。** `bada-cli build` はこのプログラムの配列・文字列
  操作を C に落とせず、空の実行ファイルになります。インタープリタで実行してください
  （約 1,200 万ステップ、既定の上限 2,000 万の範囲内、1 秒未満）。
