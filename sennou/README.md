## 🎼 できた主題 (ニ短調 · 62 bpm · 和声ループ i – VI – III – V = Dm – B♭ – F – A)

| 小節 | 役割 | 和音 | 旋律 |
|:--:|:--|:--:|:--|
| 1–2 | **A** フック | Dm → B♭ | D5 A4 **B♭4 A4** — A4 ‖ B♭4 D5 |
| 3–4 | **A'** 2 度下の反復進行 | F → A | C5 G4 **A4 G4** — G4 ‖ A4 **C♯5** (導音) |
| 5–6 | **A** 完全反復 | Dm → B♭ | D5 A4 B♭4 A4 — A4 ‖ B♭4 D5 |
| 7–8 | **B** 頂点 → 開いた終止 | F → A | A4 B♭4 A4 B♭4 **F5** ‖ **E5** (属音の上で止まる) |

- フックは「4 度下がって、上から**ため息のように半音で降りる** (B♭→A)」形。手本区間で最も多かった音型 (隣の音へ行って戻る) から来ています。
- **頂点 F5 は 7 小節目** — 全体の約 7 割の位置 (黄金分割) にひとつだけ。
- **最後は主音に戻らず、属和音 (A) の上で開いたまま止まる**。和声ループ (Dm → B♭ → F → A) の最後 A → 最初 Dm は強い引力の解決なので、耳の中で**頭に戻り続ける** — これが「洗脳」の仕掛けです。曲の本当の終わり (Coda) でだけ主和音に解決します。

## 🧭 「エントロピーではなく、音符の流れのきれいさ」で選ぶ

主題はエントロピー (情報量・意外性) を一切使わず、作曲法の規則だけでできた **flow beauty (流れのきれいさ)** の点数が最大になるものを、ビームサーチ + 総当たりで選びました。

| 規則 | 意味 | 主題の点 |
|:--|:--|--:|
| 順次進行 | 隣の音への進行が約 7 割 | −0.11 |
| 跳躍の解決 | 跳躍の後は反対方向へ順次 (gap-fill) | +1.25 |
| 不協和な跳躍 | 三全音・7 度・オクターブ超えを避ける | 0 |
| 同音 / 往復の停滞 | 同じ音の連打、a-b-a-b-a の揺れ続けを避ける | −0.75 |
| 頂点の一意性 / 黄金比の頂点 | 山はひとつ、全体の 6〜7 割の所。頂点で終わらない | +0.80 / +0.48 |
| 音域 / 歌う音域 | 9〜14 半音、主音の上 5〜6 度を中心に | +1.00 / −0.38 |
| 強拍の和声音 / 非和声音の解決 | 強拍は和音の音、非和声音は経過音・刺繍音として順次で | +1.41 / −1.40 |
| 導音の解決 | 導音 (C♯) → 主音 (D) | +0.50 |
| 終止 | ループ最後の和音の音で、長く、順次で止まる | +1.80 |
| 運動エネルギー / 曲率 | 跳躍の二乗和・音程の変化が小さい = 曲線が滑らか | −2.69 / −2.82 |
| 手本の語彙 | 手本区間 (2:30–3:00) の旋律に出る音程 3 連と一致 | +1.06 |

## 🔁 「洗脳的」に決めた伴奏と形式

- **和声ループ**: 4 つの和音を、全曲で一度も止めずに回し続けます。候補 (4 和音の全組合せ) を、手本区間の和音の進み方への一致、声部進行の滑らかさ、**最後 → 最初が吸い込まれる引力** (V→i など)、4 つとも違う和音であること、で採点して選びました。
- **オスティナート**: 1 小節の伴奏型を 6 候補 (分散和音の波 / アルベルティ / ミニマル反復 / 振り子 / 下降の滝 / 拍の脈動) から、「旋律が伸ばす所で伴奏が動いて流れが途切れない」「旋律と音域がぶつからない」「伴奏自身が滑らか」「少ない要素の反復」で採点 → **分散和音の波** (根音 → 3 声を上って下りる 8 分音符) が選ばれ、全 48 小節で同じ形が回ります。和音の転回は、ループ 1 周の声部の動きが最小になるように選んでいます。
- **形式** (A A' A B の主題を何度も聴かせる):

| 小節 | 部分 | 内容 |
|:--|:--|:--|
| 1 | Intro | 伴奏の循環だけが始まる |
| 5 | A1 | 主題 (ピアノ) |
| 13 | A2 | 弦のパッドと低音が加わる |
| 21 | **Hook** | **フック 2 小節だけを 4 回** (原形 → 反復進行 → 原形 → 反復進行)、チェレスタが 1 オクターブ上で影のように重なる |
| 29 | A3 | 頂点 — 主題をオクターブ重ね、弦が 3 度下の対旋律、合唱 |
| 37 | A4 | 静けさへ |
| 45 | Coda | フックがもう一度だけ遠くで鳴り、主和音で終わる |

- 録音そのもの (各曲の 2:30–3:00) も、目標の調へ移調し 2 倍に引き延ばした深い残響の「記憶」として、−17 dB で薄く敷いています。

## 🚀 使い方

```
pip install numpy scipy librosa mido pillow
sudo apt install fluidsynth fluid-soundfont-gm      # 無ければ内蔵の加算合成で鳴らす
python3 sennou/make_sennou.py a.mp3 b.mp4 ... -o sennou/sennou.mp4 --each sennou/each
```

| オプション | 意味 |
|:--|:--|
| `-o FILE` | 出力 MP4 (同名の `.mid` `.json` も書き出す) |
| `--each DIR` | 入力 1 本ずつの作り換え (MP3 + MIDI + JSON) |
| `--no-video` | MP4 の代わりに MP3 |
| `--size` / `--fps` / `--crf` / `--title` | 映像の設定 |

残響の乱数は seed 固定で、同じ入力からは必ず同じ曲になります。素材の録音そのものはリポジトリに含めていません。解析・残響・タイトルカードは [`requiem/make_requiem.py`](../requiem/make_requiem.py) の関数を再利用しています。
