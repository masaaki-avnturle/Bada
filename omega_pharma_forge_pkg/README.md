# Omega Pharma-Forge

**擬似量子コンピュータで触媒投与を制御する、自己触媒連鎖の反応速度論シミュレーション**

前駆体に触媒剤を投与し、分解 → 自己触媒的な連鎖反応を経て目的化合物へ変換する
過程を、質量作用則の常微分方程式系（RK4 積分）として抽象化したアプリケーションです。
本リポジトリの `omega_mobius_drive_pkg`（ノイマン型 擬似量子VM）を判断核として
再利用し、連鎖が臨界を超えないよう触媒の投与量を逐次制御します。

## ⚠️ 正直な位置づけ（最重要）

- **このシミュレーションから実際の医薬品・化合物を作ることはできません。**
  実在の試薬名・合成手順・反応条件・分離精製法は一切含まれていません。
- 化学種 P/C/I/A/B は**抽象的な記号**であり、速度定数はすべて説明用の無次元
  パラメータです。特定の実在化合物をモデル化したものではありません。
- 出力される「収率」「純度」は**モデル上の化学量**であり、**薬効・安全性・
  降圧作用を示すものではありません**。薬理活性は分子構造と生体内の作用機序で
  決まり、本モデルはそれを一切扱いません。
- 実際の医薬品開発には有機合成・構造決定・薬理評価・毒性試験・臨床試験・
  規制当局の承認が必要です。**医薬品を自作・自己投与しないでください。**

その上で本パッケージは、**反応速度論と連鎖反応制御の教材**として、実在する
化学的トレードオフを正しく再現します（下記）。

## モデル

```
(1) P + C     --k1-->  I + C       触媒による分解開始（触媒は再生）
(2) P + I + C --k2-->  2I + C      触媒媒介の自己触媒的連鎖成長 ← 臨界性の源
(3) I         --k3-->  A           目的化合物への変換（1次）
(4) 2I        --k4-->  2B          二分子停止・過分解（2次）
(5) A         --k5-->  B           目的物の緩やかな分解
(6) C         --k6-->  C_dead      触媒失活
```

**連鎖係数（臨界指標）**

```
χ = k2·P·C / (k3 + 2·k4·I)
```

χ > 1 で連鎖は自己増殖的に成長（暴走）、χ < 1 で減衰します。連鎖成長段が触媒 C を
要するため、**投与量が臨界性の直接の制御レバー**になります（C=0 なら χ=0）。

**選択性 vs 速度の実在するトレードオフ**

目的物は 1次 (k3·I)、副生成物は 2次 (2·k4·I²) で生成されるため

```
A への選択性 = k3 / (k3 + 2·k4·I)
```

すなわち**中間体 I を低く保つほど純度が上がる**が、I が低いと反応が遅く時間内に
終わらず収率が落ちます。χ の目標値を絞ることが I を抑えることに相当し、
**内点に最適値**が現れます（実測結果は下表）。

## 実行結果（既定パラメータ, 3000ステップ）

| 条件 | 収率 | 純度 | 最大 I | 最大 χ |
|:--|--:|--:|--:|--:|
| 制御あり χ*=0.80 | 0.4029 | 0.4070 | 0.1740 | 0.979 |
| 制御あり χ*=0.50 | 0.5105 | 0.5220 | 0.0771 | 0.681 |
| **制御あり χ\*=0.30（最適）** | **0.5174** | **0.6542** | 0.0352 | 0.483 |
| 制御あり χ*=0.20 | 0.3479 | 0.6859 | 0.0235 | 0.382 |
| **制御なし（触媒一括投与）** | 0.3186 | 0.3207 | 0.2848 | 5.14 |

制御なしでは χ≫1 で連鎖が暴走し中間体が高濃度になるため、2次の過分解が優位に
なって純度・収率とも制御ありに劣ります。質量保存は機械精度（~1e-16）で成立します。

## 温度結合反応器（v0.2 で追加）

等温モデルに **温度** を導入した `thermal_reactor.py` を同梱しています。実際の
反応器で最も危険なのは、発熱が温度を上げ、温度が Arrhenius 則で反応を速め、
それがさらに発熱を増やす **熱暴走（thermal runaway）** です。

```
k(T) = k_ref · exp[ −(Ea/R)·(1/T − 1/T_ref) ]          Arrhenius 則
ρCp·V·dT/dt = Σ(−ΔH)·r − U·A·(T − T_jacket)           熱収支
```

暴走判定には **Semenov 条件** を使います。発熱曲線の傾きが除熱直線の傾きを
上回った時点（`d(発熱)/dT > d(除熱)/dT`）で安定点が失われます。
コントローラは触媒投与（χ 制御）と冷却ジャケット温度の 2 系統で制御します。

| 条件 | 収率 | 純度 | 最高温度 | Semenov |
|:--|--:|--:|--:|:--|
| **制御あり** | **0.4372** | **0.6571** | 300.0 K | 常に安定 ✓ |
| 制御なし（一括投与・冷却固定） | 0.3030 | 0.3032 | 357.0 K | 暴走 ✗ |

## インストール

```bash
cd omega_mobius_drive_pkg && pip install -e .
cd ../omega_pharma_forge_pkg && pip install -e .
```

依存は `omega-mobius-drive` のみ（外部ライブラリゼロ）。Python 3.8+。

## 使い方

```bash
omega-pharma-forge 3000        # 4シナリオ（制御あり / χスイープ / 制御なし / 熱暴走）
```

```python
from omega_pharma_forge import QuantumSynthesizer, DosingConfig

s = QuantumSynthesizer(cfg=DosingConfig(chi_target=0.30, steps=3000), seed=0xBADA)
s.run()
print(s.report())
```
