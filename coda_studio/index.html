◫ スペクトル・コード・シーケンサー — 音符を使わない作曲

段階 1 — 深部 (ルート + 5度) 段階 2 — 中域 (基本ヴォイシング) 段階 3 — 上音 (テンション全開) 段階 4 — 輝き (オクターブ重ね)
行はコード記号、列は時間。マス目をタップするたびにスペクトル段階が 1 → 2 → 3 → 4 → 消 と深まり、 和音の倍音構成が厚くなります。▶ 演奏で縦線が移動し、通過したコードが鳴ります。音符は一切表示されません。

▁▃▅▇ リアルタイム・スペクトラム — いま鳴っている音の姿

演奏中の周波数スペクトルを多段階の色 (深部 → 中域 → 上音 → 輝き) で表示します。

🎹 鍵盤 — 即興用 (表示はコードとスペクトルのみ)

PCキーボードでも演奏できます: A W S E D F T G Y H U J K O L P ; (Zで1オクターブ下げ / Xで上げ)

🎼 コードパッド — 静寂のためのヴォイシング

押さえるだけで、映画音楽のような柔らかな和声が鳴ります。長押しで伸ばせます。

💾 書き出し — ループを WAV で保存

シーケンサーの内容をリバーブ・ディレイ込みで 44.1kHz / 16bit ステレオ WAV にレンダリングします。

📖 このアプリについて

Coda Studio は、音楽家・坂本龍一(1952–2023)の音楽性 — ピアノの一音、静寂、アンビエンス、 ミニマリズム — へのオマージュとして制作されたオリジナルの音楽制作アプリです。 音符を表示しないスペクトル・コード・シーケンサーを採用: 行はコード記号、 マス目の色は 4 段階のスペクトル(倍音の厚み)、縦線の移動が演奏です。 依存ライブラリゼロ・単一 HTML・完全オフライン動作。音はすべて Web Audio API による リアルタイム・シンセシスで、サンプル素材を一切含みません。
