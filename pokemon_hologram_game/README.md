# 式獣ホログラム — ポケットモンスター物語
### Shikijuu Hologram — a Pokémon-style holographic AR battle game in **Bada** (Omega dialect)

目の前の**実風景をデバイスで透過**し、その風景に宿る**式獣（＝ポケットモンスター型のマスコットキャラクター）**を、
**内蔵＋外部の 2 系統ホログラフィーディスプレイ**へ空中結像させる。
デバイス内蔵の**平行感覚センサ（傾き）**にマスコットが連動して動き、ポケットモンスターの**物語のストーリーに沿った戦い**を進める――という Bada 言語製のゲームソフトです。

> 実装言語は本リポジトリの **Bada 言語（Omega 方言 / `.om`）**。`class`・`def`・`:=`・`import Omega::DATABASE`・
> 多様体演算子・アカシックレコード（TupleSpace）といった Bada の語彙で全体を記述しています。

---

## 🎮 ゲームの流れ

1. **起動** — 内蔵ディスプレイと（あれば）外部ディスプレイを立ち上げ、平行感覚センサをゼロ点校正。
2. **風景を透過** — 背面カメラ／光学シースルーで目の前の風景を取り込む。
3. **情景を認識** — 森・水辺・山・街・空・火山・草原・雪原・夜闇 のどれかを π-softmax で推定。
4. **式獣を召喚** — その風景に宿る式獣を**アカシックレコード（`Omega::DATABASE`）**から呼び出し、
   **コースティクス（光の集光模様）**で空中に結像。
5. **傾きに連動** — デバイスを傾けると、式獣マスコットが視差つきで一緒に傾き・揺れる。
6. **バトル** — ポケモン準拠のターン制バトル。端末を**水平に保つと命中↑**、**振ると必殺ゲージが溜まる**。
7. **物語** — 全 5 章（森 → 水辺 → 山 → 街 → 火山の宿敵戦）を進めてクリア。

## 🔬 アップロード資料との対応

このゲームは、同梱の研究 PDF の概念を Bada のゲーム機構へ写像しています。

- **`hologramdisplay.pdf`** → `hologram_display.om`。
  内蔵は導波路（waveguide）越しの**光学シースルー**、外部は空中結像／体積ディスプレイへの**光線場ストリーミング**として二系統化。
- **`caostics.pdf`（コースティクス）** → `caustics_field.om`。
  「光が一点に集まって明線を描く」集光模様を式獣の像として使用。強度は `I = |∂²Φ/∂x²|⁻¹` を π-softmax で安定化。
- **量子・Ω 系（`quantum_computer4.pdf` / `QuantumBada_source.pdf` / `badaquantumreviserpaper.pdf` / `badasource1.pdf`）**
  → `Omega::DATABASE`（アカシックレコード＝TupleSpace）による**式獣図鑑・召喚・セーブ**、および `ℏ_eff` を用いた
  **π-softmax**（情景認識・集光カーネル）に反映。

## 🕹 操作と平行感覚（傾き）連動

- **探索中** — 端末を傾けると式獣が同じ向きへ傾き、視差でスライドする（`applyToPose`）。前傾で手前、後傾で奥へ。
- **バトル中**
  - 端末を**水平**に保つほど照準が定まり **命中補正↑**（`aimBonus`）。
  - 端末を**振る**と `charge`（必殺ゲージ）が溜まり、次の一撃が強化される（`isShaken`）。
  - わざ選択カーソルは左右の傾き `roll` で移動（`selectByTilt`）。
