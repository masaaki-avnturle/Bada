    Claude API
    
    
    API キーを入れると Claude が本格的なコードを生成します。空欄のときは端末内の簡易生成 (オフライン) になります。キーは この端末の中だけに保存され、api.anthropic.com 以外へは送りません。
    
    
    
    
    
      
    
      
    
        
    
    
    
    
  
    
  
    
    
    GitHub (APK / EXE の自動ビルド)
    
    
    生成したプロジェクトを自分のリポジトリにプッシュすると、同梱の GitHub Actions が APK と Windows EXE をビルドし、Releases (<名前>-latest) に添付します。
    トークンは Fine-grained token で対象リポジトリに Contents: Read and write と Workflows: Read and write を付けてください。
    
    
    
      
    
      
    
    
    
    
    
    
  
    

    


    
  
    
    
    このアプリでできること・できないこと
    
    
      
      
    • できること: 文章・音声・スケッチ・写真で伝えたイメージを Claude (または端末内の簡易生成) がコードに変換し、Android APK / Windows 10・11 EXE 用プロジェクト、PDF 文書、任意言語のソースコードとして出力します。GitHub にプッシュすれば APK と EXE が自動でビルドされます。
      • 
      
    • できること: カメラ (指先の脈波) とマイク (呼吸音) で心拍・心拍変動・呼吸数を測り、音とガンマ関数の模様で返すバイオフィードバック。
      • 
      
    • できないこと: 頭の中の思考を直接読み取ること (Neuralink の Telepathy は脳に埋め込む電極が必要です)、アカシックレコードへのアクセスや未来予知、体内・脳内の熱の流れの観測。心拍・呼吸は身体の状態であって思考の内容ではありません。
      • 
      
    • 医療機器ではありません。測定値は目安です。
