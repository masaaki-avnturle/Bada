# Omega Breath

**呼吸ガイドと、心拍変動（RSA）・圧受容器反射の共鳴シミュレータ**

薬に頼らずに「ほっと一息つく」ための、実行できる呼吸ガイドと、
なぜその呼吸が効くのかを数値で確かめられる生理学シミュレータです。

## 背景の生理学

息を吸うと心拍が速まり、吐くと遅くなります。これを **呼吸性洞性不整脈 (RSA)** と
いい、迷走神経を介した実在の現象です。さらに、血圧を一定に保つ
**圧受容器反射 (baroreflex)** のループには約5秒の遅れがあるため、系全体が
**約0.1 Hz（毎分6回）に共鳴周波数**を持ちます。

本パッケージはこの反射ループを2次の減衰共振系としてモデル化します。

```
x'' + 2ζω₀x' + ω₀²x = ω₀²·u(t)      u: 呼吸駆動, ω₀ = 2π·0.1 rad/s
```

呼吸の回数を振ってRSA振幅を測ると、**毎分5.7回付近に共鳴の山**が現れます
（減衰振動子の共鳴が ω₀√(1−2ζ²) にずれる、教科書どおりの結果）。
コヒーレント呼吸が毎分6回に設定されている理由がここにあります。

```
  15.00回/分 |███                               |  0.92
   8.57回/分 |████████████                      |  4.00
   6.00回/分 |█████████████████████████████████ | 11.04   ← 最大
   4.62回/分 |████████████████████████████      |  9.27
   3.16回/分 |███████████████████               |  6.45
```

## 収録パターン

| キー | 名前 | 配分 | 回/分 |
|:--|:--|:--|--:|
| `slow` | ゆっくり呼吸 | 吸4 / 吐6 | 6.0 |
| `coherent` | コヒーレント呼吸 | 吸5 / 吐5 | 6.0 |
| `box` | ボックス呼吸 | 4 / 4 / 4 / 4 | 3.8 |
| `478` | 4-7-8呼吸 | 吸4 / 止7 / 吐8 | 3.2 |

## インストール

```bash
cd omega_breath_pkg && pip install -e .
```

依存ライブラリはゼロ。Python 3.8+。

## 使い方

```bash
omega-breath                 # ゆっくり呼吸を4回、画面に合わせて呼吸する
omega-breath coherent 6      # コヒーレント呼吸を6回
omega-breath --sim           # 共鳴曲線とパターン別の心拍変動を表示
omega-breath --list          # パターン一覧
```

画面にバーが伸縮し、「すーっと吸って」「ゆーっくり吐いて」と案内が出ます。
途中でやめたくなったら Ctrl-C でいつでも止められます。

```python
from omega_breath import RSASimulator, get
print(RSASimulator().metrics(get("coherent")))
```

## ⚠️ 注意

- 一般的な健康法の紹介であり、**医療行為・治療の代替ではありません**。
- 計算される心拍変動は**モデル上の数値**で、実測でも診断でもありません。
- 息苦しさやめまいを感じたら、すぐに中止して普段どおりの呼吸に戻してください。
  特に 4-7-8 のような息止めを含むパターンは、つらければ半分の長さから。
- 持病がある場合は主治医にご相談ください。
