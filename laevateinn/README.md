# ⚔ Laevateinn — 自動走行の自動車アシスタントAI「アル」

**レーヴァテイン**は自動走行の自動車、**アル (Al)** はそのアシスタントAIです。
これまでの集大成スタック(BadaGPT 系の意図エンジン・self-attention トランスフォーマー・
zone:// 系 AEAD 暗号)を車載システムとして一つにまとめ、依存ゼロの
**単一 HTML** (`index.html`) に収めました。

## ⬇️ ダウンロード

| 方法 | 手順 |
|:---|:---|
| **一番かんたん** | [`index.html`](index.html) を開き **「Download raw file」(⬇)** → 保存したファイルをダブルクリック(インストール不要・オフライン可) |
| **Android APK** | [Releases](https://github.com/masaaki-avnturle/Bada/releases) から `laevateinn-al-debug.apk` |
| **Windows 10/11** | Releases から `Laevateinn-*-x64.exe`(NSIS インストーラ / ポータブル) |
| **Ubuntu** | Releases から `Laevateinn-*-x86_64.AppImage` / `Laevateinn-*-amd64.deb` |

ネイティブ版は [`laevateinn-app-build.yml`](../.github/workflows/laevateinn-app-build.yml) がビルドします
(`laevateinn-v*` タグを push するか、Actions の `workflow_dispatch` で `release_tag` を指定)。

## システム構成

| サブシステム | 内容 |
|:---|:---|
| **アル (Al)** | BadaGPT 系の意図エンジンによるアシスタント。走行実況(障害物・停止・再発進・到着・タイル受信)+ 会話(「状態」「地図」「停止」「発進」「衛星」「ウェブ」)。会話から走行・モードを実際に制御 |
| **トランスフォーマー知覚** | 16 本のレイセンサをトークン化し、16 次元 QK 内積 + 近接バイアス → softmax の **attention** で脅威に注意を集中。`threat = Σ wᵢ·closenessᵢ`。前方に注意が集中すると自動減速→停止、クリアで再発進。attention はバーで可視化 |
| **🌐 Web地図モード(衛星不使用)** | 地図は**ウェブサイトから受信するタイル**(9 枚)。各タイルは zone:// 系 LCG キーストリーム AEAD の封筒で届き、**タグ検証に通ったものだけ描画**(改ざんタイルは拒否)。測位は**推測航法**(オドメトリ積分・ドリフトあり)+**ランドマーク交差点で地図座標に吸着** |
| **🛰 人工衛星モード** | 4 機の衛星 (LVT-1〜4) の擬似距離から**ガウス・ニュートン最小二乗**でトリラテレーション測位。地図タイルも衛星ブロードキャストとして受信 |
| **経路計画** | 道路網 (12×9) 上の **A\***。地図をクリックで目的地設定 → 自動走行 |

## 使い方

1. 起動するとアルが挨拶し、地図タイルの受信が始まります(受信・検証済みの区画から地図が見えてきます)
2. 道路セルをクリック → A* が経路を計画
3. **▶ 自動走行 開始** — 障害物(車・歩行者)が現れると、アルのトランスフォーマーが前方に注意を集中して減速・停止し、クリアになると再発進します
4. 上部の **🌐 Web地図 / 🛰 人工衛星** で測位モードを切替(アルに「衛星」「ウェブ」と話しても切替可)

## テスト

```
node laevateinn/tools/engine-test.js
```

A* の連結性・attention の softmax 正規化と前方集中・推測航法のドリフトとランドマーク吸着・
トリラテレーションの収束・タイル AEAD の往復と改ざん拒否・アルの応答など
19 項目を検証します(CI の `test-core` ジョブでも実行)。

---

⚠️ Laevateinn は**シミュレーション**です。地図受信・衛星測位・走行はすべてアプリ内で
模擬され、実車・実センサー・実衛星には接続しません。実際の運転支援には使えません。
