# Ω-MorphoForge — 形態形成場 × 電磁ドリフト × カタストロフ分岐

**円形容器（コイル境界）の中で反応拡散パターンを電磁ドリフトで操作し、
Waddington 地形のカタストロフ分岐で「分化した細胞」を可視化する概念シミュレーション**

APK（Android）・EXE（Windows）・ブラウザ（`index.html` を開くだけ）で動きます。
依存ライブラリはゼロ。オフラインで完結します。

```
[ 電磁コイル ]─┐         ┌─→ Gray-Scott 反応拡散: 種 → 分裂 → 分岐
 (Ex, Ey)   ─┼─→ 移流 ─┤
             │         └─→ カタストロフ地形 U(φ)=¼φ⁴−½aφ²−bφ
             │              「未分化 → 分化」の局所スイッチ (尖点分岐)
   円形容器 (mask) ────────→ 内部だけを更新し、境界で折り返す
```

## 何を見せているか

1. **形態形成場**: Gray-Scott 反応拡散系。(F, k) = (0.030, 0.0565) 付近では
   置いた種が自発的に分裂し、複数の「細胞」パターンへ**分岐**します。
2. **電磁誘導ドリフト**: 外部場 (Ex, Ey) がパターンを場の方向へ流します。
   「反重力（逆流電磁）モード」で符号が反転し、逆向きに流れます。
3. **カタストロフ分岐（発生生物学の Waddington 地形）**:
   各格子点で分化度 φ が地形 `U(φ) = ¼φ⁴ − ½aφ² − bφ` を降る力学を解きます。
   `a` を上げると 1 つのくぼみが 2 つに割れる**尖点カタストロフ**が起き、
   活性因子の局所濃度に応じて未分化(φ<0)→分化(φ>0.5、緑)へスイッチします。
   これは Thom / Zeeman が発生生物学に応用したカタストロフ理論の教科書事例です。
4. **円形コイル容器**: 境界を円形にした固定境界。コイル巻線を金線で描画。

## ⚠️ 正直な位置づけ（最重要）

- 実在の iPS 細胞樹立プロトコル（Yamanaka 因子・培地・タイムコース等）は
  一切含まれておらず、本アプリから実際の細胞や医薬品を作ることはできません。
- 「薬の製造」に相当する出力（成分・組成・用量）はありません。
- 反重力・反重力発生器は現実には存在しません。「反重力（逆流電磁）モード」は
  外部場ドリフトの符号反転をそう呼んだだけの UI ラベルで、実際に重力を打ち消す
  ものではありません。
- カタストロフ理論の分岐は本物ですが、iPS 化のスイッチをこの単純な尖点分岐で
  完全に説明できるわけではありません。教育・アート用の抽象モデルです。

## 使い方（Android / Windows / ブラウザ）

**APK**: GitHub Actions のワークフロー `Ω apps build (APK + Windows EXE)` を
`workflow_dispatch` で走らせ、Artifacts から `omega_morpho_forge-android` を
ダウンロードしてインストールしてください。`apps-v*` タグを push すれば
Release にも自動添付されます。

**Windows EXE**: 同じワークフローで `omega_morpho_forge-windows` が
出力されます。ローカルで作るなら:
```bash
cd bio_medicine/omega_morpho_forge/electron
npm install && npm run dist
```

**ブラウザ**: `bio_medicine/omega_morpho_forge/www/index.html` をそのまま開きます。

## 操作

- ▶ 開始 / ⏸ 一時停止 / ↺ リセット
- `F`, `k`: 反応拡散パラメータ（分岐領域プリセットあり）
- `Ex`, `Ey`: 電磁ドリフト（＋方向・−方向）。「反重力（逆流電磁）モード」で反転
- `a`: カタストロフ地形の深さ（`a > 0.25` で 1 → 2 の分岐が起きる）
- `b`: 分岐のバイアス（正/負で分化先が偏る）
- 画面上のマップをタップするとその位置に活性因子の種を追加できる
- 「分岐プリセット」→ 分化ペア（緑の島）が出やすい設定
- 「停滞プリセット」→ 分化がなかなか起きない設定

## 画面の見方

- **左のマップ**: 青=基質 u、赤=活性因子 v、**緑=分化した細胞** (φ > 0.5)。
  金色の縁と巻線が円形コイル容器。
- **下の細長いグラフ**: Waddington 地形 `U(φ)` と、平均 φ を示す赤玉。
  a を大きくするとくぼみが割れ、赤玉がどちらかへ落ちる様子が見えます。
- **右のパネル**: 現在のパラメータと統計（細胞数・分化細胞の割合・重心）。
