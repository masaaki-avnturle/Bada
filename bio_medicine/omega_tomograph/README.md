# Ω-Tomograph — Γ大域的部分積分多様体 概念トモグラフ

`analyze/GammaFunction.pdf`（山口理論）の **ガンマ関数の大域的部分積分多様体**

```
∫ Γ(γ)′ dx_m = 2·e^{−x log x}      x^x = e^{x log x}      π(χ,x)=cosθ+i sinθ
```

を、医用画像（CT/MRI/X線）と統計照合（Whispered）の **実際の数学的原理** に結びつけて
可視化する、単一HTMLの概念実証アプリです。`index.html` をブラウザで開くだけで動作します
（依存ライブラリなし・オフライン可・GitHub Pages 対応）。

---

## ⚠ 重要 — 非医療・診断不可

本アプリは **概念実証・教育・可視化専用のシミュレータ** です。実在の人体を撮像しません。
実際のMRI/CT/X線は磁場・X線管・検出器など物理ハードウェアと検証済み物理を必要とします。
本アプリは **合成ファントム（数式モデル）** に対して計算を行うだけで、
**診断・医療・臨床判断には一切使用できません。**

---

## 3つの機能

| タブ | 内容 | 実装している実際の数学 | レポートとの対応 |
|:--|:--|:--|:--|
| ① Γ多様体トモグラフ | 脳/胸部断面を「熱エネルギー流」場としてCT風に再構成 | ラドン変換 → ランプフィルタ補正逆投影 (FBP) | Γ核 `e^{−x log x}` を基底核→末端の熱流重み `w=e^{−κ·d·log d}` として密度場に適用 |
| ② Γ X線投影 | 胸部/手部を肺X線写真風に投影 | Beer–Lambert 減弱則 `I=I₀·e^{−∫μ dℓ}`（前方ラドン変換） | 減弱係数を `e^{−x log x}` でエネルギー依存に重み付け |
| ③ Whispered 合致率 | MRI/fMRI/血液/CT/脳波/DNA ＋ ミラー統計 から個体一致率を % 算出 | コサイン類似度 ＋ 鏡映対称統計 | Whispered言語の個体署名を決定論的特徴ベクトルへ写像 |

### 「本物の数学」と「概念」の切り分け
- **本物**: ラドン変換、FBP（CT再構成の実体）、Beer–Lambert（X線濃淡の実体）、コサイン類似度。
- **概念**: Γ核を「熱エネルギー流」と解釈する意味づけ、Whispered／ミラー統計の医療的解釈は
  山口理論に基づく概念モデルであり、実在の医療計測ではありません。

## 使い方

```
# そのまま開く
xdg-open index.html       # Linux
open index.html           # macOS

# またはローカルサーバ
python3 -m http.server 8000   # → http://localhost:8000/
```

- **タブ①**: 断面・投影角数・Γ熱パラメータ κ を選び「スキャン実行」。原断面→サイノグラム→FBP再構成像が並びます。
- **タブ②**: 被写体・投影方向・線質を選び「撮影」。減弱マップとX線写真風フィルム像が出ます。
- **タブ③**: 個体A／参照Bの署名IDを入れ「測定」。総合合致率・モダリティ別バー・レーダーチャートを表示。
  同じ文字列なら 100%（自己同一）になります。
