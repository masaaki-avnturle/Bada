② コマンドで取得する

単一ファイルだけを取ってくる:

curl -LO https://raw.githubusercontent.com/masaaki-avnturle/Bada/HEAD/bio_medicine/omega_whispered/download/omega-whispered.html

HEAD はデフォルトブランチを指します。まだマージ前のブランチから取得する場合は、 HEAD をブランチ名（例: claude/whispered-aptitude-test-app-kmkn64）に置き換えてください。

リポジトリごと取得して、このアプリだけを開く:

git clone https://github.com/masaaki-avnturle/Bada.git
cd Bada/bio_medicine/omega_whispered
xdg-open www/index.html        # macOS は open / Windows は start

アプリのフォルダだけを取得する（sparse checkout）:

git clone --filter=blob:none --sparse https://github.com/masaaki-avnturle/Bada.git
cd Bada
git sparse-checkout set bio_medicine/omega_whispered

単一ファイルを自分で再生成する（Node 18+ / 依存ゼロ）:

node bio_medicine/omega_whispered/build_single.js

⚠ 旧版が入っていて Android にインストールできないとき: 以前の版はビルドごとに異なる鍵で署名されていたため、上書きインストールが拒否されます （「アプリがインストールされていません」）。一度だけ旧版をアンインストールしてから 新しい APK を入れてください（adb uninstall io.github.masaaki_avnturle.omega_whispered）。 1.1.0 以降は固定鍵で署名されるため、以後はアンインストール不要で上書き更新できます。 Windows / Ubuntu 版は影響を受けず、そのまま更新できます。

Ubuntu — .deb でインストール:

sudo apt install ./Omega-Whispered-1.1.0-linux-amd64.deb
omega-whispered            # またはアプリ一覧から「Omega-Whispered」

sudo apt remove omega-whispered   # アンインストール

Ubuntu — AppImage（インストール不要）:

chmod +x Omega-Whispered-1.1.0-linux-x86_64.AppImage
./Omega-Whispered-1.1.0-linux-x86_64.AppImage

Ubuntu 22.04 / 24.04（x86_64）想定。.deb は /opt/Omega-Whispered にインストールされ、デスクトップエントリとアイコン（16〜512px）を登録します。 AppImage は FUSE が無い環境では --appimage-extract-and-run を付けて実行してください。

Actions からダウンロードする手順

  1. Actions →「Ω apps build」を開く
  2. 一覧から 緑のチェックが付いた実行をクリック（アプリを更新すると自動でビルドされます）
  3. 実行ページ上部の Summary に成果物の一覧と導入方法が表示されます
  4. ページ下部の Artifacts から omega_whispered-android / -windows / -linux / -download をダウンロード（ZIP で届きます）

Artifacts のダウンロードには GitHub へのログインが必要です（保持期間 90 日）。 ログイン不要で配布したい場合は、手動実行（Run workflow）で publish_release を有効にするか、 タグ apps-v* を push してください。Release の添付ファイルは誰でもダウンロードできます。

④ 動作条件

  • モダンブラウザ（Chrome / Edge / Firefox / Safari の最近のバージョン）
  • PDF の記号抽出には DecompressionStream を使用します。非対応環境では PDF 機能のみ無効化され、 検査そのものは PDF なしで動作します。
  • インストール・ビルド・サーバー・ネットワークはいずれも不要です。
  • スキャン画像だけの PDF・暗号化 PDF からは記号を抽出できません（その旨を画面に表示します）。
