検査の構成

第一次検査 — 記号適性: 数学論文の PDF に現れる方程式の記号(∫ ∂ ∇ ⊗ ⊢ 𝒪 𝔤 ℵ ⋆ など)について、 その意味・専門分野・文脈による意味の変化を識別します。 PDF を読み込んだ場合は、その論文から実際に抽出された記号が優先的に出題されます (フォント埋め込み・ToUnicode CMap を解析した本物の抽出です)。

第二次検査 — 方程式の意味解析: 方程式が何を主張しているのかを読み解きます。さらに 連想検査では、a²+b²=c² のような簡単な方程式が、専門分野で ds² = gᵢⱼdxⁱdxʲ のようにどう一般化されるかを対応づけます (簡単な方程式 → 専門分野の方程式への構造的連想)。

第三次検査 — 数学適性分野の診断: 正誤のない思考スタイル設問(無限の扱い方、同じとみなす基準、証明の好み、対称性を見たとき何をするか…) への回答から 志向を、第一次・第二次の分野別成績から 実力を測り、両者を合成して 解析学 / 微分幾何 / 位相幾何 / 代数・数論 / 代数幾何 / 圏論・論理 / 確率・統計 / 作用素環・関数解析 / 表現論・群論 / 数理物理 の 10 分野の適性をプロファイル化します。 上位分野には、思考の型・代表的な方程式と記号・隣接分野・次に学ぶとよい主題を提示します。

第四次検査 — 瞬読(フラッシュ): 速読法の瞬読に倣い、数学の専門用語(100 語)・記号・バラバラに分解した方程式のトークンを、 画面上のランダムな位置・角度・大きさで一瞬だけ一斉提示し、消えた直後に 「何が見えたか」「その用語の意味は」「どの方程式の断片か」「いくつ見えたか」を問います。 注視点 → 提示 → マスクの順で提示し、露出時間は 2-down/1-up ステアケースで適応的に上下させて 瞬読閾値(ms)を推定します。

薬学のウィスパードテスト: 出題系統を「薬学」にすると、薬物動態(PK) / 薬力学(PD) / 医薬品化学 / 製剤学 / 薬理学 / 毒性・安全性 / 生化学・分子標的 / 臨床薬学 の 8 分野になります。 記号（AUC · C_max · t½ · CL · V_d · F · EC50 · LD50 · TI · K_m · logP · TDM）、 関係式の意味、そして 簡単な問題 → 関係する専門の問題 への連想 （薬は時間とともに消える → C(t)=C₀e^(−k_e t)、 腎臓が悪いと薬が抜けにくい → CLcr による用量調節、 グレープフルーツで効きすぎる → CYP3A4 阻害）を検査します。

経済学のウィスパードテスト: 出題系統を「経済学」にすると、ミクロ / マクロ / 計量経済学 / 金融・ファイナンス / ゲーム理論 / 国際経済 / 行動経済学 / 公共経済・厚生 の 8 分野になります。 記号（GDP · CPI · MC · MR · PED · NPV · β_i · OLS · PPP · DWL）、関係式の意味、 そして 簡単な問題 → 関係する専門の問題 への連想 （安くすればたくさん売れる → PED=(ΔQ/Q)÷(ΔP/P)、 損は得より強く感じる → プロスペクト理論の価値関数、 卵を一つのかごに盛るな → CAPM）を検査します。

専門英語・造語のウィスパードテスト: 出題系統を「専門英語・造語」にすると、数学 / 化学 / 物理 / 薬学 / 経済 / 学術英語共通 の 7 系統の英語になります。学術表記（et al. · i.e. · cf. · iff · w.l.o.g. · in vitro / in vivo / in silico · ceteris paribus · API · RFC · POSIX · UTF-8）、 分野で意味が変わる多義語（field=体/場/分野、normal=法線/規定度/正常、 derivative=導関数/デリバティブ/誘導体）、そして 造語の成り立ち（photon = phōt-(光) + -on(粒子)、 bit = binary + digit、pixel = picture + element、 malware = malicious + software、cybernetics ← kybernētēs(舵取り)、 stagflation = stagnation + inflation、 isotope = isos(等しい) + topos(場所)、 eigenvalue = eigen(独: 固有の) + value）を検査します。 語根・接辞（-on · -ase · -ose · iso- · homo-/hetero- · -morph · -nomics · -ware · cyber- · meta-）も 出題され、他の系統の検査にも専門英語と造語の設問が混ざります。

情報科学のウィスパードテスト: 出題系統を「情報科学」にすると、アルゴリズム・計算量 / データ構造 / プログラミング言語・型理論 / OS・システム / ネットワーク / データベース / 機械学習・AI / 情報理論・暗号 の 8 分野になります。 記号（O(n) · Ω(n) · NP · Γ ⊢ e : τ · LRU · RTT · ACID · CAP · η · ∇_θL · H(X) · SHA-256）、関係式の意味、 そして 簡単な問題 → 関係する専門の問題 への連想 （辞書は真ん中を開いて探す → 二分探索 O(log n)、 よく使う物は手元に置く → キャッシュの実効アクセス時間、 山を下るときは最も急な方へ → θ ← θ − η∇_θL、 答え合わせは解くより簡単 → P ⊆ NP）を検査します。 kernel=OS 核/カーネル法、key=探索鍵/主キー/暗号鍵/Attention の Key のような文脈依存記号も出題します。

ロシア語・フランス語のウィスパードテスト: 出題系統を「ロシア語・フランス語」にすると、数学 / 物理学 / 化学 / 薬学 / 経済学 情報科学の専門用語を原語のまま検査します（露 6 分野 + 仏 6 分野）。 瞬読ではキリル文字・フランス語がそのまま提示されます。 用語（производная=導関数、сверхпроводимость=超伝導、 раствор=溶液、период полувыведения=半減期、 dérivée、liaison covalente、demi-vie、 taux de chômage、машинное обучение=機械学習、 ordinateur=計算機、logiciel=ソフトウェア、 octet=バイト）、論文の略号（ч.т.д. · и т.д. · ЛС · ВВП · ЭВМ · ОС · БД · ИИ / C.Q.F.D. · ssi · AMM · DCI · PIB · TVA · TIC · SGBD · IA · RGPD）、 空似言葉（expérience=実験/経験、рецепт=処方箋に対し recette=レシピ・収入、решение=解に対し раствор=溶液）、 露 ⇄ 仏 の対応も出題します。他の系統の検査にも、その分野に対応する ロシア語・フランス語の用語が混ざります。

化学・物理のウィスパードテスト: 出題系統を切り替えると、有機化合物・半導体・超電導を軸にした化学／物理の検査になります。 記号（–OH · C=O · E_g · E_F · T_c · Δ · λ_L · Φ₀）、関係式の意味、 そして 簡単な問題 → 関係する専門の問題 への連想 （V=IR → σ=q(nμ_n+pμ_p)、磁石が浮く → ∇²B=B/λ_L²、 温度を上げると反応が速い → k=Ae^(−Ea/RT)）を検査します。 PDF を読み込むと、その論文に出てきた化合物・専門用語・記号からも出題します。 検査中は電子音が鳴ります（出題・正誤・瞬読の注視点/提示/マスク）。
