# Ω-Whispered — ウィスパード適性検査（瞬読 × 数学記号 × 方程式の意味解析）

数学論文の **PDF に現れる方程式の記号**、**方程式が何を主張しているのか**、
**どの数学分野に適性があるか**、そして **瞬読（フラッシュ）でどこまで捉えられるか** を検査する
4 段構成の適性検査アプリです。依存ゼロ・ブラウザ／APK／EXE で動作し、
**PDF の解析はすべて端末内**で完結します（外部送信なし）。

---

## ⚠ 重要 — 非公式のファン・オマージュ / 学習・娯楽目的

- 「フルメタル・パニック!」の **ウィスパード** という設定に着想を得た二次的創作であり、
  **原作・アニメの権利者とは一切関係がありません**。
- 判定結果（Ω 値・クラス）は **学習と娯楽のための指標**です。
  実在の能力・適性・知能を測定または診断するものではありません。

## 検査の構成

### 第一次検査 — 記号適性
数学論文に現れる方程式の記号（`∫ ∮ ∂ ∇ ⊗ ⊕ ⊢ ⊨ ⋆ ℵ 𝒪 𝔤 𝔭 ℏ ℘ …`）について、

| 設問種別 | 内容 |
|:--|:--|
| 記号の意味 | その記号が数学で何を表すか |
| 記号の分野 | どの専門分野で特徴的に使われるか |
| 文脈依存記号 | **同じ記号が分野で意味を変える**（例: `π` = 円周率 / 基本群 π₁ / 表現 π / 素数計数関数 π(x)） |

**PDF を読み込むと、その論文から実際に抽出された記号が優先的に出題されます。**

### 第二次検査 — 方程式の意味解析
方程式が **何を主張しているのか** を読み解きます。

| 設問種別 | 内容 |
|:--|:--|
| 方程式の意味 | 式が主張している内容（紛らわしい近傍の誤答つき） |
| 方程式の同定 | 式の名称 |
| **連想（簡単 → 専門）** | 簡単な方程式の構造が、専門分野でどう一般化されるか |
| 連想（専門 → 簡単） | 専門分野の方程式の原型にあたる基本式はどれか |

**連想検査**が本アプリの主眼です（第二次検査の約 4 割）。例:

| 簡単な方程式 | → | 専門分野の方程式 | 連想の中身 |
|:--|:-:|:--|:--|
| `a² + b² = c²` | → | `ds² = gᵢⱼ dxⁱ dxʲ` | 定数係数の計量を場所ごとに変えると曲がった空間の距離になる |
| `∫_a^b f′dx = f(b) − f(a)` | → | `∫_M dω = ∮_∂M ω` | 区間→多様体、端点→境界。ストークスの定理 |
| `∇×(∇φ) = 0` | → | `d ∘ d = 0` | 閉形式／完全形式の差＝de Rham コホモロジー |
| `∑ rⁿ = 1/(1−r)` | → | `ζ(s) = ∏_p (1 − p^−s)^−1` | 素数ごとの等比級数の積＝オイラー積 |
| `ab = ba` | → | `[x̂, p̂] = iℏ` | 可換性が壊れる度合い（交換子）そのものが物理量になる |
| `A𝐱 = 𝐛 の解の個数` | → | `ind(D) = ∫_M ch(E)Td(TM)` | rank-nullity を楕円型作用素へ持ち上げた指数定理 |

### 第三次検査 — 数学適性分野の診断

**どの専門分野に適性があるか**を、2 つの独立した測定を合成して診断します。

| 成分 | 測り方 |
|:--|:--|
| **志向**（思考スタイル） | 正誤のない設問 20 問（無限の扱い方 / 「同じ」とみなす基準 / 証明の好み / 対称性を見たとき何をするか / 挑みたい未解決問題 …）。各選択肢は分野への重みベクトルを持ち、**設問ごとの最大重みで正規化**（0〜1） |
| **実力**（分野別成績） | 第一次・第二次の設問を **難度 lv で重み付けした分野別正答率**（0〜1）。第一次/第二次の出題は分野が偏らないよう分野間で均した順に選ばれます |

```
総合 = 0.55 × 志向 + 0.45 × 実力      （両方測れた分野）
     = 志向 または 実力               （片方しか測れていない分野）
```

結果は 10 分野のランキングバー（総合／志向／実力を併記）と、**上位 3 分野のカード**として表示されます。
カードには「思考の型」「代表的な方程式」「代表的な記号」「隣接分野」「**次に学ぶとよい主題**」を提示します。

> 例（第一適性が微分幾何のとき）
> 思考の型: 座標に依らない量（テンソル・微分形式）で図形を記述し、局所の曲率から大域の形を導く
> 代表的な方程式: `ds² = gᵢⱼdxⁱdxʲ · ∫_M dω = ∮_∂M ω · ∫_M K dA = 2πχ(M)`
> 次に学ぶとよい主題: **多様体と微分形式 → 接続・曲率 → リーマン幾何**

**検査モード**は 4 つから選べます。

| モード | 内容 |
|:--|:--|
| フル | 第一次 → 第二次 → 第四次（瞬読）→ 第三次（適性分野診断） |
| 記号 + 方程式のみ | Ω 判定のみ |
| 数学適性分野の診断のみ | 思考スタイル設問だけを実施（Ω 判定は行わない） |
| 瞬読（フラッシュ）検査のみ | 瞬読設問だけを実施し、瞬読閾値を推定する |

**診断の妥当性検証**: ある分野への重みが最大の選択肢を常に選ぶ自動テストを 10 分野すべてで実行し、
**10/10 でその分野が第一適性**として返ることを確認しています（回答が結果に正しく反映されている、という検証）。

### 第四次検査 — 瞬読（フラッシュ）

速読法の **瞬読** に倣い、**数学の専門用語・記号・バラバラに分解した方程式のトークン**を、
画面上の **ランダムな位置・角度・大きさで一瞬だけ一斉提示** し、消えた直後に問います。

```
注視点(+) 500ms  →  バースト提示（可変 ms・ランダム配置）  →  マスク 120ms  →  設問
```

マスク（ランダムな記号片）を挟むのは、**残像から読み取るのを防ぐ**ためです。

| 設問種別 | 内容 |
|:--|:--|
| 瞬読（専門用語） | 散らして提示された用語のうち、実際に表示されたのはどれか |
| 瞬読（用語→意味） | 表示された用語の **意味** はどれか（瞬読＋理解） |
| 瞬読（記号） | 表示された数学記号はどれか（PDF 読込時はその論文の記号を使用） |
| **瞬読（方程式バラバラ）** | 方程式をトークンに分解して散らし、**元の方程式はどれか** を当てる |
| 瞬読（個数把握） | 表示要素は全部でいくつだったか（逐次読みでなく面で捉える） |

例: `∇f = (∂f/∂x, ∂f/∂y, ∂f/∂z)` は `∇f` `=` `(∂f/∂x,` `∂f/∂y,` `∂f/∂z)` に分解され、
それぞれがランダムな位置・角度・文字サイズで散らして提示されます。

**露出時間は 2-down/1-up ステアケース法で適応制御**します（2 連続正答で ×0.78、1 誤答で ×1.32）。
反転点の幾何平均を **瞬読閾値**（約 70% 正答できる露出時間）として推定し、
スループット（要素/秒）・最短正答露出・段位（Class-S 〜 D）とともに表示します。

**検証**: 真の閾値を持つ模擬観測者でステアケースを 200 回シミュレートし、
真値 120/250/500 ms に対して推定値の中央値が 169/292/552 ms と単調に追随することを確認
（2-down/1-up は 50% 点ではなく約 70% 点に収束するため、真値よりやや長い側に出るのが理論通りの挙動です）。
実ブラウザでも、要求露出 600 ms に対し実測 626 ms（注視点・マスクの動作も含めて確認済み）。

問題銀行: **記号 114 種**（+ 文脈依存 9 種）· **方程式 51 式**（Lv1〜Lv5）· **連想対応 20 組** ·
**適性設問 20 問**（+ 10 分野プロファイル）· **専門用語 100 語**（10 分野 × 10 語）。
分野は 解析学 / 微分幾何 / 位相幾何 / 代数・数論 / 代数幾何 / 圏論・論理 / 確率・統計 /
作用素環・関数解析 / 表現論・群論 / 数理物理 の 10 分野。

## 何が「本物の処理」か — PDF 記号抽出器（`www/pdf_symbols.js`）

外部ライブラリを使わず、**PDF を実際にパースして数式記号を抽出**します。

- 通常オブジェクト + **圧縮オブジェクトストリーム**（`/Type /ObjStm`, PDF 1.5+）の展開
- `FlateDecode` の伸長（`DecompressionStream`、末尾ゴミのある壊れた流も部分復元）
- `/Type /Page` の `/Resources /Font` と `/Contents` を辿ったページ単位のテキスト抽出
  （`/Resources` は `/Parent` 継承にも対応）
- フォント別デコード
  1. **`/ToUnicode` CMap**（`bfchar` / `bfrange`）
  2. **`/Encoding /Differences`** のグリフ名 → Unicode（TeX/AGL の数学グリフ名）
  3. **CM/AMS フォントの内蔵エンコーディング**（CMMI・CMSY・CMEX・CMR・MSBM・EUFM）
     — `∂`(CMMI 0x40)、`ℵ`(CMSY 0x40)、黒板太字 `ℝ ℂ ℤ`(MSBM)、フラクトゥール `𝔤 𝔪`(EUFM) など
  4. `Type0`（Identity-H 等）の 2 バイトコード

抽出結果は、記号のヒストグラム・数式断片・埋め込みフォント一覧として表示され、
そのまま第一次検査の出題に使われます。

### 検証済み（リポジトリ内の実 PDF）
| PDF | ページ | 抽出文字 | 記号種 | 主な検出 |
|:--|--:|--:|--:|:--|
| `analyze/mathmatics_field_theorem_1.pdf` | 119 | 113,123 | 60 | `∇`500 `∫`487 `∂`138 `∑`111 `𝒪`27 |
| `analyze/SuperNatureOfNormal2.pdf` | 183 | 157,017 | 86 | — |
| `analyze/Heisenberg.pdf` | 4 | 3,734 | 17 | `∫` `π` `∇` `⊗` `ℏ` |
| `src/object.pdf`（Word 由来 / CambriaMath） | 48 | 50,308 | 5 | `∫Γ(γ)′ dx_m` |

40 本の PDF に対する連続実行でクラッシュなし（約 2.6 秒）。
散文だけの PDF では「数式記号は見つかりませんでした」と正直に返します
（偽の結果は返しません）。

**限界**: スキャン画像のみの PDF、暗号化 PDF、上記以外の特殊エンコーディングは非対応です。

## 採点

正解した設問の難度 `lv` を、Γ カーネル由来の応答時間係数で重み付けします。

```
Γk(τ) = exp(−τ · log(1+τ)),  τ = 応答秒数 / 20
Ω     = 100 · Σ_correct lv·(0.7 + 0.3·Γk) / Σ_all lv
```

| Ω | クラス |
|--:|:--|
| ≥ 90 | Class-S — 完全共鳴 |
| ≥ 75 | Class-A — ウィスパード適性 高 |
| ≥ 60 | Class-B — 適性あり |
| ≥ 40 | Class-C — 訓練段階 |
| < 40 | Class-D — 共鳴未達 |

結果画面では、分野別正答率のレーダーチャート、到達難度、
**全設問の講評（誤答の解説つき）** を表示します。

## 使い方（ブラウザ）

```bash
xdg-open www/index.html          # または: python3 -m http.server 8000
```

1. （任意）数学論文の PDF をドロップ → 抽出された記号・数式断片を確認
2. 検査モード・問題数・難度上限・専門分野を設定して「▶ 適性検査を開始」
3. 第一次（記号）→ 第二次（方程式の意味・連想）→ 第四次（瞬読）→ 第三次（適性分野の診断）
   → Ω 判定・瞬読閾値・分野プロファイル
4. 「📖 記号辞典を開く」で 114 記号を分野別に閲覧できます

## APK / Windows EXE をダウンロード

偽のバイナリは置いていません。実バイナリは CI（GitHub Actions）がビルドします。

- **Actions** タブ →「Ω apps build (APK + Windows EXE)」→ **Run workflow** → 成果物
  `omega_whispered-android`(APK) / `omega_whispered-windows`(EXE) をダウンロード。
- タグ `apps-v*` を push すると **Releases** に APK/EXE が添付されます。
- 構成: `www/`（アプリ本体） · `electron/`（EXE） · `cordova/config.xml`（APK） ·
  `../../.github/workflows/omega-apps-build.yml`（ビルド）。

```bash
node -e "const P=require('./www/pdf_symbols.js'),fs=require('fs');
P.extract(new Uint8Array(fs.readFileSync('../../analyze/GammaFunction.pdf')))
 .then(r=>console.log(r.symbols.slice(0,10)))"
```
