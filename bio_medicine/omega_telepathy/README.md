# Ω-Telepathy — 概念BCI「思考タイピング」シミュレータ

Neuralink の "Telepathy"（思考でカーソル/入力を操作する脳-コンピュータ・インターフェース＝BCI）の
**概念**に着想した、教育／アートの**シミュレータ**です。実際の脳信号は使わず、**ドウェル（ホバー/注視）を
神経意図の代理入力**とし、未知事前エンジンが「意図」を復号・予測して入力を加速します。

---

## ⚠⚠ 重要 — シミュレーション/アート・非医療・非読心

- 脳インプラントでも本物のBCIでもありません。
- **思考を読み取らず、送信もしません**（読心・テレパシーではありません）。
- **Neuralink 社とは無関係**で、その商標・製品ではありません。
- 医療用途・意思決定には使えません。すべて通常入力（マウス/ホバー）と決定論的エンジンによる演出です。

## 機能
- **意図デコード（思考タイピング）**: キーにカーソルを重ねる（ドウェル）と意図が蓄積し、満ちると確定。
  エンジンが次文字を予測（青枠ハイライト）し、語彙補完候補と「デコード信頼度」を提示して入力を加速。
- **ニューラル・ラスター**: 現在の意図語をエンジンが決定論的にスパイク列へ符号化した可視化（脳波ではありません）。
- **思考コーデック**: 入力語を符号化→同一端末で復号し一致率を表示（脳間送信ではなく、符号化/復号のデモ）。

## 動かす
```bash
cd www && python3 -m http.server 8000     # http://localhost:8000/
# または www/index.html を直接開く
```

## APK / Windows EXE をダウンロード
偽のバイナリは置いていません。実バイナリは CI（GitHub Actions）がビルドします。
- **Actions** タブ →「Ω apps build (APK + Windows EXE)」→ **Run workflow** → 成果物
  `omega_telepathy-android`(APK) / `omega_telepathy-windows`(EXE) をダウンロード。
- タグ `apps-v1.0.0` を push すると **Releases** に APK/EXE が添付されます。
- 構成: `www/`（アプリ） · `electron/`（EXE） · `cordova/config.xml`（APK） ·
  `../../.github/workflows/omega-apps-build.yml`（ビルド）。本アプリもシミュレーション用途に限ります。
