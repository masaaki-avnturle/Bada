# ⚛ Bada QuantOS — 擬似量子オペレーティングシステム

**今までの集大成である擬似量子コンピュータ(量子 Bada 実行系)を、そのままオペレーティングシステムにしたアプリケーション。カーネルは生成 AI。**

タブレット・スマートフォンの機能 — **電話回線 / SMS / メール / カメラ / ギャラリー / 時計・アラーム / 電卓 / メモ / ファイル / 連絡先** — を、**トポロジーの写像機構**によって擬似量子コンピュータの上へ移植し、通信と保管を**量子暗号方式(BB84 量子鍵配送 + ワンタイムパッド)**で保護しています。**インストール済みアプリの起動と Play ストア**、**Samsung フリーフォーム / マルチウィンドウ**にも対応。依存ゼロ・単一 HTML・オフライン動作。

## 🪢 トポロジーの写像機構

各 OS 機能には**結び目(Reidemeister I カール列 = ±1 の交点符号列)**が割り当てられています。

1. **不変量による分類** — カール列の Kauffman ブラケットは ⟨K⟩ = (−A³)^w(w = ライズ = 符号和)。組 (交点数 c, ライズ w) は全機能で相異なるため、機能はトポロジー不変量で一意に分類されます。
2. **基底への単射写像 φ** — 各機能を 4 量子ビットレジスタの基底状態 |b₀b₁b₂b₃⟩ へ単射に写像します(2⁴ = 16 基底 ≥ 14 機能)。写像先は各アプリのアイコン下と画面上部の Ψ 表示で常に確認できます。
3. **連続変形による遷移** — 機能間の移動はハイパーキューブの辺(X ゲート 1 発 = 1 ビット反転)に沿った連続変形として表され、「写像室」アプリでゲート列と擬似量子カーネルによる検算を観測できます。不変量 (c, w) は変形の間も保存されます。

## 🧠 生成AIカーネル

画面下のコマンドバーが OS シェルです。すべての応答で 6 段パイプラインを開示します:

**① トークン化 → ② 意図解析 → ③ トポロジー写像 → ④ 計画 → ⑤ 生成 → ⑥ 検証**

例:
- 「**090-1234-5678 に電話**」 → 電話 ↦ |0001⟩ へ写像し、`tel:` インテントを端末回線へ発行
- 「**写真を撮って**」 → カメラ ↦ |0101⟩ へ写像して起動
- 「**1+2*3**」 → 電卓パーサで検算つき評価
- 「**qubit q0 q1 ↵ H q0 ↵ CNOT q0 q1 ↵ state**」 → 擬似量子カーネルで直接実行

## 📞 電話回線について

電話・SMS・メールの**発信は端末 OS へ `tel:` / `sms:` / `mailto:` インテントとして委譲**します。Android APK では標準の電話アプリ・SMS アプリが起動して実際に発信できます(APK は Cordova の `allow-intent` で許可済み)。デスクトップ(Windows / Ubuntu)には電話回線がないため、発行予定のインテント内容を表示します(mailto: は既定メールアプリへ)。

## 🛒 インストール済みアプリ + Play ストア

「アプリ」(基底 |1111⟩)から、端末にインストール済みのアプリを URL スキーム / `market:` インテントで起動できます。

- **🚀 起動** — `vnd.youtube://` `line://` `twitter://` などのスキームを端末 OS へ発行。未インストールなら Play ストアのページが開きます。
- **🗔 分割** — `FLAG_ACTIVITY_LAUNCH_ADJACENT` (0x1000) を載せた `intent:` URI で、**Samsung のマルチウィンドウ(分割画面)のもう一方**にアプリを起動します。
- **🛒 Play ストア** — キーワード検索(`market://search?q=`)とパッケージ名指定(`market://details?id=`)。
- AIカーネルに「**YouTube を開いて**」「**LINE をインストールして**」と話しかけても同じ操作ができます。

## 🗔 Samsung フリーフォーム / マルチウィンドウ

ステータスバーの **🗖 全画面 / 🗔 フリーフォーム** で、OS シェル自体を **Samsung DeX 風のフローティング・ウィンドウ**に切り替えられます。Samsung 端末や DeX、幅 900px 以上のタブレットでは最初からフリーフォームで起動します。

- **複数アプリを同時に表示** — ホームのアイコンを押すたびに新しい窓が開きます(同じアプリは二重に開かず既存の窓にフォーカス)。
- **ドラッグ移動 / 角つまみでリサイズ / 最小化・最大化・閉じる**、DeX 風の**タスクバー**。
- **端へドロップでスナップ** — 左右半分・上下半分に吸着(Samsung の分割画面ドロップと同じ操作感)。
- **整列** — 左右2分割 / 上下2分割 / 3分割 / 格子4分割 / カスケード / 最大化。
- **窓の重なり = 組み紐(braid)** — x 座標順のストランドを重なり順 (z) へ並べ替える隣接互換の列が組み紐語 σ₁σ₂… で、交差数は置換の転倒数として一意に定まります。その閉包の Kauffman ブラケット ⟨K⟩=(−A³)^w を、トポロジー写像機構と**同じ不変量**で計算して上部に表示します。
- **AIカーネル連携** — 「マルチウィンドウにして」「ウィンドウを左右に分割して」「窓を上下に並べて」で切替・整列します。

Android 側(APK)も **`android:resizeableActivity="true"`**、サイズ系を網羅した `configChanges`(リサイズしてもアクティビティが再生成されず状態が保たれる)、フリーフォーム時の既定/最小ウィンドウサイズ(`<layout>`)、Samsung One UI / DeX 向けメタデータ(`com.samsung.android.supports.multiwindow` ほか)を宣言しています。

## 🔐 量子暗号方式(BB84 + ワンタイムパッド + 量子金庫)

「量子暗号」アプリ(基底 |1110⟩)が OS の暗号層です。

1. **BB84 量子鍵配送** — Alice が乱数ビットを乱択基底(Z=+ / X=×)で量子ビットとして送出し、Bob が乱択基底で測定。基底一致分をふるい、前半を照合して **QBER(量子ビット誤り率)** を推定します。**盗聴者 Eve を挿入**(チェックボックス)すると intercept-resend 盗聴が再現され、複製不可能定理により基底一致位置へ約 25% の誤りが混入 → **QBER > 10% で盗聴を検出し鍵を破棄**します。伝送ログ(先頭 12 qubit)・ふるい数・QBER・判定を表示します。
2. **ワンタイムパッド暗号** — 確立した共有鍵で平文を XOR し 16 進の暗号文にします(鍵長 ≥ 本文長のとき情報理論的に安全)。鍵は**メモリ内のみ**に保持し、保存しません。
3. **量子金庫** — メモを共有鍵で暗号化してから端末に保管します(端末内に残るのは暗号文だけ。復号には保管時と同じ鍵が必要)。
4. **SMS 連携** — メッセージアプリの「🔐 量子暗号化」で本文を暗号化してから `sms:` で送信できます。
5. **AIカーネル連携** — 「鍵配送して」「盗聴されていないか確認」と話しかけると BB84 を実行し QBER を報告します。

## ⚛ 擬似量子カーネル(量子 Bada)

`qubit / H / X / Z / CNOT / measure / state / let / print` を実装した実振幅の状態ベクトル・シミュレータ(8 qubit まで)。「量子ラボ」アプリからベル状態・GHZ などを実行できます。

## 🚀 使い方

1. [`index.html`](index.html) を「Download raw file」で保存 → ダブルクリック(インストール不要)
2. または [Releases](https://github.com/masaaki-avnturle/Bada/releases) から:

| プラットフォーム | ファイル |
|:---|:---|
| **Android** (APK) | `bada-quantos-debug.apk` |
| **Windows 10 / 11** | `BadaQuantOS-*-x64.exe`(NSIS インストーラ / ポータブル) |
| **Ubuntu** | `BadaQuantOS-*-x86_64.AppImage` / `BadaQuantOS-*-amd64.deb` |

ビルドは [`quantos-app-build.yml`](../.github/workflows/quantos-app-build.yml) が実行します(`quantos-v*` タグで Release へ添付 / `workflow_dispatch` で Actions アーティファクト)。
