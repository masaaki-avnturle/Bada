# 🛠 Yappa CAD — 近未来ビークル CAD (Bada 言語で機能拡張)

**依存ゼロの単一 HTML ファイル**で動く、近未来の乗り物専用のパラメトリック CAD アプリです。
🚗 **近未来自動車** / 🛸 **UFO 宇宙船** / 🏍 **近未来バイク** をテンプレートから設計し、
各パーツに**機能(役割)を割り当てて性能を設計**し、さらに **Bada 言語**のスクリプトで
アプリ自体を機能拡張できます。WebGL レンダラ・行列演算・**Bada インタープリタ**まで、
すべて [`index.html`](index.html) 1 ファイル内に自前実装しています。

## 🚀 起動方法

**ブラウザで開くだけ**です。インストール不要・オフライン動作:

- GitHub Pages: **<https://masaaki-avnturle.github.io/Bada/yappa_cad/>** (main マージ後)
- ローカル: [`index.html`](index.html) をダウンロードしてダブルクリック
  (GitHub のファイル表示画面右上の「Download raw file」⬇ で保存できます)

## 🚘 ビークルテンプレート (パラメトリック設計)

「🚀 テンプレート」から生成すると、左下のスライダーで**リアルタイムに再生成**できます:

| テンプレート | パラメータ | 生成されるパーツ (機能つき) |
|:---|:---|:---|
| 🚗 **近未来カー** | 全長 / 全幅 / 全高 / ホイール径 | ボディ+ノーズ+テール(構造) · キャノピー(キャビン) · ホイール×4 · イオンスラスター(推進 26kN) · 量子電池(電源 240kW) · LiDAR(センサー) · AI コア(制御) |
| 🛸 **UFO 宇宙船** | 直径 / 船体厚み比 / ドーム比 / 着陸脚数 | 円盤船体+発光リム(構造) · ドーム(キャビン) · 重力子エミッタ(浮上) · 反物質炉(電源) · 航行灯×8 · 量子レーダー · 航法 AI |
| 🏍 **近未来バイク** | 全長 / ホイール径 / シート高 | モノコックフレーム · 前後輪 · フロントフォーク+カウル · シート · パルスジェット(推進) · セル電池(電源) · ジャイロ(制御) |

テンプレート以外に「＋ パーツ」から 8 プリミティブ
(ボックス / 球 / 円柱 / コーン / リング / パネル / **ウェッジ** / **カプセル**) を自由に配置できます。

## ⚙️ 機能設計 — 役割の割当とスペック算出

パーツを選択し、インスペクタの「⚙ 機能設計」で役割を割り当てます:

| 役割 | 効果 |
|:---|:---|
| 🧱 構造 / 🪟 キャビン | 質量に寄与 (密度が役割ごとに異なる) |
| 🔥 推進 (kN) | 総推力・最高速度・推力重量比に寄与。電力を消費 |
| 🛸 浮上/揚力 (kN) | 揚力。**揚力 > 重量**で「浮上可能」判定 |
| 🔋 電源 (kW) | 発電。体積から電池容量 (kWh) も推算 |
| 🎛 制御 / 📡 センサー | 電力を消費 |

右パネルの「📐 機体スペック」が**リアルタイム**に更新されます:
寸法 / 総質量 / 総推力 / 推力重量比 / 最高速度(推算) / 揚力 / 電力収支 / 電池容量 / 航続 —
さらに ✓/⚠ の設計判定 (推進系の有無・電力不足・浮上可否) を表示します。

## ⚡ Bada 言語で機能拡張

画面下の **Bada 拡張コンソール** (F9 / Ctrl+Enter で実行) に Bada インタープリタを内蔵しています。
文法は Bada 本体と同じ: `:=` 代入、`def f |a, b| { }` 関数、`if/else`、`while`、`for x in`、
`return`、`print`、リスト、`# コメント`、そして **`>> tuplespace`** (追記専用の設計台帳)。

```bada
# リング状に 6 基のスラスターを配置して推進力を増強
def thruster |i, n| {
    a := i * 2 * pi() / n
    t := part("cylinder", "スラスター" + str(i+1))
    move(t, cos(a)*1.3, 0.9 + sin(a)*0.5, -2.9)
    rot(t, 90, 0, 0)
    scale(t, 0.3, 0.45, 0.3)
    assign(t, "propulsion", 9)     # 機能設計: 推進 9 kN
    return t
}
for i in range(6) { thruster(i, 6) }
spec_report()                       # スペックをコンソールへ
"ion thruster ring x6" >> tuplespace
```

### CAD API (Bada ビルトイン)

| 分類 | 関数 |
|:---|:---|
| 生成 | `part(type, name)` · `vehicle("car"/"ufo"/"bike")` · `clone(id)` · `remove(id)` · `clear()` |
| 変形 | `move(id,x,y,z)` · `rot(id,x,y,z)` · `scale(id,x,y,z)` |
| 外観 | `paint(id,"#rrggbb")` · `shine(id,1..128)` · `rename(id,s)` |
| 機能設計 | `assign(id, role, power)` — role は `propulsion/lift/power/control/sensor/cabin/structure` |
| 照会 | `ids()` · `count()` · `find(name)` · `name_of(id)` · `pos_of(id)` · `select(id)` · `focus(id)` |
| スペック | `spec_mass()` · `spec_thrust()` · `spec_power()` · `spec_vmax()` · `spec_report()` |
| 拡張 | **`macro("ボタン名", "関数名")`** — def した関数をビューポートのボタンとして登録 (localStorage に永続化) |
| 汎用 | `print` `len` `push` `range` `str` `num` `floor` `round` `abs` `sqrt` `sin` `cos` `tan` `pow` `min` `max` `pi` `rand` `f5` |

サンプルは「サンプルを選択…」から: ヘッドライト 6 連装 / 六連イオンスラスター /
UFO 艦隊 (3 機) / スペック検査 → 台帳 / マクロ登録。

## 💾 保存と書き出し

- 💾 **保存 / 📂 読込** — シーン JSON (`vehicle.yappacad.json`)。機能割当・テンプレートパラメータ込み
- ⬇ **OBJ** — Wavefront OBJ + MTL 書き出し (Blender 等で読込可)
- 📷 **PNG** — ビューポートのスクリーンショット

## 🔧 実装メモ

- レンダラは [Yappa 3D](../yappa3d/) エンジン (WebGL1 + 自前 mat4 + GPU カラーピッキング +
  平面射影シャドウ) を拡張し、ウェッジ / カプセルの 2 プリミティブを追加
- Bada インタープリタは再帰下降パーサ + 木巡回評価器 (~300 行)。
  ステップ上限 150 万で無限ループを安全に停止。`>> tuplespace` は追記専用台帳
- スペックは役割別密度 × パーツ体積で質量を推算し、前面投影面積から
  最高速度 v = √(2T/ρC_dA) を概算 (未来型全固体電池 900 kWh/m³)
