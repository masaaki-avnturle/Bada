主題 (フーガ) — 音名:拍 (例 D4:3 E4:1 F4:2 A4:2)

主題の入り:

4 声の楽器

主進行 (1 行目、金色) と、オーケストラの各行。セルは「Dm」「Gm A7」(2 拍ずつ)「Dm Gm A7 A7」(1 拍ずつ) のように書け、空欄はその小節の主進行に従う。行ごとに楽器・型 (持続 / 刻み / 分散 / バス / 声部の重ね) ・オクターヴ・音量。
和音パレット (選んだセルに書き込み):
Requiem BADA の各曲の score.json (Python 版 compose_*.py の出力) を読み込むと、その曲の 4 声・シンセ・鼓動・実音の抜粋がタイムラインの「楽譜」トラックに載り、ここで編曲できます。
音符の編集: クリックで選択 (Shift で追加、空所をドラッグで範囲選択)、ドラッグで移動 (上下 = 音高、左右 = 時間)、空所をダブルクリックで追加。
実音の抜粋 (REC) は、「音源・映像」で同じ録音 (ファイル名に 20260923_080607 などの日時を含む mp3 / mp4) を読み込んであると、その音源から自動的に鳴ります。読み込んでいない録音の抜粋は鳴りません (一覧に ⚠ で表示)。
動画: 映像トラックの映像 (なければピアノロールと波形) を音と合成して録画します。再生時間ぶんの時間がかかります。Android では保存ダイアログ、Windows / Linux ではネイティブの保存ダイアログで保存先を選びます。プロジェクトには音源の音そのものは含みません (ファイル名を記録し、開き直すときに同じ音源を読み込み直してください)。
1. 音源・映像 — 「読み込む」でどの拡張子のファイルでも選べます (mp3 / wav / ogg / flac / m4a / aac / opus / mp4 / webm / mov …、中身で判断してデコード)。デコードできない形式は「生 PCM として読み込む」で 16 bit 44.1 kHz として読みます。
2. タイムライン — 上から 映像 / 作曲 / 音声トラック。クリップをドラッグで移動、両端をドラッグで切り詰め、✂ で分割。数値欄で開始・元の位置・長さ・音量・フェード。ルーラーをタップして再生位置。
3. 作曲 — 🎲 自動作曲で、調とテンポからコード進行 (機能和声)、主題、フーガの入り、オーケストラの行を作ります。対位法エンジン (bada_fuga/compose.py の移植) が 4 声を書き、行の和音で管弦楽が支えます。主題は手で書けます。読み込んだ音源をサンプラー楽器として使えます。
4. コード進行 (オーケストラ) — 主進行 + 弦 5 部・木管・金管・ティンパニなど 5 行以上の表。行ごとに違う和音を書けば多層の進行 (複和音) になります。
5. 楽譜 (score.json) — Requiem BADA の曲の score.json を読み込んで編曲: 移調、速さ、声部の楽器、シンセ・鼓動・抜粋の on/off、音符の移動・削除・追加。同じ録音を「音源・映像」で読み込んでおくと、実音の抜粋もその音で鳴ります。編集した楽譜は score.json に書き戻せます (Python 版 synth.py でそのまま高音質に)。
6. 書き出し — WAV / MIDI / 動画 / score.json / プロジェクト。
