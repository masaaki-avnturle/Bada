# 📝 Markdown でページを作る — 使い方ガイド

このハブは **Markdown（`.md`）だけでページを書ける** ようになっています。
CDN や外部ライブラリを一切使わない、依存ゼロの自前レンダラで表示します。

## 3 つの使い方

1. **既存の `.md` を表示する**
   上の入力欄にパスを入れて「⤵ 読み込む」。例：`bada_ruby/README.md`
2. **その場で書いてプレビュー**
   左のエディタに Markdown を入力すると、右側に即時レンダリングされます。
3. **`.md` として保存**
   「💾 .md で保存」でファイルとしてダウンロード → リポジトリに置けば公開ページになります。

## 対応している記法

| 記法 | 例 |
|:-----|:---|
| 見出し | `# H1` 〜 `###### H6` |
| 強調 | `**太字**` `*斜体*` `~~打消~~` |
| コード | `` `inline` `` とフェンス ```` ``` ```` |
| リスト | `- 箇条書き` / `1. 番号付き` |
| 引用 | `> 引用` |
| リンク・画像 | `[text](url)` `![alt](src)` |
| テーブル | この表そのもの |
