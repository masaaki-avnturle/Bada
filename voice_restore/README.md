# 声色リストア — Voice Restore Studio

ミュージックレコーダーやボイスチェンジャーで **ピッチ・フォルマントを変調(ボイスチェンジ)された録音** を、
**逆変換して元の声色に近づける** 単一ページ Web アプリです。インストール不要・依存ライブラリなし・
**すべてブラウザ内で完結**(音声はどこにも送信されません)。

> ⚠ 逆変換は変調内容の推定に基づく **近似** です。元信号を完全に復元できるわけではありません。
> 録音の取り扱いは、各自の権利と責任の範囲で行ってください。

---

## できること

- 🎵 **読み込み**: 音声ファイル(WAV / MP3 / M4A / OGG など)を選択、またはブラウザで **マイク録音**。
- 🔍 **変調の自動推定**: 有声区間の平均ピッチを自己相関で測定し、目標の声域(男性 / 女性 / 中性)へ
  合わせるための **ピッチ・フォルマント補正量の初期値** を提案。
- ⚙ **声色の復元**:
  - **ピッチ復元**(±12 半音): 変調で上げ下げされた音程を戻す。
  - **フォルマント復元**(50〜200%): 声道の長さ=声色を戻す(ピッチは保ったまま包絡だけを補正)。
  - **弱ノイズゲート** / **出力ゲイン** / クリップ保護。
- 🎧 **A/B 試聴**: 「変調前(オリジナル)」と「復元後」を聴き比べ。
- ⬇ **WAV 書き出し**: 16bit PCM WAV で保存。

## 使い方(ブラウザ)

```bash
cd voice_restore/www
python3 -m http.server 8000     # → http://localhost:8000/
```

> `index.html` は `dsp.js` を ES モジュールとして読み込むため、`file://` で直接開くと
> ブラウザの CORS 制限で読み込めない場合があります。上記のようにローカルサーバ経由で開いてください。

### 手順

1. **① 変調された録音を読み込む** — ファイル選択 / マイク録音 / 「デモ音声を生成」。
2. **② 声色を戻す** — 「変調を自動推定」で初期値を入れ、`ピッチ復元` と `フォルマント復元` を耳で微調整 →
   **「復元を実行」**。
3. **③ 試聴して書き出す** — 「変調前」「復元後」で聴き比べ、必要なら②に戻って追い込み、
   **「WAV で保存」**。

## 仕組み(DSP)

`www/dsp.js` に Web Audio 非依存の純粋関数として実装しています。

| 処理 | 手法 |
|:--|:--|
| ピッチシフト | **フェーズボコーダ**(STFT + 位相伝播)でタイムストレッチ → 線形リサンプル。フォルマントも一緒に移動。 |
| フォルマントシフト | **ケプストラム包絡**推定 → 包絡を周波数軸方向にワープして再適用。ピッチ(励起)は保持。 |
| 復元 | フォルマント包絡を戻してからピッチを戻す(`restoreVoice`)。 |
| ピッチ推定 | 自己相関による有声区間の基本周波数(中央値)。 |
| 書き出し | 16bit PCM WAV エンコード。 |

変調が「ピッチ +n 半音・フォルマント r 倍」だった場合、復元は「ピッチ −n 半音・フォルマント 1/r 倍」に相当します。

## テスト

DSP コアには単体テストがあります(Node 18+ / 22 で確認)。

```bash
node voice_restore/test/dsp.test.mjs
```

FFT 往復・ピッチシフトの周波数・フォルマントシフトのピッチ保持・復元の往復・WAV ヘッダ等を検証します。

## 制限

- 完全なブラインド復元は原理的に不可能です。変調が強い/複数段/時間変化する場合、近似の限界があります。
- 位相ボコーダ由来のわずかな残響感が出ることがあります。フォルマント補正量を控えめにすると自然になります。
- 長い録音は処理に数秒かかります(全処理はメインスレッドのオフライン処理)。
