Usage on Windows:
 1) Ensure Python3 is installed on Windows.
 2) Ensure AutoHotkey is installed (https://www.autohotkey.com/).
 3) Copy this package to Windows.
 4) Run:
    python -m emacskeys.runner --config-file mymap.json
    # This will generate a generated/emacskeys_remap.ahk and register it to start at login (HKCU Run).

Notes:
 - The JSON format expects an object with a top-level "bindings" object mapping keys to actions.
 - Key names: use modifiers as prefix (C- for Ctrl, M- for Alt, S- for Shift), examples: "C-a", "M-x", "h", "j".
 - The runner is a helper that emits an AutoHotkey script; complex modal behaviors should be implemented in the AHK script or by extending the runner.
 - Registry writes are to HKCU Run; no admin privileges required for HKCU.
