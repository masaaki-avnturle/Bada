# こんにゃく照合器 — omega_konnyaku_dialog

手帳ノートの見開き（`assets/source_note.jpg`）を、そのまま**ダイアログボックス操作のアプリケーション**に作り換えたもの。

- **左ページ**：4 本の方程式と 4 枚の絵（砂時計・球と測地線・レンズ・∞）
- **右ページ**：箱の絵、段落の区切り、三本線 **≡**、「後ろ側で分析」の走り書き

この二枚を重ねると、**「段落＝箱をひらいて任意の数値を入れると、後ろ側で “絵の形” と “数値のエントロピー” を照合し、こんにゃくの弾力性・優しさ・カインの刻印を判定して、消せない台帳（アカシックレコード）に綴じる」** という 1 本の操作になる。それを実装したのが本アプリ。

### 👉 [**omega_konnyaku_dialog/index.html を開く／ダウンロード**](index.html)

単一 HTML。ダブルクリックで開くだけで動く（サーバ不要・通信なし・インストール不要）。入力と台帳はその端末の `localStorage` にだけ残る。

## ノートのどこが、どの操作になったか

| ノート | アプリでの姿 |
|---|---|
| 左ページの方程式（4 本） | 4 つの箱の「方程式」。入力した数値で実際に計算され、**方程式値**として表示される |
| 左ページの絵（4 枚） | 箱の中に描き起こした図。絵ごとの**形シグネチャ**（鞍 / 軸 / 葉 / 閉 の重み）に写し、そのシャノンエントロピーが **H<sub>形</sub>** |
| 右ページの箱の絵 | 段落カード。タップで**入力ダイアログ**（OK／キャンセル、Esc で取り消し、不正値は検証エラー） |
| 段落ごとの区切り | 箱ごとに独立した入力・照合・記録 |
| 三本線 **≡** | **同値類**。残差 r を刻み幅 τ で丸めた k が等しい箱同士が ≡ で結ばれる（全体照合ダイアログ） |
| コンニャク（弾力性） | 入力をつまんだときにエントロピーがどれだけ戻るか＝**弾力性** |
| 優しさのカイン | 三条件の門。欠けると「**カインの刻印**」と理由が残る（拒否ではなく、刻んで残す） |
| 後ろ側で分析・アカシックレコード | SHA-256 のハッシュ連鎖で綴じた**追記専用台帳**。検証と JSONL 書き出しができる |

## 4 つの箱

| 箱 | 絵 | 方程式（ノートの手書きを正規化した読み） | 入力 |
|---|---|---|---|
| B1 | 砂時計（カテノイド） | ∂ = \|t\| · ∫₀ᵗ √(ζ·x + a) dx | ζ, a, t |
| B2 | 球と測地線 | ∂ζ ⁄ ∂√( ∬ ∂n ∂t_a ) = ζ ⁄ √\|n·t_a\| | ζ, n, t_a |
| B3 | レンズ（二楕円の交わり） | ∮₀^θ (6 + x² − 9x) du,  x = r·cos u（θ=2π で 12π + π r²） | r, θ |
| B4 | 二葉（∞）とガウス周回 | d⁄dt ∮ σ·e^(−t²) dx = −2 t σ √π · e^(−t²) · k | t, σ, k |

各箱には変数のほか、**追加の数列**（任意の数値列）を流し込める。変数値と数列を合わせた列が、エントロピーを測る標本になる。

## 照合のしくみ

1. **形のエントロピー** `H形 = −Σ wᵢ log₂ wᵢ`（wᵢ は絵の 4 成分の重み、0〜2 bit）。
   一軸に尖った形ほど 0 に近く、四方に均された形ほど 2 に近い。
2. **数値のエントロピー** `H数値`。入力列を min–max で正規化し、4 ビンに**線形補間**で配った分布のエントロピー（0〜2 bit）。
   階段状に数えると微小な摂動に反応せず弾力性が測れないため、境界をなめらかに跨がせている。
3. **照合率** `match = exp(−|H数値 − H形|)`。形と数値がぴたり重なると 100%。
4. **同値類（≡）** 残差 `r = H数値 − H形` を τ = 0.25 bit で丸めた `k`（−2〜+2）。
   同じ k の箱同士が `B2 ≡ B4` のように結ばれる。反射律・対称律・推移律を満たす正真正銘の同値関係（自己テストで検査している）。
5. **こんにゃく弾力性** 入力をレンジの ±5% で互い違いにつまみ、エントロピーの応答 `S = |ΔH|/0.05` から `E = 1/(1+S)`。
   つまんでも形が戻れば 1 に近く、千切れると 0 に近い。数が少ない列は脆く、ほどよく散った列は弾力がある。
6. **優しさ** 隣り合う数の跳ね（全変動 TV）から `G = 1/(1 + TV/(レンジ·(n−1)))`。なめらかな列ほど 1 に近い。
7. **カインの門** `照合率 ≥ 0.60`・`弾力性 ≥ 0.60`・`優しさ ≥ 0.50` の三条件。
   そろえば「刻印なし（受理）」、欠ければ「カインの刻印」と欠けた理由。**どちらの場合も台帳には必ず残る**。
8. **アカシックレコード** 1 行ごとに `hash = SHA-256(前の行の hash ‖ 正準化した本文)`。
   途中を書き換えると以降すべてが壊れるため、「消せない記録」として検証できる。JSONL で書き出せる。

> 桁の違う数（例：半径 2 と角度 360）を同じ箱に混ぜると、片方のビンに潰れてエントロピーが落ち、形と噛み合わなくなる。これは不具合ではなく、そういう物差しであることの表れ。B3 の角度をラジアンにしてあるのはそのため。

## 使い方

1. `index.html` を開く。
2. 箱の「数値を入力…」→ ダイアログに任意の数値（既定値が入っている）。Enter か「照合する」で確定、Esc かキャンセルで取り消し。
3. 照合結果ダイアログで、左ページの形・エントロピー 2 本・三本線 ≡ と同値類・各指標・カイン判定を読む。
4. 「全体照合（同値類マップ）」で、4 つの箱が ≡ でどう束ねられたかを見る。
5. 「アカシックレコード」で台帳を開き、連鎖を検証／JSONL に書き出す。

## 検証

計算核（`index.html` の `KONNYAKU CORE BEGIN … END` の区間）は、コピーを持たず本体から直接抜き出して試験する。

```sh
node tools/check-html.mjs        # index.html の健全性検査（CI のビルド前ゲート）
node tools/selftest.mjs          # 自己テスト（43 項目）
node tools/selftest.mjs --demo   # 4 つの箱に既定値を入れた照合結果を表示
```

## 式を読み替えたいとき

`index.html` 冒頭の `BOXES` 定義（`equation` / `weights` / `vars` / `evaluate` / `seqDef`）を書き換えれば、箱の挙動がそのまま変わる。方程式はノートの手書きを正規化した読みなので、別の読み方をしたい場合はここを直す。しきい値は `TAU` / `BINS` / `DELTA` / `GATE` で調整できる。
