Contact Transporter Studio

    
「CONTACT TRANSPORTER 異次元への輸送機 3 次元設計図書」(contact_blueprint.pdf) の方程式から作った設計スイートです。3 つのアプリはすべて量子プログラミング言語 Bada で書かれており、アプリ内の Bada IDE でソースを読み・書き換え・新しいアプリを作ってその場で実行できます。

    
    
      
  • Bada 処理系 — bada_silent_vim/bada (Python) の字句解析・構文解析・バイトコードコンパイラ・スタック VM を JavaScript へ忠実に移植 (リポジトリ内の Bada プログラム 99 本で出力が完全一致)。<- -< >- -> <-> >> =>、Omega::DATABASE[space]、#include。
    • 
      
  • ContactGPT (apps/contactgpt.bada) — ゼロから実装した Transformer のロジットを Bada が受け取り、上位 k → softmax → 量子状態 ψ = √a·e^{iθ} → Born 則測定で次の文字を選ぶ (設計図書 Q.1–Q.10)。方程式検索・設計値の即答・Bada 式の電卓。
    • 
      
  • 輸送機 3D CAD (apps/transporter.bada) — Γ, φ = arcosh Γ, Riemann–Siegel θ(φ)・Z(φ) (Borwein 法の ζ も Bada)、Jones 多項式を Bada で計算し、ジンバル環・ポッド・Jones コイル・扉の軸を組み立て、frame(t) で回転。
    • 
      
  • BadaClaude (apps/badaclaude.bada) — Claude / ChatGPT の対話の仕組み (① 字句化 → ② 意図推定 a = softmax(z), ψ = √a·e^{iθ} → ③ 論文 10 本 + 方程式 2111 本の BM25 検索 → ④ 道具 → ⑤ 根拠つき回答 → ⑥ Ω 台帳) を Bada で書いた対話エンジン。Anthropic の Claude や OpenAI の ChatGPT の学習済みの重みは含みません。汎用の会話には任意の Claude API モード (Bada が集めた <bada_context> を Claude に渡す) を使います。API キーは「端末に保存」を選んだときだけ端末内に保存され、送信先は api.anthropic.com だけです。
    • 
      
  • UFO 設計図面 (apps/ufo.bada) — 船体断面・部品配置・寸法・部材表・反重力モデル L = cosh(x log x) の飛行計算を Bada で書き、A3 図面を生成。
    • 
    

    
※ 設計図書自身が述べているとおり、これは論文の方程式に基づく思索的・フィクションの設計図 (幾何的な可視化) です。工学的に検証された装置ではなく、異次元への輸送や反重力飛行を実現するものではありません。
