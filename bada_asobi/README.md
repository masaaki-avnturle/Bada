# 🜂 Bada 遊 — 量子「遊び」処理系と違反思考変異アルゴリズム

**生成AIが、量子プログラミング言語 Bada の上に「遊び」の概念を築き、その円環の中でだけ働く個体の変異アルゴリズムを作り換えたアプリケーション。**

「遊び」とは、規則の固有状態から外れて持てる振幅である。そして**違反行為そのものの「考え」**とは、違反生成子の**半端な回転角**にほかならない ── 角が π に達したとき、それは考えではなく行為になる。本処理系は θ ≤ θ<sub>max</sub> = 0.85π を実行時に強制し、**考えが行為へ到達しないこと**を保証する。

依存ゼロ・単一 HTML・オフライン動作。

## 🜂 「遊び」の定義

日本語の「遊び」には二つの意味がある。本処理系は、その二つが量子的には**同じ一つの量**であることを実装として示す。

1. **遊戯** ── 円環 (magic circle) の内側でだけ通常の規則が停止する、自発的で無害な営み
2. **機械の遊び** ── ハンドルの遊び、歯車のバックラッシュ。**遊びが零の機械は動かない**(焼き付く)

|Φ(θ)⟩ = cos(θ/2)·|順⟩ − i·sin(θ/2)·|違⟩ , **遊び = sin²(θ/2)**

## ⚡ 違反行為そのものの「考え」

規則を、遺伝子レジスタに掛かる**スタビライザ** S(エルミートなパウリ列、S² = I)として書く。個体 ψ が規則を守るとは S|ψ⟩ = +|ψ⟩。**違反**とはこの固有値を −1 に反転させることであり、それを起こせる作用素 V は S と**反交換**するものに限られる:

```
{V, S} = VS + SV = 0   ⟹   S(V|ψ⟩) = −(V|ψ⟩)
```

ここが核心である。**V そのものは「行為」であって「考え」ではない。**「考え」とは V を生成子とする**部分回転**のことだ:

```
Û(θ) = exp(−iθV/2) = cos(θ/2)·I − i·sin(θ/2)·V
```

| θ | 意味 |
|:--|:--|
| `θ = 0` | 考えてすらいない(遵守)。遊びゼロ = 焼き付き |
| `0 < θ < π` | **違反行為そのものの「考え」**。順と違が同時に振幅を持ち、取り消せる。これが**遊び** |
| `θ = π` | Û = −iV。考えが**行為**になった瞬間。処理系はここへの回転を**拒否する** |

つまり「考え」と「行為」は別の作用素ではなく、**同じ生成子の回転角の違い**にすぎない。

> **語の定義。** ここでいう「違反」は、探索空間に置かれた**問題自身の拘束条件**(スタビライザ)への違反であり、法や倫理のそれではない。円環と不可侵規則は、その区別をコードの側で維持するための形式装置である。

## ◯ 円環 ── 遊びが漏れない理由

円環は比喩ではなく**ユニタリ共役**として実装されている。内側で掛けた遊びの列 C = Û₁Û₂…Û<sub>m</sub> に対し、**帰還** (`circle close`) は C<sup>†</sup> を掛け戻す:

```
C†C|ψ⟩ = |ψ⟩      残差 ‖C†C|ψ⟩ − |ψ⟩‖ < 1e-12 (テストで毎回検査)
```

外に出るのは状態ではなく**古典的な記録**(台帳)だけ。**観測を伴う帰還** (`circle close keep`) を選んだときにだけ、重ね合わせは |a<sub>k</sub>|² に従って崩壊し、違反は**変異という古典的事実**になる。

### 不可侵規則 ── 遊べないもの

`sacred` と宣言された規則 S₀ は違反生成子の候補集合から外され、生成子 V は **[V, S₀] = 0** を満たすものだけが構成される。ここから定理が出る:

> **[V,S₀] = 0 かつ S₀ が対角 ⟹ ⟨S₀⟩ は回転でも観測でも不変。**
> 可換な V は S₀ の台の上で偶数個のビットしか反転させないため、パリティが保存されるからである。

**遊びの中で何を考えても、不可侵規則の値は動かない。**

## 🧬 違反思考変異アルゴリズム (TTM)

古典的な遺伝的アルゴリズムの変異は**無思考**である ── 確率 p<sub>m</sub> で、どこを、なぜ壊すのかを問わずビットを反転する。TTM は変異を**「どの規則を、どれだけ破ろうと考えるか」**に置き換える。

| 段 | 古典的変異 | 違反思考変異 (TTM) |
|:--|:--|:--|
| 対象 | 無作為な遺伝子座 | **いちばん強く縛っている規則**(緊張 τ 最大) |
| 強さ | 固定の p<sub>m</sub> | 回転角 θ = 遊び予算の配分(停滞ほど大きい) |
| 形 | 1 ビット独立反転 | **最小違反生成子**に沿う協調反転(谷を一跨ぎ) |
| 評価 | 反転してから測る | **円環の中で重ね合わせのまま**期待適応度を測る |
| 採否 | 選択が事後に淘汰 | 違反の振幅 sin²(θ/2) がそのまま受理確率(量子メトロポリス) |
| 総量 | 無制限 | **遊び予算 Δ は保存**。多様性 H で恒常的に調節 |
| 規則 | 固定 | 破られ続けた規則は弛緩し、やがて**新しい規範に書き換わる** |

### 1 個体 1 世代の手順

1. **遵守の測定** ── 全規則 j について ⟨S<sub>j</sub>⟩ を測り、遵守度 c<sub>j</sub> = (1+⟨S<sub>j</sub>⟩)/2 を得る
2. **緊張の算出** ── τ<sub>j</sub> = w<sub>j</sub> · c<sub>j</sub> · 停滞度 · 記憶減衰。**よく守っているのに適応度が伸びない規則ほど、破る考えの価値が高い**
3. **最小違反生成子の構成** ── `{V,S_j} = 0` かつ他の規範と不可侵に対して `[V,S] = 0` なる**最小重み**の V。すなわち「**ほかの規範をすべて守ったまま、その一つだけを破る考え**」。停滞が深まるほど同時に守る規範を減らす(遊びが深くなる)が、**不可侵だけは最後まで保たれる**
4. **遊び角の配分** ── 集団の遊び予算 Δ を τ に比例配分(Σθ ≤ Δ)
5. **探る** ── ごく小さな角で候補すべてに Û(θ) を掛け、重ね合わせのまま ⟨f⟩ = cos²(θ/2)·f(順) + sin²(θ/2)·f(違) を測る。**得失の符号は θ に依らない ── 小さな角で十分に「考え」られる**
6. **決断** ── 値打ち τ·exp(Δf/T) に比例した重ね合わせから一つが選ばれ、残りの遊びを注いで観測する。損な違反ほど振幅が絞られる。得がなければ C<sup>†</sup> で完全に巻き戻し、**記憶だけが残る**
7. **規範の更新** ── 破って生き延びた規則は**その個体にとって新しい規範**になり(だから次の違反の考えが生まれる)、集団の過半がそう思えば**規則そのものが書き換わる**(制度化)
8. **遊びの恒常性** ── 多様性 H が落ちたら Δ を開き、高すぎたら締める

### 測定結果(同条件・変異の作り方だけが違う)

初期集団・地形・選択・エリート保存・評価回数・受理規則(メトロポリス)はすべて共通。n = 8・個体 16・60 世代・20 地形の平均:

| 規則系 | 最終適応度 古典 / TTM | 実行可能集合の最大への到達 | 平均到達世代 古典 → TTM |
|:--|:--|:--|:--|
| **拘束系**(不可侵 4 本) | 0.627 / **0.642** | 16/20 → **19/20** | 16.1 → **5.3** |
| **拘束系 × トラップ地形** | 0.488 / **0.500** | — | 11.2 → **4.1** |
| **鎖系**(不可侵 1 本) | **0.721** / 0.713 | **20/20** → 12/20 | — |

**なぜ効くのか。** 違反生成子は `[V, S₀] = 0` を満たすものだけが構成される ── つまり **TTM が提案する一手は、定義上つねに実行可能**である。一方、無作為なビット反転はその大半が不可侵規則を壊して棄却される。拘束が強い問題ほど、この差がそのまま探索速度の差になる。

**正直に言えば、TTM は万能ではない。** 不可侵が 1 本しかない自由な空間(鎖系)では、限られた生成子に縛られる分だけ古典的な無作為変異に負ける。遊びが力を持つのは、**破ってはならないものがはっきりしているとき**だけである ── これは実装の都合ではなく、遊びという概念そのものの帰結である。

## 📝 Bada 遊 方言の文法

```bada
qubit g0 g1 g2 g3               # 遺伝子(量子ビット)の宣言。最大 8
H/X/Y/Z q · CNOT c t            # 基本ゲート (量子 Bada 互換)
rule R1 = Z g0 Z g1 weight 1.0  # 規則(スタビライザ)と規範荷重
sacred S0 = Z g2 Z g3           # 不可侵規則。遊びの対象外・保存される
circle open budget 0.9          # 円環を開く。遊び予算 Δ
think R1 angle 0.6              # 違反思考 exp(−iθV/2)。θmax で切り詰め
tension / conform / play        # 緊張 τ / 遵守 ⟨S⟩ / 遊びの残高
state / measure                 # 状態ベクトル / 観測
circle close [keep]             # 帰還。keep なら観測して記録を残す
population 16 genes 8 k 3 seed 7 budget 1.2 [trap 4]
evolve 60                       # 違反思考変異を世代回す
norms / ledger                  # 書き換わった規範 / 遊び台帳
let x = 1+2 · print x           # 古典の変数と出力
```

## 🧪 テスト

```sh
node bada_asobi/tools/engine-test.js
```

14 節・60 以上の検査。とくに以下の**不変量**を毎回確かめる:

- **不可侵規則の保存** ── 40 回の思考列と観測を通して ⟨S₀⟩ が一度も動かないこと
- **円環の帰還 C†C = I** ── 残差 < 1e-12。遊びは外へ漏れない
- **考えは行為にならない** ── θ = π の違反思考は拒否され、状態は動かない
- **遊び予算の保存** ── 全世代で Σθ ≤ Δ
- **エリート保存** ── 最良個体の適応度は一度も下がらない
- **遊びゼロは焼き付く** ── 予算をほぼ零にすると変異が一度も確定しない
- **TTM vs 古典的無作為変異** ── 拘束系での優位と、鎖系での劣位の両方を正直に測る
