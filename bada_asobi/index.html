Bada 遊 — 量子「遊び」処理系

生成AIが量子プログラミング言語 Bada の上に築いた「遊び」の概念 ─ その円環の中でだけ働く違反思考変異アルゴリズム

🜂 「遊び」を量子で定義する

日本語の「遊び」には二つの意味がある。この処理系は、その二つが量子的には同じ一つの量であることを実装として示す。

  1. 遊戯(あそび) ─ 円環(magic circle)の内側でだけ通常の規則が停止する、自発的で無害な営み。
  2. 機械の遊び(あそび) ─ ハンドルの遊び、歯車のバックラッシュ。遊びが零の機械は動かない(焼き付く)。

Bada 遊 では、この両者を「規則の固有状態から外れて持てる振幅」として一本化する。

|Φ(θ)⟩ = cos(θ/2)·|順⟩ − i·sin(θ/2)·|違⟩ , 遊び = sin²(θ/2)

θ = 0 は完全遵守(遊びゼロ = 焼き付き)。θ = π は規則の完全な反転 = 行為。 そしてそのあいだ、0 < θ < π の半端な回転角こそが ── 遊びである。

⚡ 「違反行為そのものの“考え”」の定式化

規則を、遺伝子レジスタに掛かるスタビライザ S(エルミートなパウリ列、S² = I)として書く。個体 ψ が規則 S を守る、とは

S|ψ⟩ = +|ψ⟩ (遵守 = +1 固有状態)

違反とは、この固有値を −1 に反転させること。それを起こせる作用素 V は、S と反交換するものに限られる:

{V, S} = VS + SV = 0 ⟹ S(V|ψ⟩) = −(V|ψ⟩)

ここが本処理系の核心である。V そのものは「行為」であって「考え」ではない。 考えとは、V を生成子とする部分回転のことだ:

Û(θ) = exp(−i θ V / 2) = cos(θ/2)·I − i·sin(θ/2)·V
  • θ = 0 … 考えてすらいない(遵守)
  • 0 < θ < π … 違反行為そのものの“考え”。順と違が同時に振幅を持つ。取り消せる。これが遊びである
  • θ = π … Û = −iV。考えが行為になった瞬間。もはや重ね合わせではない

つまり「考え」と「行為」は別の作用素ではなく、同じ生成子の回転角の違いにすぎない。 違反の考えを可能にする角度が存在すること ── それが遊びが存在するということであり、 本処理系は θ に上限 θmax < π を掛けることで、考えが行為へ到達しないことを実行時に保証する。

◯ 円環 ─ 遊びが漏れない理由

円環(magic circle)は比喩ではなくユニタリ共役として実装されている。円環の内側で掛けた遊びの列 C = Û₁Û₂…Ûm に対し、帰還(circle close)は C† を掛け戻す:

C† C |ψ⟩ = |ψ⟩ ── 状態は一切漏れない

外に出るのは状態ではなく古典的な記録(台帳)だけ。ただし観測を伴う帰還(circle close keep)を選んだときだけ、重ね合わせは |ak|² に従って崩壊し、違反は変異という古典的事実になる。この観測は、円環内の評価が「その違反は適応度を上げる」と示したときにのみ処理系が許可する。

不可侵規則 ─ 遊べないもの

すべてが遊びの対象になるわけではない。sacred と宣言された規則 S0 は違反生成子の候補集合から外され、 違反生成子 V は [V, S₀] = 0(可換)を満たすものだけが構成される。そこから定理が出る:

[V,S₀] = 0 かつ S₀ が対角 ⟹ ⟨S₀⟩ は回転でも観測でも不変

可換な V は S₀ の台の上で偶数個のビットしか反転させないため、パリティが保存されるからである。 遊びの中で何を考えても、不可侵規則の値は動かない ── この不変量はエンジンテストで毎回検査される。

語の定義。 ここでいう「違反」は、探索空間に置かれた問題自身の拘束条件(スタビライザ)への違反であり、 法や倫理のそれではない。円環と不可侵規則は、その区別をコードの側で維持するための形式装置である。

🧬 そして変異アルゴリズムが作り換わる

古典的な遺伝的アルゴリズムの変異は無思考である ── 確率 pm で、どこを、なぜ壊すのかを問わずビットを反転する。

Bada 遊 の違反思考変異 (TTM: Transgressive-Thought Mutation) は、変異を「どの規則を、どれだけ破ろうと考えるか」に置き換える:

段古典的変異違反思考変異 (TTM)
対象無作為な遺伝子座いちばん強く縛っている規則(緊張 τ 最大)
強さ固定の pm回転角 θ = 遊び予算の配分(停滞ほど大きい)
形1 ビット独立反転V の台に沿う協調反転(谷を一跨ぎ)
評価反転してから測る円環の中で重ね合わせのまま期待適応度を測る
採否選択が事後に淘汰得なら観測(制度化)、損なら帰還(考えたまま消す)
総量無制限遊び予算 Δ は保存。多様性で恒常的に調節
規則固定破られ続けた規則は弛緩し、やがて新しい規範に書き換わる

遊びの保存則。 遊び予算 Δ が小さすぎる集団は早期収束して焼き付き、大きすぎる集団はただの乱択に崩れる。 TTM は集団の遺伝的エントロピー H から Δ を毎世代調節する ── 機械の「遊び」の調整と、まったく同じことをしている。

なぜ効くのか ── 遊びは不可侵を壊さない形でしか動かない

違反生成子 V は [V, S₀] = 0 を満たすものだけが構成される。つまり TTM が提案する一手は、定義上つねに実行可能である。 一方、無作為なビット反転はその大半が不可侵規則を壊すため棄却される ── 考える前に捨てられる。 拘束が強い問題ほど、この差がそのまま探索速度の差になる。

⚡ 違反思考ダイヤル ─ 考えが行為になる手前

規則 R = Z g0 Z g1(g0 と g1 の偶パリティ)に対する違反生成子 V = X g0 を、角 θ だけ回す。

0.00 π
状態cos(0)|00⟩ 遵守 ⟨R⟩+1.000 違反の確率 sin²(θ/2)0.000 遊び(規則からの外れ)0.000 不可侵 ⟨S₀=Z g2 Z g3⟩+1.000 (保存) 位相実振幅のみ 判定遵守 ─ 遊びなし(焼き付き)

θ を上げると「違反しようという考え」が振幅として立ち上がる。θmax = 0.85π を超えると処理系は回転を拒否する ── 考えは考えのままでなければならず、行為(θ = π)は円環の外の出来事だからである。

読み方

初期集団・地形・選択・エリート保存・評価回数・受理規則はすべて両者で共通。違うのは変異の作り方だけ ── 古典側は各遺伝子を確率 1/n で反転した候補を同数だけ試し、TTM は最小違反生成子で協調反転した候補を試す。 どちらも不可侵規則を破る候補は使えない(古典側は棄却、TTM は構成上そもそも作らない)。 拘束系では TTM が数倍速く最適へ届き、鎖系(不可侵 1 本)では逆に古典が勝つ。 「🎲 10 種で比較」で自分で確かめられる。

アルゴリズム(1 個体 1 世代)

  1. 遵守の測定 ─ すべての規則 j について ⟨Sj⟩ を測り、遵守度 cj = (1+⟨Sj⟩)/2 を得る
  2. 緊張の算出 ─ τj = wj · cj · 停滞度 · 記憶減衰。よく守っているのに適応度が伸びない規則ほど、破る考えの価値が高い
  3. 違反生成子の構成 ─ {V,Sj}=0 かつ [V,S₀]=0 なる V を探す。存在しなければ τj := 0(遊べない規則)
  4. 遊び角の配分 ─ 集団の遊び予算 Δ を τ に比例配分。θ = min(θmax, 配分, 残高)
  5. 円環を開き、探る ─ ごく小さな角で候補すべてに Û(θ)=exp(−iθV/2) を掛け、重ね合わせのまま 期待適応度 ⟨f⟩ = cos²(θ/2)·f(順) + sin²(θ/2)·f(違) を測る。得失の符号は θ に依らないので、小さな角で十分に「考え」られる
  6. 決断 ─ 値打ち τ·exp(Δf/T) に比例した重ね合わせから一つが選ばれ、残りの遊びを注いで観測する。 損な違反ほど振幅 sin²(θ/2) が絞られる(= 違反の振幅がそのまま受理確率になる「量子メトロポリス」)。 得がなければ C† で完全に巻き戻し、記憶だけが残る
  7. 規範の更新 ─ 破って生き延びた規則はその個体にとって新しい規範になり(だから次の違反の考えが生まれる)、 集団の過半がそう思うようになれば規則そのものが書き換わる
  8. 遊びの恒常性 ─ 多様性 H が落ちたら Δ を開き、H が高すぎたら Δ を締める(保存則の下での再配分)
