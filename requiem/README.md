# 🕯 Requiem — 提出された録音から生成したレクイエム (MP4)

**提出された 4 本の録音 (MP3 / AAC) を素材に、レクイエム (死者のためのミサ曲) を 1 曲、生成した。** 出力は音声付きの **MP4 動画** ([`requiem.mp4`](requiem.mp4) — 1280×720 / H.264 + AAC / 約 9 分 12 秒)。生成は Python スクリプト [`make_requiem.py`](make_requiem.py) が行い、同じ入力からは必ず同じ曲が出来る (乱数 seed 固定)。生成 AI の即興ではなく、**信号処理と作曲の規則だけ**で組み立てている。

## 🎼 構成 — レクイエム典礼文の 5 楽章 (ヘ短調)

| 時刻 | 楽章 | 内容 |
|:----|:----|:----|
| 0:00 | **I. Introitus** — *Requiem aeternam* | F のオルガン・ドローンと風 (8 秒の録音を引き延ばした「息」)、鐘。いちばん静かな録音を 2.6 倍に引き延ばし、朧げに浮かべる |
| 1:32 | **II. Kyrie** — *Kyrie eleison* | 調性のはっきりした 30 秒を 1.6 倍に引き延ばし、**4 声のカノン** (原調 / 4 度下 / 1 オクターブ下 / 5 度上) として 14 秒ずつ追いかけさせる。低音は i–VI–V–i、4 秒ごとの心拍 |
| 3:20 | **III. Dies irae** — *Dies irae, dies illa* | いちばん鳴っている録音を原速のまま、歪みと 8 分音符のゲートで「息詰まる刻み」に。1 オクターブ下の影、上の叫び、4 分音符の鼓動、**三全音 F–B (diabolus in musica) の鐘**。最後は鐘一打で断絶 |
| 5:00 | **IV. Lacrimosa** — *Lacrimosa dies illa* | 低音が**嘆きのテトラコルド F–E♭–D♭–C** を下降。主題を 3 倍に引き延ばし 1 オクターブ下げた「涙」、静かな録音の**逆再生リバーブ**が吸い込まれるように立ち上がる |
| 7:08 | **V. Lux aeterna** — *Lux aeterna luceat eis* | いちばん鳴っている録音の一瞬を**グラニュラー・フリーズ**で持続音にした「合唱」(原調 / 5 度上 / 1 オクターブ上のシマー)。D♭–A♭–F と進み、最後に長三度 A を重ねる **ピカルディの三度** (短調 → 長調 = 光) で閉じる |

## ⚙ 仕組み (make_requiem.py)

1. **復号** — ffmpeg で全ファイルをモノラル 44.1 kHz float に。
2. **解析** — 1 秒刻みの音量とクロマ (12 音の分布) を求め、**Krumhansl–Kessler 調性プロファイル**で各録音の調を推定。レクイエムの調 (ヘ短調 / 変イ長調) に最も近づく移調量 (半音) を決める。区間選びは「よく鳴っていて調性のはっきりした所」「静かだが鳴っている所」を点数化し、同じ区間を使い回さないようにする。20 秒未満 / 非常に小さい録音は音楽ではなく「風・息」のテクスチャとして扱う。
3. **変換** (numpy / scipy のみで実装)
   - **フェーズボコーダ** タイムストレッチ (STFT 2048 / hop 512、位相を累積) と、それを使った**ピッチシフト** (ストレッチ → 多相リサンプル)
   - **畳み込みリバーブ** — 指数減衰ノイズ + 初期反射の合成インパルス応答 (高域ほど早く減衰)、左右で別の IR
   - **逆再生リバーブ**、**グラニュラー・フリーズ** (140 ms グレイン)、**ゲート**、**サチュレーション**、トレモロ
   - 合成音: 加算合成の**オルガン・ドローン** (倍音を左右で微妙にデチューン)、非整数次倍音の**鐘**、サブベースの**鼓動**
4. **ミックス** — 定パワーパン、Haas による広がり、30 Hz ハイパス、高域シェルフ、ソフトリミッタ、ピーク −1 dBFS 正規化。
5. **映像** — ffmpeg の `showcqt` (定 Q 変換スペクトル: 低音 = 金色の炎 → 高音 = 青白い光) を金色に色調整し、Pillow で描いたタイトルカード (楽章名 / ラテン語典礼文 / 日本語) を `overlay` で重ねて **libx264 + AAC** の MP4 に。

## 🚀 使い方

```
pip install numpy scipy pillow imageio-ffmpeg   # ffmpeg が PATH にあれば imageio-ffmpeg は不要
python3 requiem/make_requiem.py a.mp3 b.mp3 c.mp3 d.mp3 -o requiem.mp4
```

| オプション | 意味 |
|:--|:--|
| `-o FILE` | 出力 MP4 (既定 `requiem.mp4`) |
| `--wav FILE` | ミックスの WAV も残す |
| `--no-video` | WAV のみ生成 |
| `--size 1920x1080` / `--fps 30` / `--crf 29` | 映像の解像度 / フレームレート / 画質 (小さいほど高画質・大容量) |
| `--seed N` | 乱数 seed (グレインや心拍の揺らぎが変わる) |
| `--title TEXT` | タイトルカードの文字 |

入力は ffmpeg が読める音声なら何でもよい (MP3 / M4A / AAC / WAV / FLAC / OGG)。本数は 1 本以上、多いほど役割 (静かな曲 / 中庸の曲 / いちばん鳴る曲 / 風) が分かれる。素材の録音そのものはリポジトリに含めていない。
