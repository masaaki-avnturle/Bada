# ⚗ Bada Pharma — 薬剤製造装置

これまでに作った**計測器アプリ**の読みを一本のプロファイルに束ね、**標的同定 → 分子設計 → 逆合成 → 製剤化 → 薬物動態 → 品質管理 → 製造記録**までを通す、**8 段の製造ラインのシミュレータ**。依存ゼロ・単一 HTML・オフライン動作。

> ⚠ **概念シミュレーション・非医療・実製造不可** — 実在の人体も検体も計測せず、合成データ上の数値実験だけを行います。**試薬・反応条件・操作手順は一切出力しません**(逆合成は収率と原子効率の計画だけを扱う抽象モデルです)。医薬品の製造は**薬機法と GMP** に基づく許可と設備が必要で、本アプリはその代わりにはなりません。診断・治療・投薬の判断にも使えません。**薬の内容・量・継続や中止は必ず主治医にご相談ください。**

## 📡 ① 計測取込 — これまでの計測器アプリを束ねる

| モダリティ | 単位 | 参照範囲 | 由来アプリ |
|:--|:--|:--|:--|
| MRI | コントラスト比 | 0.2 – 1.4 | [`bio_medicine/omega_tomograph`](../bio_medicine/omega_tomograph/)(ラドン変換 + FBP) |
| fMRI | BOLD %変化 | 0.1 – 3.0 | 同上 |
| DNA 解析 | 変異負荷 | 0.0 – 1.0 | [`bada_serenace`](../bada_serenace/)(塩基 ↦ 組み紐 ↦ Jones 指紋) |

各読みを参照範囲で 0–1 に正規化し、**Γ 大域的部分積分多様体**から来る熱核 k(r) = ½ + ½e<sup>−κ·r log r</sup> を重みにして総合負荷を出します。半数以上のモダリティが揃って初めて次段へ進みます。

## 🎯 ② 標的同定

6 つの標的(D2 受容体 / DRD2 転写産物 / COX-2 / GABA-A / セロトニン輸送体 / HMG-CoA 還元酵素)が 7 モダリティ上の署名ベクトルを持ち、**平均を抜いたコサイン類似度(= ピアソン相関)**で照合します。生のコサインは成分がすべて正のため軒並み 0.9 を超えて見分けがつかないので、形だけを見ます。

- CRP が高く熱流束の大きい計測 → **COX-2**(相関 0.99)
- 血液寄りで熱の低い計測 → **HMG-CoA 還元酵素**
- fMRI・脳電磁場・脳トポグラフィーが高い計測 → **D2 受容体 と DRD2 転写産物が拮抗** → 上流(RNA 干渉)と下流(受容体遮断)を**並行して設計**するよう促します(Bada Serenace の主題そのもの)

## 🧩 ③ 分子設計 — 積み木から分子へ

20 種のフラグメント(積み木)から分子式・分子量・logP・TPSA・水素結合供与/受容数・回転可能結合数を積み上げ、**Lipinski の Rule of Five** と **Veber 則**、望ましさ指標で評価します。分子量は標準原子量からの計算で、既知の医薬品を正確に再現します。

| 参照医薬品 | 積み木 | 得られる分子式 | 分子量 |
|:--|:--|:--|:--|
| アスピリン | フェニル + カルボキシル + アセチルオキシ | C9H8O4 | 180.16 |
| パラセタモール | フェニル + ヒドロキシル + アセトアミド | C8H9NO2 | 151.16 |
| **ハロペリドール(セレネース)** | フェニル + フッ素 + ケトン + メチレン×3 + 4,4-二置換ピペリジン + ヒドロキシル + フェニル + 塩素 | **C21H23ClFNO2** | **375.86** |

logP はフラグメント和による粗い近似で、実測値とは数値がずれます(ハロペリドールで 5.9、実測 ≈ 4.3)。順位付けの目安として使ってください。

## 🔁 ④ 逆合成 — 積み木の真逆

組み上げが「積み木 ↦ 分子」なら、逆合成はその**逆像**です。末端の積み木から順に切り離し、各切り口に対応する結合形成の収率を掛けて**通算収率**を、脱離分子の質量から**原子効率**を出します。

> **この装置は収率・原子効率・工程数の計画だけを扱います。試薬・溶媒・温度・触媒・操作手順の欄は構造として持たず、出力もしません。**(テストでも各工程がそれらの欄を持たないことを検証しています。)

線形に切ると工程が伸びて通算収率が落ちることが数で見えます。ハロペリドール相当の分子は 9 工程・通算収率 8.8% で、100 g の製品に 1.1 kg の原薬仕込みが要る、という具合です。

## 💊 ⑤ 製剤化

原薬 + 充填剤 + 崩壊剤 + 結合剤 + 滑沢剤 の**質量収支が閉じる**ことを確かめ、溶出を **Weibull 式** F(t) = 1 − exp(−(t/τ)<sup>β</sup>) で描きます(τ は 63.2% 溶出時間)。崩壊剤を増やすと τ が短くなり、30 分での溶出規格 Q80 の適合/不適合が切り替わります。**Noyes–Whitney 式** dC/dt = k(C<sub>s</sub> − C) も併せて実装しています。

## 📈 ⑥ 薬物動態

1 コンパートメント・一次吸収モデル:

C(t) = F·D·k<sub>a</sub> / (V(k<sub>a</sub> − k<sub>e</sub>)) · (e<sup>−k<sub>e</sub>t</sup> − e<sup>−k<sub>a</sub>t</sup>)

| 量 | 式 | 検証 |
|:--|:--|:--|
| T<sub>max</sub> | ln(k<sub>a</sub>/k<sub>e</sub>)/(k<sub>a</sub> − k<sub>e</sub>) | 数値探索の最大点と一致 |
| AUC | F·D/(V·k<sub>e</sub>) | 刻み 0.001 h の数値積分と一致 |
| t½ | ln2/k<sub>e</sub> | — |
| 蓄積率 R | 1/(1 − e<sup>−k<sub>e</sub>τ</sup>) | 重ね合わせと整合 |

反復投与は単回の重ね合わせで描き、C<sub>max</sub> での受容体占有を **Bada Serenace と同じ目盛り**(応答域 65–80%)で表示します。用量の助言ではありません。

## 🔬 ⑦ 品質管理

- **含量均一性** — 判定値 **AV = |M − X̄| + k·s**(n ≤ 10 で k = 2.4、L1 = 15)。平均が 98.5–101.5% の内なら M は平均そのもの、外れれば境界に固定されます。
- **工程能力** — C<sub>p</sub> = (USL − LSL)/6σ、C<sub>pk</sub> = min(USL − μ, μ − LSL)/3σ。C<sub>pk</sub> ≥ 1.33 を目安に判定。
- **検量線** — 最小二乗で傾き・切片・R²。R² ≥ 0.99 を直線性の目安に。

## 📋 ⑧ 製造記録

製剤の組成と通算収率から、必要な原薬の**仕込み量**と**工程損失**を計算し、決定的な**ロット番号**(BP-XX-00000)と**記録指紋**(内容が 1 文字変われば変わる 8 桁 16 進)を付けます。

## 🏭 製造ライン
