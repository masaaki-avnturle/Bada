# 🎚 Bada AudioForge — オーディオエディタ

**音声ファイルを波形で編集するソフト。** MP3 などを読み込んで波形を表示し、ドラッグで範囲を選んで切り取り・貼り付け、フェードやノーマライズなどのエフェクトをかけ、WAV で書き出します。依存ゼロ・単一 HTML・完全オフライン動作。読み込んだ音声が端末の外に出ることは一切ありません。

## ✨ できること

### 読み込み
MP3 / WAV / OGG / M4A / FLAC / WebM(ブラウザがデコードできる音声全般)。**WAV は自前パーサで読むためデコード誤差がありません。**

### 編集
- **範囲選択** — 波形をドラッグ(マウス / 指)。ダブルタップで全選択。秒数を直接入力しても指定できます
- **ゼロクロス スナップ** — 選択端を波形がゼロを横切る点へ自動で吸着。切り貼りの「プチッ」というノイズを防ぎます
- **切り取り / コピー / 貼り付け(挿入・ミックス)/ 削除 / 切り抜き / 無音化**
- **繰り返し** — 選択範囲を指定回数に増やす(ループ素材づくり)
- **無音挿入** — カーソル位置に指定秒数の無音を差し込む
- **元に戻す / やり直し** — 30 段の履歴

### エフェクト(選択範囲、未選択なら全体に適用)
| 効果 | 内容 |
|:---|:---|
| **音量** | dB 指定でゲイン調整(クリップ保護つき) |
| **ノーマライズ** | ピークを指定 dB(既定 -1 dB)に合わせる |
| **フェードイン / アウト** | リニア / S カーブ / 指数の 3 カーブ |
| **逆再生** | 選択範囲を前後反転 |
| **速度変更** | 0.25〜4 倍(リサンプル方式 — 音程も一緒に変わります) |
| **エコー** | 遅延(秒)と減衰を指定するフィードバック山びこ |
| **フィルタ** | ローパス(高音カット)/ ハイパス(低音カット)、カットオフ周波数指定 |
| **DC オフセット除去** | 直流成分(波形の上下の偏り)を取り除く |
| **パン** | 定パワー パン(ステレオ) |
| **モノラル化** | 全チャンネルを 1ch に混合 |
| **無音トリム** | 前後の無音をしきい値(dB)で自動除去 |

### 解析・再生
選択範囲の**ピーク / RMS を dB 表示**し、クリッピングの警告と「あと何 dB 上げられるか」を表示。再生・選択範囲のみ再生・ループ再生に対応し、再生位置を波形上に表示します。

### 書き出し
- **WAV 16bit PCM / 24bit PCM / 32bit float** — すべて自前エンコーダ(外部ライブラリなし)
- **サンプルレート変換** — 48000 / 44100 / 32000 / 22050 / 16000 Hz
- **全体 または 選択範囲のみ** を書き出し。推定ファイルサイズを事前表示
- **圧縮書き出し**(M4A/AAC・WebM/Opus)— 環境が対応していれば選べます(リアルタイム録音のため音声と同じ時間がかかります)

## ⌨ ショートカット

| キー | 動作 |
|:---|:---|
| `Space` | 再生 / 停止 |
| `Ctrl+Z` / `Ctrl+Y`(`Ctrl+Shift+Z`) | 元に戻す / やり直し |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 切り取り / コピー / 貼り付け |
| `Delete` | 選択範囲を削除 |
| `Ctrl+A` | 全選択 |
| `Ctrl+S` | WAV で保存 |
| ホイール | 波形のズーム(ポインタ位置を中心に) |

## ⚙ 仕組み

音声は AudioBuffer ではなく、素の `{ sampleRate, channels:[Float32Array,…] }`(Clip)として保持し、すべての編集をこの Clip 上の**純粋関数**として実装しています。そのため DOM も Web Audio も使わずに Node 単体テストで全機能を検証できます。

1. 読み込み — WAV は自前 `parseWav`(PCM 8/16/24/32bit・IEEE float 対応)、それ以外は `decodeAudioData`
2. 描画 — `channelPeaks` で表示幅ぶんの min/max に集計(縮小時)、拡大時はサンプル点を折れ線で描画
3. 編集 — `sliceClip` / `deleteRange` / `insertClip` / `mixClip` などが常に新しい Clip を返す(非破壊 → 履歴がそのまま Undo に)
4. 効果 — ゲイン・フェード・1 次 IIR フィルタ・フィードバック遅延をサンプル単位で適用
5. 再生 — Clip → `AudioBuffer` → `AudioBufferSourceNode`(ループは `loopStart`/`loopEnd`)
6. 書き出し — `encodeWav` が RIFF/WAVE ヘッダごと組み立て、`Blob` として保存

## 🚀 使い方

1. [`index.html`](index.html) を「Download raw file」で保存 → ダブルクリック(インストール不要)
2. 音声をドロップ → 波形をドラッグで選択 → 編集・効果 → **💾 WAV で保存**
3. または [Releases](https://github.com/masaaki-avnturle/Bada/releases) から:

| プラットフォーム | ファイル |
|:---|:---|
| **Android** (APK) | `bada-audioforge-debug.apk` |
| **Windows 10 / 11** | `BadaAudioForge-*-x64.exe`(NSIS インストーラ / ポータブル) |
| **Ubuntu** | `BadaAudioForge-*-x86_64.AppImage` / `BadaAudioForge-*-amd64.deb` |

ビルドは [`audioeditor-app-build.yml`](../.github/workflows/audioeditor-app-build.yml) が実行します(`audioforge-v*` タグで Release へ添付 / `workflow_dispatch` で Actions アーティファクト)。

## 🧪 テスト

```
node audio_editor/tools/engine-test.js
```

167 項目の Node 単体テストで、整形(fmtTime / fmtBytes / fmtDb)、dB 変換、Clip 操作(slice / delete / insert / mix / repeat / チャンネル整合)、リサンプルと速度変更、振幅(peak / RMS / ゲイン / ノーマライズ)、エフェクト(フェード 3 カーブ / 逆再生 / DC 除去 / パン / モノラル化)、フィルタとエコー、無音トリムとゼロクロス探索、描画補助(ピーク集計 / 目盛り刻み)、**WAV の 16/24/32bit ラウンドトリップ**を検証します。

## 📝 制限

- 速度変更はリサンプル方式のため、**音程も一緒に変わります**(タイムストレッチではありません)
- 圧縮書き出しは `MediaRecorder` のリアルタイム録音です。無劣化・即時に保存したい場合は WAV を使ってください
- MP3 での書き出しには対応していません(エンコーダを同梱しないため)。WAV で保存して別途変換してください
