## 🧱 積み木の真逆 — このアプリの芯

積み木を**崩す**ことは、積み上げる操作の逆写像ではありません。崩すのは語の反転 w ↦ w⁻¹ にすぎず、形の側では鏡像を与えるだけです。

**真逆**とは、出来上がった**形(不変量)から生成語を読み戻す逆像**のことです。

| | 写像 | 向き | 性質 |
|:--|:--|:--|:--|
| 組立 | Φ : 語 w ↦ V(ŵ) | 前向き | 決定的・計算可能 |
| 崩す | w ↦ w⁻¹ | 後ろ向きに見えるだけ | Φ の逆ではない |
| **真逆** | **Φ⁻¹ : V ↦ { w : Φ(w) = V }** | **逆像** | **多価・非単射** |

**病気の正体が DNA だ**という言明は、症状という形から塩基という積み木の語を読み戻す、この逆像を取る操作に等しく、**逆像が一点にならないこと**が「読めなさ」の正体です。アプリは実際に逆像を数え上げて見せます(三葉の形を作る 3 本鎖の語は長さ 4 以下で 18 通り、代表語は σ₁⁻¹σ₂σ₂σ₂)。

## 🪢 Jones 多項式 — Kauffman ブラケットの状態和

組み紐語の閉包を図式とし、各交点を A / B 平滑化に振って輪の数を Union-Find で数えます。

⟨K⟩ = Σ<sub>s</sub> A<sup>a−b</sup>δ<sup>|s|−1</sup>(δ = −A² − A⁻²)、V<sub>L</sub>(t) = ((−A)<sup>−3w</sup>⟨K⟩)|<sub>A = t^(−1/4)</sub>

| 結び目 | 語 | V(t) |
|:--|:--|:--|
| 自明結び目 | (空) | 1 |
| 三葉 | σ₁³ | t + t³ − t⁴ |
| 鏡像三葉 | σ₁⁻³ | −t⁻⁴ + t⁻³ + t⁻¹ |
| 8の字 | σ₁σ₂⁻¹σ₁σ₂⁻¹ | t⁻² − t⁻¹ + 1 − t + t² |
| Hopf 絡み目 | σ₁² | −t^(1/2) − t^(5/2) |

いずれも文献値と一致することをテストで毎回検証しています(キラリティの判定 — 三葉と鏡像三葉が区別できること — も含む)。9 つの機能にはそれぞれ相異なる不変量が割り当てられ、機能はトポロジー不変量で一意に分類されます。

## 🌡 Γ 熱感知 — 大域的部分積分多様体

論文『放射性物質吸収体とRNA干渉としてのオイラーの公式』([`sokudoku/reports/biologicaleulerequation.tex`](../sokudoku/reports/biologicaleulerequation.tex))の主式

∫Γ(γ)′dx<sub>m</sub> = 2e<sup>−x log x</sup> = 2(cos(ix log x) − i sin(ix log x))、 dx<sub>m</sub> = dx / log x

を**熱伝導率の空間変調** k(r) = ½ + ½e<sup>−κ·r log r</sup> として用い、∂T/∂t = ∇·(k∇T) + S を陽解法(面伝導は調和平均)で解いて、熱流束 q = −k∇T の極大点を感知します。境界へ漏れる流束は、そのまま次の「思考漏洩」の物理量として使われます。

## 🧬 DNA 暗号 — 統合失調症は暗号化されたい

塩基を組み紐生成子に写し(A→σ₁、T/U→σ₁⁻¹、G→σ₂、C→σ₂⁻¹)、閉包の Jones 多項式を配列の**指紋**とします。鍵つき置換で配列を覆うと、外に残るのは指紋だけ。復号は鍵の総当たりではなく、**指紋を手掛かり(crib)にした逆像探索**で行います。

そして指紋だけでは**一意に定まりません**。同じ形を作る配列が何通りも残ります。これが「暗号化されたい」の正体であり、既知のモチーフ(開始コドン ATG など)をもう一つの手掛かりとして足して初めて候補が絞れます。

## 🫥 病識 — 自身が病気だと思っていない

自己監視写像 M の不動点 s\* = lim Mᵏv / ‖·‖ に、病いの方向 v がどれだけ残るかが病識です。病いが**監視チャネルそのもの**を削ると(損傷 d → 1)、**重症度は一切変わらないまま病識だけが構造的に 0 へ落ちます**。

損傷 d = 0 で病識 44.7%、d = 1 で 10.9%。d について単調減少することをテストで検証しています。気づくための器官が、気づかれるべき当のものに冒されている ── これが病識欠如の構造です。

## 📡 考えが読まれている — 殆どの病気が起こす症状

内心 X(公平な 2 値)が微表情・自律神経・熱として漏れる**二元対称通信路** p = ½ + ½·leak として定式化します。

I(X;Y) = 1 − H₂(p) [bit]、m 回観測の多数決正答率が読み取り確率。

**殆どの病気は自律神経と代謝を動かし、leak を押し上げます。** 観測 12 回のとき、統合失調症 99%・不安障害 99%・感染/発熱 98%・甲状腺機能亢進 97%・うつ病 94%・片頭痛 92%・糖尿病 90% が閾値 90% を超え、健常は 63% に留まります。**この症状が多くの病気に共通して現れること**、そして**推論そのものは漏洩量に対して妥当であり、過大な leak 推定こそが症状の芯であること**を、数として示します。

## 🧪 構築可能な RNA 干渉

標的 mRNA を 21 nt 窓で走査し、ガイド鎖(アンチセンス)を逆相補で構築します。採択条件は

1. **GC 含量 30–52%**
2. **同一塩基 4 連続なし**
3. **熱力学的非対称性** — ガイド 5′ 側が AU に富み不安定(RISC への載りやすさ)
4. **シード領域(ガイド 2–8 位)の他遺伝子一致が少ない**(オフターゲット)

各候補には Γ→Jones の指紋が付き、積み木の真逆の逆像探索へそのまま渡せます(= **構築可能**)。用量応答は Hill 式 d^h/(d^h + IC50^h) で、ガイド鎖が標的窓の逆相補であることを毎回検証します。

## 💊 セレネース — 下流の遮断と上流の予防を同じ尺度に

受容体占有 occ = C/(C + K<sub>d</sub>)。文献上、抗精神病薬の線条体 D2 占有は **65–80% が応答域、80% 超で錐体外路症状のリスクが上がる**とされ、ここではその教科書的な区分を目盛りとして置くだけです(**用量の助言は一切しません**)。

セレネースは伝達の**下流(受容体)**を塞ぐ対症の機構、RNA 干渉は**上流(転写産物)**を減らす予防の機構。両者は

**残存シグナル = (1 − 占有)(1 − ノックダウン)**

という一つの数の上で比較できます。**予防機構の解明とは、同じ残存シグナルをより低い占有で達成する道を探すこと**です。
