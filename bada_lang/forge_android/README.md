# Bada Forge — Android app (APK)

An Android app that hosts the **Bada Forge** source auto-correction IDE in a
WebView.  The IDE is generated by the Bada program
[`apps/bada_forge.bada`](../apps/bada_forge.bada) and embeds the
integrable-system / spinning-top error-correction engine
([`lib/forge.bada`](../lib/forge.bada)) as JavaScript, so it auto-fixes broken
Bada source entirely on-device.

## What it does

- Edit Bada source in the editor.
- The **invariant defect** — bracket/quote balance treated as a spinning-top
  conserved *angular momentum* `L = (paren, square, brace)` plus quote parity —
  is shown live; a valid program has defect 0 (it sits on the valid-syntax
  manifold).
- **Forge auto-fix** applies damped "precession" corrections (close strings,
  balance brackets, `=`→`<-`) that drive the defect to zero, re-projecting the
  code onto the manifold — the classical analogue of quantum error correction
  projecting back into the code space.

## Build the APK

The Android **SDK download is blocked in the Bada cloud sandbox**
(`dl.google.com` is not in the network allowlist), so the APK is built on a
machine that has the SDK:

```bash
export ANDROID_HOME=/path/to/Android/Sdk      # has platform-34 + build-tools-34
cd forge_android
./build_apk.sh
# -> app/build/outputs/apk/debug/app-debug.apk
```

`gradle` (8+) and JDK 17+ are already present in the sandbox; only the Android
SDK component is missing here.

To refresh the embedded IDE from the Bada source before building:

```bash
cd ..
./bada run apps/bada_forge.bada
cp bada_forge.html forge_android/app/src/main/assets/index.html
```
