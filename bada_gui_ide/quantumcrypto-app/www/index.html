🔐Bada QuantumCrypto

Jones 多項式量子暗号 — テキストとファイルを暗号化し、パスフレーズで解除(復号)します。
鍵は結び目図の Kauffman ブラケット標本 (jones_key) とパスフレーズから導出、 Bell 対 QKD がセッションソルトを採取し、本文は ChaCha20 + HMAC-SHA256 の AEAD で封緘。 改ざんや誤鍵は 409 zone-guard-reject として拒否されます。すべて端末内で完結(通信なし)。
タップ / クリックしてファイルを選択
(どんな形式でも可 — 暗号化は任意ファイル、解除は .badaqc / アーマーテキスト)
