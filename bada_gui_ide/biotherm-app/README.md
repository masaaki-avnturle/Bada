# BioThermNet (知的生命体 熱感知ネットワーク) — ネイティブ アプリ

発見済み惑星をノードとする機知ネットワーク: Γ関数の大域的(部分)積分多様体が網の総熱量
(大域積分 Q=ΣP_bio)を、微分多様体が各ノードの熱勾配 d|V|/dθ (三つ葉Jones多項式)を与える。
各惑星の実測物理(クライバーの法則・シュテファン=ボルツマン放熱面積・アレンの法則・
g=R^1.58g⊕・恒星色)から知的生命体の姿を決定論的に描画し、PNG保存できる。
正直な前提: 2026年時点で地球外の知的生命体は一体も検出されていない(冒頭に明記)。
