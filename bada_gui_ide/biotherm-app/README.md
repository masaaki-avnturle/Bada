# BioThermNet (人間に近い生命体ファインダー) — ネイティブ アプリ

人間と同型の生命体が成立し、子孫(世代)を残し続けられる惑星を発見する機知ネットワーク。
ヒト同型度 HIS = Γ部分積分恒等式で正規化した実測5項(重力・温度・日射・恒星色・導出体重)。
子孫継続性 = 恒星の主系列寿命 t_MS=10·(M★/M☉)^-2.5 Gyr と地球の実績(知的生命まで45億年・
1世代25年)から可能世代数を実計算(近接M矮星は潮汐固定・フレアで減点)。実測物理
(クライバー・シュテファン=ボルツマン・アレンの法則)から親と第1世代の子孫を決定論的に
描画し PNG 保存。🔭熱感知スキャン: Jones多項式 |V(e^{iθ})| の θ 掃引 (低温→高温) で
惑星を感知しながらΓ部分積分 ∫|V|dθ を積算、人間モデル並み判定 (HIS≥75%・体重35–140kg・
代謝40–170W・恒星寿命≥4.5Gyr) を通過した惑星を★発見として記録。🛰NASA確定惑星カタログへの
ライブ探索つき (オフライン時はスナップショット)。🧍姿スキャン: 発見された人間並みモデルの
姿を走査ビームで上から確定させながら再生 (部位ごとに導出値コールアウト)、★発見全員の姿を
ギャラリーで一覧・クリック再生。🎨画風切替: 標準デッサン / モネ風 (寒色パステル・破れた色触) /
ルノワール風 (暖色の柔らかい筆致) の印象派レンダリング — 筆致はシード付き乱数で決定論的。
正直な前提: 「発見」は惑星の特定であり生命体の検出ではない・2026年時点で検出ゼロ(冒頭に明記)。
