# Modem Vault — 量子暗号パスワード保管庫 + LANモデム検出

**あなた自身の**モデム/ルーターの認証情報を、以前作った **Jones 多項式量子暗号**
(`omega_jones_crypto` / zone:// と同じ構成)で暗号化して手元に保管し、必要な
ときにマスターパスワードで復号表示するアプリです。あわせて、自分の LAN の
モデム(ゲートウェイ)を検出する補助機能を備えます。すべてローカル・オフラインで
動作します。

## できること / できないこと

できること(自分の機器のため):
- **量子暗号パスワード保管庫** — 自分で入力した「型番＋パスコード(WiFiキーや
  管理パスワード)」を Jones 量子暗号 AEAD で暗号化して `localStorage` に保存。
  マスターパスワード(＝結び目→Jones 鍵)でのみ復号表示。誤ったマスターは
  AEAD タグ照合に失敗して復号できません。
- **LANモデム検出** — 自分の PC の IP(WebRTC)から推定ゲートウェイと管理URLを
  提示。MAC の OUI 照合でメーカーを推定。確実な検出は CLI が担当。

**できないこと(意図的に非対応)**:
- 型番・MAC・SSID・シリアルから**パスコードを割り出す/照合する**こと。
- 他人の機器の認証情報を表示すること。
- 既定認証情報データベースや WiFi キー生成器。

このアプリは**あなたが自分で入力した内容だけ**を暗号化して保管します。型番は
単なるラベル(索引)で、そこから秘密は一切導きません。モデムのパスワードは
LAN 上のどのプロトコルでも配信されないため、「型番から自動表示」は原理的に
できません。

## ファイル

```
modemvault/
  modemvault-lib.bada   Jones 量子暗号による vault_seal / vault_open (Bada)
  oui.json              MAC先頭3オクテット -> メーカー 推定表(ベンダー識別のみ)
  cli/modem-scan.js     LANのゲートウェイIP/MAC/ベンダー/管理URLを実検出(Node)
```

生成物: `../dist/modem-vault.html`(単一自己完結HTML)。
`node ../tools/build-modemvault.js` で生成します。

## 使い方

```sh
# アプリ(保管庫 + LAN補助)を生成して開く
node bada_gui_ide/tools/build-modemvault.js
# → bada_gui_ide/dist/modem-vault.html をブラウザで開く

# 自分のLANのモデム(ゲートウェイ)を実検出(パスワードは表示しません)
node bada_gui_ide/modemvault/cli/modem-scan.js
```

1. 初回はマスターパスワードを設定 → 保管庫が作成されます。
2. 「モデム認証情報を追加」で型番・パスコード(・任意でIP/MAC)を保存。
3. 一覧の「パスコード表示」でマスターで復号表示。「ロック」でメモリから鍵を破棄。
4. 「LAN検出」タブで自分のIP・推定ゲートウェイ・管理URL・MACメーカーを確認。

セキュリティ:
- 鍵はマスターパスワードから結び目図を編み、その Kauffman/Jones 多項式標本を
  ハッシュして導出(`vault_key`)。本文は鍵ストリーム AEAD で封緘。
- マスターパスワードはどこにも保存されません(復号時のみメモリ上)。
- 暗号文と索引のみ `localStorage` に残ります。
