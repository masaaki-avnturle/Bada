# HeatSense (未知の伝達チャネル模索シアター) — ネイティブ アプリ

廃熱赤外(ダイソン球探索)・ニュートリノ・アクシオン・宇宙線の実在の模索を、地上の探索地点
(神岡・南極点・フェルミ研等)と天球ターゲット(タビーの星・M31等)のズーム動画で見る。
量子もつれは no-communication 定理により伝達不可、と正直に明記。

| プラットフォーム | ファイル |
|---|---|
| Windows 10 / 11 | `HeatSense-*-x64.exe` |
| Ubuntu | `HeatSense-*-x86_64.AppImage` / `*-amd64.deb` |
| Android | `heatsense-debug.apk` |

ビルドは [`space-apps-build.yml`](../../.github/workflows/space-apps-build.yml) (Artifacts: spaceapps-*)。
