# AquaVita (命の水・命の樹アトラス) — ネイティブ アプリ

宇宙に実在する「命の水」(クエーサー APM 08279+5255 の地球の海の140兆倍の水蒸気・
銀河系の水メーザー・エンケラドス/エウロパの地下の海・系外惑星大気の水) と
「命の樹」(創造の柱の樹状構造・いて座B2の糖・リュウグウ試料のウラシル=RNA塩基・
ベンヌ試料の全5種の核酸塩基) — 14地点の実座標・周辺に何があるか・映像
(DSS2実写の視野ズーム / 太陽系天体はプロシージャル) を、Γ関数の大域的部分積分
多様体の分析 (∫₀^θ|V|dθ' のライブ積算) と Jones多項式の熱感知 (各地点の実測温度→θ)
で調べる。.webm 録画つき。神話の泉や樹そのものが見つかったわけではない、と冒頭に明記。
