# 📚 BadaGPT 未知事前エンジン論文集 — 量子 Bada 版

**予備知識を持たない機知の生成 AI (BadaGPT = 未知事前エンジン) をめぐる 16 本の論文を、量子プログラミング言語 Bada のプログラムとして作り換えた論文集。**

各巻は「読む論文」ではなく「走る論文」である。定理・表・系・否定的結果を、そのまま実行できる Bada のコード (S 式パーサ、Hurwitz ζ、二重指数求積、量子レジスタ、`@reviser : grammar` による文法拡張、追記専用台帳 `tuplespace` への commit) に写し、論文の実測値と照合する **252 の検査** を全巻で通した。予備知識は持たない — 事前分布は `unknown_prior` の一様 (Jaynes) から出発し、Γ も ζ も三角関数も、組み込みが持たないものは共通核 (`bada/00_prelude.bada`) で Bada 自身の上にこしらえる。

```sh
node badagpt_papers/tools/run-papers.js            # 全巻を実行・検査 (約 50 秒)
node badagpt_papers/tools/run-papers.js 02 10      # 第二巻と第十巻だけ
node badagpt_papers/tools/run-papers.js --quiet    # 判定だけ
```

Bada にはモジュール読み込みの仕組みが無いので、実行器は各巻を共通核と連結して 1 本にし、`bada_gui_ide/www/bada.js` のインタープリタで走らせる (ステップ上限を 40 億に上げている)。連結した全文は `dist/NN_*.full.bada`、実行出力は `dist/NN_*.out.txt` に残る。連結済みファイルは `node bada_gui_ide/cli/bada-cli.js run dist/01_form_entropy.full.bada` のように CLI でも走る (第二巻・第十巻は既定の上限 2000 万ステップを超えるので実行器を使う)。

## 🔬 作り換えで見つかったこと

論文の数値を Bada で再現する過程で、三つの点は論文と違う結論になった。いずれも該当巻の出力に明記してある。

1. **第二巻 系3 の閾値 y_c = 1.0766323907 は x の探索上限の産物。** 大きな x で ζ(x,y) ≈ y^{−x}、B(y,x−1) ≈ Γ(y)x^{−y} なので Λ(x,y) ≈ y^{−x}x^{y}/Γ(y) → 0 (y > 1)。したがって y > 1 なら十分大きな x で必ず Λ = 1 の解がある。x ≤ 60 で探索すると論文の値 1.0766323907 が 1e-11 で再現され、x ≤ 4000 まで広げると y = 1.0766, 1.05, 1.02, 1.01 のすべてに解 (60.0, 99.3, 293.0, 659.3) が見つかる。真の閾値は y_c → 1⁺ であり、y = 1 では Λ(x,1) = (x−1)ζ(x) > 1 で解がない。
2. **第八巻 表5 (縦横比を変えた平坦トーラスの log det) は厳密値から 3×10⁻⁴ ずれている。** Kronecker の極限公式 det_ζ Δ = A·τ₂·|η(iτ₂)|⁴ (Dedekind η) から厳密値が出る (正方トーラス L = 2π で 2.6210658518 に一致)。論文の数値 (Simpson 6000 分割) より、桁落ちを避けて正則化した本実装の数値のほうが厳密値に近い (差 5e-6 以下)。
3. **第一巻 表3・表4 の基底分布 a は論文の z と異なる。** 論文の表3 の a (0.65957, 0.14717, …) を再現する z = [3.0, 1.5, 0, −40, 1.0, −3.0, −40, 0.75] を逆算して用いた。共通位相場 φ_i = cos i は論文に明記がなく、表4 の maxdiff は 3 桁まで一致し 4 桁目で異なる (定理の内容 — 単調性・順位不変・零点保存 — は全ケースで成立)。

論文の表と **全桁一致** したもの: 第一巻 表1 (7 本の H_form)・表E (部品分布と厳密零)、第二巻 表6 (x*(y) 10 点)・表12・表9、第三巻 表2 (p_succ)・表4・表10、第四巻 表5〜7 (H1 と k*)、第九巻 表 (8 幾何の Ricci、フローの終値)、第十巻 表 (残差 × Λ)。数値の丸め床 (10⁵ 項の直和で 10⁻¹²) や Euler–Maclaurin が負の x で精度を失うこと (第五巻 表11 の自明零点) は、論文と同じく隠さず出力する。

## 🧭 論文集を貫く原理 (各巻の結論に一行ずつ足されてきたもの)

> 零を保存するのは、非零因子による乗算だけである。曲率はその乗算を級数に開き、重複度がその級数の項を数え、位相はゼータの原点に、形はその傾きに宿る — ただし二次元でだけ。三次元では、フローの固有値が語りはじめる。Γ の部分積分が原点と傾きを切り分け、関数等式の奇部が曲率の在処を告げる。ただし、力は生まれない。

全巻が「主張しないこと」を結論に持つ: 重力の量子化、統一場理論、リーマン予想への含意、方程式が大脳の機能を持つこと、反重力の発生、新しい暗号方式。第十三巻は仮説を仮説として台帳に残し、検査の対象にしない。

## 🔤 Bada 方言について (この処理系で実測した制約と、その回避)

論文の付録が想定する Bada (`pow`, `sum`, `push`, `pi()`, `or`, 索引代入 `c[k] := …`) と、本リポジトリの処理系 (`bada_gui_ide/www/bada.js`) には差がある。共通核はその差を埋める。

| 論文の書き方 | 処理系の実際 | 共通核での回避 |
|:--|:--|:--|
| `c[k] := c[k] + 1` (索引代入) | 構文エラー | `set_at(c, k, v)` で再構築、または `<-` 追記 |
| `a or b`, `a \|\| b` | 構文エラー | `&&` と `!` と入れ子の `if`、`either` 相当は関数で |
| 関数の中から大域変数へ `:=` | 局所束縛になり外へ出ない | 配列への `<-` 追記だけが外へ届く (`CHECKS`) |
| `for x in xs { acc := acc + x }` | 本体の代入が外へ出ない | 累積は `while` で |
| `pow`, `sum`, `push`, `pi()`, `floor`, `cos`, `atan` | 組み込みなし | `pow_`, `arr_sum`, `<-`, `PI`, `floor_`, `cos_` (Taylor), `atan_` |
| 改行で文が終わる | 改行は区切りではない | `ok` の次行が `[…]` で始まると索引になる → 配列リテラルは束縛してから `>> tuplespace` |
| `rule "x" postfix [ 'x' '(' expr ')' ]` に多引数 | 1 引数のみ | パターンに `','` `expr` を並べて `_1, _2, …` |

量子部分言語は `qubit(n)` / `H(reg,q)` / `X` / `Rz(reg,λ,q)` / `CNOT(reg,c,t)` / `Measure` をそのまま使う。`Ry(θ)` は無いので `H·Rz(θ)·H` で同じ Born 確率 cos²(θ/2), sin²(θ/2) を作る (第三巻・第五巻の積状態)。量子ビット 0 が基底添字の最下位ビットである。
