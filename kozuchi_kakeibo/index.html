📷 レシートを撮影して自動登録

ℹ️ このアプリについて

小槌の家計簿 — 打ち出の小槌のように、レシートを一振り(撮影)するだけで帳簿がふくらむ家計簿です。
・文字認識(OCR)は Tesseract.js をブラウザ内で実行します。画像が外部サーバーへ送信されることはありません(OCR エンジンと日本語辞書の取得時のみ CDN へアクセスします)。
・簿記機能: 仕訳帳 / 総勘定元帳 / 合計残高試算表 / 損益計算書 / 貸借対照表
・単一 HTML ファイル。インストール不要、ホーム画面に追加すればアプリのように使えます。
