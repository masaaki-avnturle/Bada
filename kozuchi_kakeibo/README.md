# 🪙 小槌の家計簿 — レシート撮影で自動記帳(複式簿記)

打ち出の小槌のように、レシートをカメラで一振り(撮影)するだけで帳簿がふくらむ家計簿アプリです。
**単一 HTML・インストール不要**。スマホ / タブレット / PC のブラウザで動きます。

## ✨ できること

| 機能 | 内容 |
|:---|:---|
| 📷 レシート撮影 → 自動登録 | スマホ・タブレットのカメラで撮影(標準カメラ / ライブカメラの両対応)。画像はモノクロ化・コントラスト強調で自動補正 |
| 🔍 OCR(文字認識) | [Tesseract.js](https://github.com/naptha/tesseract.js)(日本語+英語)を**ブラウザ内で実行**。画像が外部サーバーへ送信されることはありません(エンジンと辞書の取得時のみ CDN へアクセス) |
| 🧮 レシート解析 | 日付(西暦・令和対応)/ 店名 / 品目と金額 / 合計 / 消費税を自動抽出。全角数字・`円`・`¥` 表記に対応 |
| 🏷 勘定科目の自動判定 | 品目名と店名のキーワード辞書から 食費・外食費・日用品費・医療費・被服費・娯楽費 などを自動判定(登録前に修正可能) |
| 📒 複式簿記 | 仕訳帳 / 総勘定元帳 / 合計残高試算表 / 損益計算書(P/L)/ 貸借対照表(B/S)/ 費目別グラフ |
| 💳 支払方法 | 現金 / クレジットカード(未払金)/ 電子マネー / 普通預金 |
| ✏️ 手入力 | 支出・収入の直接登録(収入は「借方 資産 / 貸方 収益」で仕訳) |
| 🏁 開始残高 | 元入金仕訳(借方 資産 / 貸方 元入金)で家計簿を開始 |
| 💾 データ | 端末内 localStorage にのみ保存。JSON バックアップ / 読み込み、仕訳帳 CSV(Excel 対応 BOM 付き)書き出し |

## 📱 Android APK でインストール

[Releases](https://github.com/masaaki-avnturle/Bada/releases) の `kozuchi-v*` から **`kozuchi-kakeibo-debug.apk`** をダウンロードし、スマホ・タブレットでタップしてインストールします(初回は「提供元不明のアプリのインストール」の許可が必要です)。

- APK は [`.github/workflows/kozuchi-app-build.yml`](../.github/workflows/kozuchi-app-build.yml) が GitHub Actions 上で Cordova を使ってビルドし、`kozuchi-v*` タグを付けると自動で Release に添付されます(`workflow_dispatch` で手動実行も可能。`release_tag` を空欄にすると Actions アーティファクトのみ)
- アプリ内の「📷 カメラで撮影する」ボタンは端末の標準カメラアプリを呼び出します
- レシート解析・簿記エンジンは [`tools/engine-test.js`](tools/engine-test.js) が CI で毎回検証します

## 🚀 使い方(ブラウザ版)

1. [`index.html`](index.html) を開き **「Download raw file」(⬇ アイコン)** で保存
2. スマホ・タブレットのブラウザで開く(ホーム画面に追加するとアプリのように使えます)
3. **⚙️ 設定** タブで開始残高(手持ちの現金など)を登録
4. **📷 撮影** タブでレシートを撮影 → 「🔍 文字を読み取る」→ 「🧮 解析」→ 内容を確認して「🪙 小槌に登録する」
5. **📒 仕訳帳 / 📚 元帳 / 📊 報告書** タブで帳簿を確認

> 💡 カメラ(ライブカメラ)やクリップボード等の機能はブラウザの仕様上 **HTTPS または file:// で開いたとき**に使えます。OCR が使えないオフライン環境では、読み取り結果欄にレシート内容を貼り付けて解析するか、手入力タブをご利用ください。

## 📚 簿記のしくみ

- 支出: **借方 費用科目(食費など)/ 貸方 支払方法(現金・クレジット未払金など)**
- 収入: **借方 資産(普通預金など)/ 貸方 収益(給与収入など)**
- 開始残高: **借方 資産 / 貸方 元入金**
- 貸借対照表は「資産 = 負債 + 元入金 + 繰越利益(累計収支)」で常に貸借一致します

## 🔒 プライバシー

- 家計データ・レシート画像が外部へ送信されることはありません
- 保存先はお使いのブラウザの localStorage のみ(バックアップは JSON 書き出しで)
