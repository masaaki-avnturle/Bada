# Omega MorphoField

**形態形成場（反応拡散系）＋外部場ドリフトによる細胞分岐の操作と、腫瘍停滞の個体群動態**

2つのモジュールからなります。どちらも依存ライブラリゼロ、Python 3.8+。

## 1. 形態形成場と電磁誘導ドリフト — `morphogen.py`

チューリングの形態形成理論に基づく **Gray-Scott 反応拡散系** を2次元格子で解きます。

```
∂u/∂t = Du∇²u − u·v² + F(1−u) − (E·∇)u
∂v/∂t = Dv∇²v + u·v² − (F+k)v − (E·∇)v
```

(F, k) = (0.030, 0.0565) 付近では、置いた種が成長して**自発的に分裂**します。
1つの種が時間とともに複数の「細胞」へ分岐していく様子が、パラメータだけから
自然に現れます。

```
  t=   375  細胞数=  1  活性因子総量=  222.8
  t=   750  細胞数=  1  活性因子総量=  270.6
  t=  1125  細胞数=  8  活性因子総量=  293.9    ← 分岐
  t=  1500  細胞数=  1  活性因子総量=  288.7    ← 再結合
```

細胞数はいったん増えたあと再び結合することもあります（分裂と融合を繰り返す
動的なパターンで、静止した解ではありません）。48格子で長く回すと分岐が定着します。

**外部場 E** は移流項として入り、パターン全体を場の方向へドリフトさせます。

| Ex | 重心x | 重心y |
|--:|--:|--:|
| 0.00 | 20.00 | 20.00 |
| 0.01 | 23.36 | 20.00 |
| 0.03 | 36.68 | 20.00 |
| 0.05 | 15.28 | 20.00 |

場をかけると**場の向き（x）にだけ**重心が移動し、直交方向（y）は 20.00 のまま
まったく動きません。外部場でパターンの位置を制御できることが数値で確認できます
（境界は周期的なので、Ex=0.05 では格子の端を回り込んで 15.28 に現れています）。

なお、生体で直流電場が細胞遊走の向きを変える現象（**電気走性 / galvanotaxis**）は
実在しますが、本モデルはその定量的再現ではなく、場が空間パターンを操作できる
ことを示す抽象モデルです。

## 2. 腫瘍の停滞と耐性競合 — `tumor_dynamics.py`

「腫瘍が停滞する」を、**数理腫瘍学の個体群動態**として扱います。

```
dS/dt = r_S·S·ln(K/(S+R)) − ε(t)·κ·S      S: 感受性クローン
dR/dt = r_R·R·ln(K/(S+R))                 R: 耐性クローン (r_R < r_S)
```

`ε(t) ∈ [0,1]` は**用量でも成分濃度でもなく**、感受性クローンの死亡率が
どれだけ上がるかを 0〜1 で表した無次元パラメータです。

### 結果 — 停滞は「強く叩くこと」では得られない

| 方針 | 最終腫瘍量 | 耐性割合 | 進行までの時間 | 停滞 | 治療時間の割合 |
|:--|--:|--:|--:|:--|--:|
| 無治療 | 10000.0 | 0.5% | 60.5 | いいえ | 0% |
| 常時最大強度 | 10000.0 | 100.0% | 331.2 | いいえ | 100% |
| **適応的（断続）** | **7410.8** | 90.2% | **達せず** | **はい ✓** | **20%** |

S と R は同じ環境収容力 K を奪い合っています。ε を上げ続けて S を消し去ると、
S による競合抑制が外れて R が空いた席を占め、腫瘍は再増殖します
（**competitive release**）。逆に S をあえて残す断続的な方針では、S が R を
抑え続けるため腫瘍全体が停滞し、しかも治療している時間は全期間の20%で済みます。

これは Gatenby らの**適応療法 (adaptive therapy)** や Goldie-Coldman の耐性理論で
知られる、実在する数理的帰結です。

## ⚠️ 正直な位置づけ（重要）

- **薬の成分・用量（度数）は扱いません。** 本パッケージにその出力はなく、
  そこから導くこともできません。扱うのは細胞集団の増減という個体群動態だけです。
- 治療方針の助言ではありません。実際のがん治療は主治医と決めるものです。
- 形態形成場は実在の細胞・組織・医療機器のモデルではなく、医療目的に
  使えるものではありません。
- 「アメル」は共和薬品工業のジェネリック医薬品のブランド名（接尾辞）であって
  薬剤名ではないため、その製造をシミュレートすることはできません
  （`omega_medsafe_pkg` が同じ説明を返します）。

## インストール・使い方

```bash
cd omega_morphofield_pkg && pip install -e .

omega-morphofield morph    # 種から細胞が分岐していく様子（アスキー表示つき）
omega-morphofield field    # 外部場によるドリフトの計測
omega-morphofield tumor    # 治療方針3種の比較
omega-morphofield          # すべて
```

```python
from omega_morphofield import MorphogenField, FieldConfig, compare_policies

f = MorphogenField(FieldConfig(n=48, Ex=0.03))   # 外部場つき
f.seed_spot(radius=3)
f.run(1500)
print(f.count_spots(), f.centroid())
print(f.render())
```

## テスト

```bash
pytest -q    # 13テスト
```

一様状態の安定性、濃度の有界性、種の分裂、場の向きへのドリフト（直交方向は不動）、
無治療での収容力到達、常時最大強度での耐性選択、適応方針による進行遅延と停滞、
治療強度が0〜1に制限されること、再現性を検証します。
