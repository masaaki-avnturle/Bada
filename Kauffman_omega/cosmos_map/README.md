# 宇宙の地図

天の川銀河の地球型惑星候補から、観測可能な宇宙の果て（宇宙マイクロ波背景放射）までを
1枚にまとめたインタラクティブな 3D 地図です（Three.js 0.147、`index.html` をブラウザで開く）。

- **宇宙全体（対数スケール）**: 太陽を中心に、外へ1目盛り（3単位）進むごとに距離が10倍。
  天体は実際の方向（赤経・赤緯 J2000）に置いています。惑星は今日の日付から平均軌道で計算。
- **天の川銀河（実寸）**: 1単位 = 1,000光年。渦状腕は対数螺旋の模式図、太陽は中心から2.67万光年。
  地球型惑星候補は銀河座標に変換した実際の位置にあり、すべて太陽から半径2,000光年の球の中に入ります。

収録: 地球型惑星候補19、恒星・星雲11、天の川銀河の構造4、局部銀河群5、近傍銀河6、
銀河団・大規模構造9、遠方宇宙4。距離は公開値の概数で、遠方は共動距離（光が出た時期も併記）。
宇宙マイクロ波背景放射の模様は模式図です。
