D-brane 宇宙図

レポートのあらまし「宇宙と異次元が、D-braneを柱として、生み出された」を立体化した図です。母なる Jones 多項式から D-brane の柱が立ち上がり、我々の宇宙（無限の D-brane）と反ド・ジッター AdS5 のバルク、有限の anti-D-brane を貫きます。宇宙の各点にはカラビ・ヤウ多様体の余剰次元が畳まれ、ブレーンから8つの子宇宙（サーストンの8幾何）が芽吹き、2つずつ4つの宇宙にまとまって1つの宇宙へ統合されます。

生成の系譜

  1. 無（ゼータ関数）無限の時間の無が、場の理論として存在していた
  2. ガンマ関数（父）オイラーの定数の大域的積分多様体
  3. Jones 多項式（母）質量差エネルギーとして生まれた三葉結び目
  4. D-brane の柱ゼータ関数を Z 軸に束ねたシリンダー。ねじれは Seifert 多様体の第5次元
  5. 宇宙と異次元D-brane（無限）と anti-D-brane（有限）、AdS5 バルク、各点のカラビ・ヤウ
  6. 8つの子宇宙 → 4つの宇宙8種類のサーストン幾何を2種類ずつまとめる
  7. 統一宇宙（共時性）4つの宇宙が1つの宇宙へ統合される

表示レイヤー

パラメータ

0.18 歪み因子 e−2πT|ψ|。T を上げるとバルクが絞られ、anti-D-brane が小さく（有限に）なります。
0.79 5次フェルマー曲面の複素 2 次元断面を 3 次元へ射影する角度。25 枚のパッチの色は (k₁,k₂)。

視点

子宇宙（サーストンの8幾何）

レポートの式

AdS5 計量（AdS5.tex, Kalabi-Yau.tex）
‖ds²‖ = e^(−2πT‖ψ‖) [η_μν + h̄_μν(x)] dx^μ dx^ν + T² d²ψ
フェルマー型カラビ・ヤウ多様体（Kalabi-Yau.tex）
x⁵ + y⁵ + z⁵ + u⁵ + v⁵ − 5ψ·xyzuv = 0
D-brane と anti-D-brane の方程式（output_file.tex）
dV(τ)/dL = d/df ∬_M 1/(x log x)² dx_m + d/df ∬_M 1/(y log y)^(1/2) dy_m
鏡映理論（anti-D-brane は鏡像の曲率）
R′_ij = −R_ij
ガンマ関数から Jones 多項式へ
∫Γ(γ)′ dx_m = e^f + e^(−f) ≥ e^f − e^(−f)
