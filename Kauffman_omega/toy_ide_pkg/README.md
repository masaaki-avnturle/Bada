# toy_ide_pkg (hypothesis engine — safe, concrete)

This package generates exploratory hypothesis documents (LaTeX), SymPy stubs,
validation harnesses and experimental BNF/skeletons from PDF inputs and optional
web context. All outputs are explicitly labeled HYPOTHESIS / EXPLORATORY and are NOT proofs.

Run: bash bin/run.sh
Commands (interactive): .report, .export_hypothesis, .congen_skeleton, .run_validation, .to_sympy
