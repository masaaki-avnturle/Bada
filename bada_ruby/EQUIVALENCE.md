# Bada 言語による 等価原理・半減期・トポロジー

Bada 言語を拡張し、**慣性質量と重力質量の等価原理**、**放射性崩壊の半減期**、
**トポロジーの位相不変量**を Bada で書けるようにしました。

```bash
cd bada_ruby
bin/bada run examples/equivalence.bada   # 等価原理
bin/bada run examples/halflife.bada      # 半減期と壊変系列
bin/bada run examples/topology.bada      # メビウス二重被覆とオイラー標数
ruby -Ilib test/test_equivalence.rb      # 33 テスト
```

## 言語の拡張

これまでの Bada は「1 行 = 1 演算子」で、値を演算子で流すだけの言語でした。
物理を書くために次を追加しています（**既存の構文はそのまま動きます**）。

| 追加 | 例 |
|:--|:--|
| 算術式 | `print 1 + 2 * 3 ^ 2` — `+ - * / ^` と括弧、単項マイナス |
| 数値変数 | `let a = 3` （`set` は従来どおり BadaNode を作る） |
| 関数呼び出し | `print gamma(5)` → `24` |
| 繰り返し | `repeat 5 as k` … `end`（ネスト可） |
| 書式つき出力 | `print "eta = ", eotvos(a1, a2)` |

未知の識別子は従来どおり「裸の語 = 文字列トークン」として扱われるため、
`g <- manifold_node` のような旧来の書き方も壊れません。

あわせて、ロケールが ASCII の環境でライブラリを直接呼んだとき、日本語コメントを
含む `.bada` が `Encoding::CompatibilityError` で落ちる不具合を直しました。

## 1. 等価原理 — `examples/equivalence.bada`

落下加速度は `a = (m_g / m_i) · g`。慣性質量と重力質量が等価なら比は 1 で、
**加速度は物質にも質量にもよりません**。破れは**エトヴェシュ比**で測ります。

```
η = 2(a₁ − a₂) / (a₁ + a₂)
```

```
-- 同じ比 m_g/m_i を持つ 2 物体 --
  物体1 (m_g=1, m_i=1): a = 9.80665
  物体2 (m_g=7, m_i=7): a = 9.80665
  エトヴェシュ比 eta  = 0

-- 自由落下の軌道 (t=0..4) --
   t      x(m_i=1)      x(m_i=7)        差
  2   19.6133   19.6133   0
  4   78.4532   78.4532   0
  → 測地線は質量によらず一致する。
```

比を `1e-12` ずらすと `η = -1.000e-12`、`1e-3` ずらすと `η = -1.0e-3` と、
**破れの大きさがそのまま η に出ます**。実験の感度がそのまま検証の上限になる、
というエトヴェシュ実験の構造がここに現れます。

等価原理の帰結である重力赤方偏移 `Δν/ν = gh/c²` も同じスクリプトで計算します
（h=100 m で `1.09e-14`）。

### Γ 多様体との対応

部分積分の漸化 `Γ(s+1) = s·Γ(s)` は **s によらず成り立つ不変性**で、
等価原理の「物質によらず m_g/m_i = 1」と同じ形をしています。
スクリプトは両者を並べ、Γ 側の破れが機械精度（`1e-16` 台）に収まることを示します。

## 2. 半減期と壊変系列 — `examples/halflife.bada`

`dN/dt = −λN`、`T½ = ln2/λ`。壊変系列 A → B → C は **Bateman 方程式**で解きます。

```
-- 残存比 N/N0 = 2^(-t/T_half),  T_half = 10 --
  t = 10  N/N0 = 0.5     (= 2^-1)
  t = 20  N/N0 = 0.25    (= 2^-2)
  t = 30  N/N0 = 0.125   (= 2^-3)

-- 壊変系列 A -> B -> C   T_half(A)=5, T_half(B)=15, C は安定 --
     t         A          B          C        総量
  0     1000        0          0          1000
  10    125       562.5      312.5        1000
  50    0.977     147.354    851.669      1000
  → 総量は常に 1000 で保存される（物質収支が閉じている）。
```

親が速く娘が遅いので、娘 B はいったん増えてから減ります。ピークは
`t = ln(λ_A/λ_B)/(λ_A − λ_B) = 11.89` で、スクリプトの探索も `t = 12` を返します
（テストで解析解と照合済み）。

**⚠️ 実在の核種データや臨界計算は含みません。** 扱うのは指数崩壊則そのものです。

## 3. トポロジー — `examples/topology.bada`

```
-- メビウスの帯: 向きは 2 周で戻る --
  周回   向き   復帰したか
   1     -1      0
   2      1      1
  → 奇数周では -1（裏面）。偶数周で +1 に戻る = 二重被覆。

-- オイラー標数 chi = V - E + F --
  正四面体 chi = 2 / 立方体 chi = 2 / 正二十面体 chi = 2
  → どの多面体も chi = 2。球面と同相だから同じ値（位相不変量）。

-- 向き付け可能閉曲面: chi = 2 - 2g --
  種数 0 (球面) chi = 2 / 種数 1 (トーラス) chi = 0 / 種数 2 chi = -2
```

メビウスの帯は `χ = 0` で、円板（`χ = 1`）とは別物です。この二重被覆は
`omega_mobius_drive_pkg` の擬似量子VMが使う「メビウス回路HDD」と同じ性質で、
そちらを位相不変量として書き直したものになっています。

## テスト

`test/test_equivalence.rb` の 33 件（104 アサーション）で次を検証しています。

- 等価原理: 質量によらず a = g、軌道の完全一致、η がずれの大きさを回復すること
- 半減期: λ と T½ が互いの逆算、半減期ごとにきっちり半分、A = λN
- 壊変系列: **総量保存**、親が単純指数崩壊に従うこと、娘のピークが解析解と一致
- トポロジー: 二重被覆、正多面体すべて χ=2、χ=2−2g、巻き数
- 言語拡張: 算術・関数・repeat（ネスト含む）・エラー報告・**後方互換**

既存の `test_bada` / `test_nn` / `test_penrose` / `test_theory` の 64 件も
すべてパスしたままです（合計 97 件）。
