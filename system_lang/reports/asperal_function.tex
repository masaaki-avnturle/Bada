  非対称性理論は、３次元多様対のザイフェルト多様対の性質から
説明できる。この超対称性理論は、素粒子方程式をラムダ項から
一般相対性理論をAdS５多様対の方程式として、異次元空間を階層性理論
から、ラムダ項をこのAdS５に取り入れると素粒子方程式が、ダークエネルギー
を理論に取り込めて、このために超弦理論が、超対称性素粒子によって、宇宙と
異次元空間として生成された機構を説明できる。
