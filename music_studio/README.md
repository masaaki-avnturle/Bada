# 🎹 Bada Music Studio — 音楽制作ソフト (DAW)

**市販の DAW と同じ作り方で曲が作れる、依存ゼロの音楽制作ソフト。** 打ち込み・音づくり・ミックス・書き出しまでを 1 本の HTML で完結します。インストール不要、サーバー不要、完全オフライン。**あなたの曲が端末の外に出ることは一切ありません。**

起動するとデモ曲「Aurora」(8 小節 / 5 トラック) が読み込まれるので、**▶ を押せばすぐ音が鳴ります。**

## ✨ できること

### 🎚 アレンジ (タイムライン)
トラック × 小節のタイムラインにクリップを配置して曲を組み立てます。クリップはドラッグで移動、右端をドラッグすると**パターンが小節数だけ繰り返され**、右クリックで削除、ダブルクリックでエディタが開きます。クリップ内にはパターンの中身がミニプレビューとして描画されます。トラックは**インスト / ドラム / オーディオ**の 3 種類。

### 🎹 ピアノロール
ドラッグで音符を描画、右端をドラッグで長さ変更、右クリックで削除。下段の**ベロシティレーン**で強弱を、**グリッド** (1/1 〜 1/32、8 分・16 分の 3 連符) でスナップを調整できます。**クオンタイズ**、半音 / オクターブ単位の移調、**スケール表示** (メジャー / マイナー / ドリアン / ペンタトニック / ブルースなど 9 種、スケール外の音は暗く表示)、**コードモード** (1 クリックで maj / min / 7th / M7 / m7 / sus4 / dim / aug / add9 を配置)。

### 🥁 ステップシーケンサ
**10 種のドラム音源をすべてその場で合成**します (音声サンプルは 1 バイトも同梱していません)。キック / スネア / クラップ / リムショット / クローズ・オープンハイハット / ロー・ハイタム / ライド / クラッシュ。1〜8 小節、1/8・1/16・1/32・8 分 3 連の分解能、**ステップごとのベロシティ**(右クリックで弱打)、音名クリックで試聴、「ランダム生成」で 3 系統 (4 つ打ち / ブレイクビート / ハーフタイム) のビートを自動生成。

### 🎛 シンセサイザ
減算合成方式のポリフォニック・シンセです。

| セクション | 内容 |
|:---|:---|
| **オシレータ ×2** | ノコギリ / 矩形 / 三角 / サイン、オクターブ・半音・デチューン・レベル |
| **サブ / ノイズ** | サブオシレータ (−1 / −2 oct) とホワイトノイズ |
| **ユニゾン** | 最大 5 声のデチューン・スプレッド (スーパーソウ) |
| **フィルタ** | ロー / ハイ / バンドパス / ノッチ、カットオフ・レゾナンス・**エンベロープ量**・**キートラック** |
| **エンベロープ ×2** | アンプ用とフィルタ用の独立した ADSR (波形をグラフ表示) |
| **LFO** | ピッチ (ビブラート) / フィルタ (ワウ) / 音量 (トレモロ)、4 波形 |

**13 種のプリセット** — Init / Super Saw Lead / Fat Bass / Warm Pad / Pluck / E.Piano / Bell / Organ / Brass / Strings / Chiptune / Wobble Bass / Air Choir。

### 🎚 ミキサー & エフェクト
トラックごとに **フェーダー (dB) / パン (等パワー) / ミュート / ソロ / レベルメーター**。エフェクトは **ドライブ**(ソフトクリップ)・**3 バンド EQ**・**コーラス**をトラックごとに、**リバーブ**(合成インパルス応答 / Room・Hall・Cathedral・Plate)と**テンポ同期ピンポンディレイ**(1/16 〜 1/2・付点)をセンドで。マスターには**リミッタ**とレベルメーター。

### 🎧 入力と書き出し

| 入出力 | 内容 |
|:---|:---|
| **WAV 書き出し** | `OfflineAudioContext` で**オフラインレンダリング**。16 / 24 bit PCM・32 bit float、44.1 / 48 / 96 kHz、末尾の余韻、ノーマライズ (−0.3 dBFS) |
| **ステム書き出し** | トラックごとに個別の WAV |
| **MIDI** | 標準 MIDI ファイル (SMF format 1) の**書き出しと読み込み**。テンポ・拍子・トラック名、ドラムは ch.10 の GM マッピング |
| **プロジェクト** | `.badaproj` (JSON) で保存・復元。ブラウザへの**自動保存**つき |
| **オーディオ読込** | MP3 / WAV / OGG / M4A などをオーディオトラックへ (波形表示つき) |
| **マイク録音** | 端末のマイクから録音してオーディオトラックへ |

### ⏱ トランスポート
再生 / 停止 / **ループ**(ルーラーを Shift+ドラッグで範囲指定) / **メトロノーム** / BPM 20〜300 / 拍子 4-4・3-4・6-8・5-4・7-4 / **スウィング** 0〜70% / 小節.拍.ティック表示 / **リアルタイム録音**(再生しながら鍵盤を弾くとパターンに記録)。

## ⚙ 仕組み

**再生と書き出しは、同じコードを共有します。**

1. `buildEvents(project)` — トラックのクリップとパターンを展開し、**時間順の平坦なイベント列**にします (クリップの反復・長さによる切り詰め・ミュート / ソロ・スウィングをここで解決)
2. `buildGraph(ctx, project)` — トラックごとの `ドライブ → EQ → コーラス → フェーダー → パン` と、リバーブ (`ConvolverNode` + 合成 IR) / ディレイのセンド、マスターのリミッタを組み立てます
3. `scheduleEvent(ctx, graph, project, ev, when)` — 1 イベントを絶対時刻に載せます
4. **ライブ再生**は `AudioContext` + 25 ms 間隔・140 ms 先読みのスケジューラ、**書き出し**は `OfflineAudioContext` で、どちらも 2〜3 をそのまま呼びます

つまり「書き出したら音が違った」が原理的に起きません。ドラムは 1 打ごとにオシレータとフィルタを組んで合成し (ノイズ源は決定論的な擬似乱数なので**毎回まったく同じ音**が書き出されます)、シンセは 1 音ごとに `OscillatorNode` → `BiquadFilter` → ADSR ゲインの voice を生成します。

外部ライブラリ・CDN・サーバーは一切使いません。

## 🚀 使い方

1. [`index.html`](index.html) を「Download raw file」(⬇ アイコン) で保存 → ダブルクリック(インストール不要)
2. **▶** でデモ曲を再生 → 🥁 でビートを打ち込む → 🎹 でメロディを描く → 🎛 で音色を作る → 💾 で書き出す
3. または [Releases](https://github.com/masaaki-avnturle/Bada/releases) から:

| プラットフォーム | ファイル |
|:---|:---|
| **Android** (APK) | `bada-music-studio-debug.apk` |
| **Windows 10 / 11** | `BadaMusicStudio-*-x64.exe`(NSIS インストーラ / ポータブル) |
| **Ubuntu** | `BadaMusicStudio-*-x86_64.AppImage` / `BadaMusicStudio-*-amd64.deb` |

ビルドは [`musicstudio-app-build.yml`](../.github/workflows/musicstudio-app-build.yml) が実行します(`musicstudio-v*` タグで Release へ添付 / `workflow_dispatch` で Actions アーティファクト)。

## 🧪 テスト

```
node music_studio/tools/engine-test.js
```

DOM と Web Audio を切り離した純ロジックを **203 項目**で検証します — 整形、音程・音名の全 128 音往復、スケール・コード、クオンタイズとスウィング、dB / 等パワーパン / ADSR、**スケジュール生成**(クリップの反復・切り詰め・ミュート / ソロ・ステムの絞り込み)、**WAV エンコーダ**(16/24/32 bit のヘッダとサンプル値、範囲外・NaN のクリップ)、**MIDI**(VLQ の境界値、SMF の構造、書き出し → 読み込みの往復)、**プロジェクトの保存 / 復元**(欠損値の補完と壊れた値の是正)、保存ファイル名の無害化、画面座標の逆変換、デモ曲の整合性。

## 💾 保存されるファイル名について

対応環境 (Chrome / Edge / デスクトップアプリ版) では**保存ダイアログ**が開き、日本語を含む曲名がそのままファイル名になります。ダイアログを使えない環境ではブラウザのダウンロード機能に切り替わりますが、**`download` 属性に非 ASCII 文字が含まれるとファイル名ごと無視して拡張子のない `download` として保存してしまうブラウザがある**ため、その場合だけファイル名を ASCII に落として保存します(拡張子は必ず維持します)。曲名が全角のみのときは曲名から作った短い識別子を付けるので、**別の曲どうしが同じファイル名で上書きされることはありません**。

ステム書き出しは複数ファイルを連続して保存するため、ブラウザが「複数のファイルのダウンロードを許可しますか?」と一度だけ確認することがあります。

## 📝 制限

- 変換ではなく**合成**なので、生楽器のサンプル音源は入っていません (音色はシンセとドラム合成で作ります)
- Android の WebView ではファイル保存 (ダウンロード) が環境によって制限されることがあります。書き出しは Windows / Ubuntu / デスクトップブラウザを推奨します
- 96 kHz・長尺のステム書き出しはメモリを多く使います
