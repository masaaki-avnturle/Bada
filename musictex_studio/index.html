MusicTeX Studio について

  

    MusixTeX (texlive-music) の楽譜ソースを作成・プレビュー・試聴し、
    .tex として書き出す楽譜制作アプリです。依存ゼロ・単一 HTML で、
    Android APK / Windows 10・11 / Ubuntu アプリとして配布されています。
  

  

    テンプレートはレポート 「Δと」(Masaaki Yamaguchi, octave74) の音階理論に
    もとづきます: B♭・E♭ 長音階のとりうる音、2音階で 4〜5 オクターブをカバーする考え方、
    G と A の和音、HANON 練習など。
  

  
    
    
  • ⚛ 量子作曲 (擬似量子コンピュータ): Bada VM Pro と互換の量子 Bada 言語
        (qubit / H / X / Z / CNOT / measure / state / let / print、状態ベクトル実行系・
        最大8量子ビット) に音楽命令 note / chord / rest を追加。重ね合わせ・量子もつれの
        測定結果が現在の調の音階と五行コード線に写像され、そのまま譜面化・
        スペクトル映像化・シンセ演奏される (取り込みモードの置き換え/重ねるにも対応)
    • 
    
  • シンセサイザー (スペクトルコード): 音色 = 倍音1〜8の振幅スペクトルを
        スライダーで設計。楽器プリセット (ピアノ/オルガン/ヴァイオリン/チェロ/フルート/
        トランペット/クラリネット/ギター/ハープ/オルゴール/ベル/マリンバ/ベース + 基本波形) は
        倍音 + ADSR (アタック/ディケイ/サステイン/リリース) + ビブラートまで切り替わる。
        試聴・鍵盤・コードすべての音源になり、出力はライブスペクトル (12音階の色の FFT) として映像化
    • 
    
  • 取り込みモード: 曲ファイル (MIDI / wav / mp3 / ogg / m4a / flac / aac / opus / mp4 等) を
        「置き換え」または「重ねる」で取り込み — 作曲中の楽譜に外部の曲を被せられる
        (同時発音は和音に統合)。音声取り込み時は曲のスペクトル分布を倍音コード化して
        シンセの音色にも自動設定。「🧩 コード化して重ねる」で、いまの楽譜から小節ごとの
        コード進行 (五行コード線の5種×12音階) を抽出して伴奏として重ねる
    • 
    
  • 五行コード線: M / m / 7 / M7 / sus4 の5行 × 12音階のコード格子。
        セルは根音の波長色。クリックでシンセ演奏 + 楽譜へ和音 (\zq) を挿入
    • 
    
  • モーツァルト・ビジョン: 音の周波数を約40オクターブ上げると可視光の周波数帯に
        一致する物理対応 (例: A4 440Hz → 484THz ≒ 620nm 赤) で、楽譜を色の波長帯の映像として
        表示 (試聴と同期して発光)。波長で着色された色鍵盤をクリックすると、その色 (=音) が
        楽譜に書き込まれ、色から曲を制作できる
    • 
    
  • 曲→楽譜 (自動採譜): MIDI (.mid) は SMF 解析 (和音対応)、音声 (wav/mp3/ogg/m4a)
        は自己相関ピッチ検出 (単旋律・先頭60秒) で MusixTeX を自動生成。調号は長調15種への
        当てはまりで推定
    • 
    
  • プレビュー対応コマンド: \NOtes…\en, \qu \ql \hu \hl \wh \cu \cl \zq,
        \sh \fl \na, \qp \hpause \pause, \bar,
        \generalsignature, \generalmeter (ト音記号・単一譜表)
    • 
    
  • 音高は MusixTeX 表記: a=A3, c=中央C (C4), j=C5, q=C6 …
    • 
    
  • 印刷用 PDF: musixtex -p score.tex (texlive-music)
