MusicTeX Studio について

MusixTeX (texlive-music) の楽譜ソースを作成・プレビュー・試聴し、 .tex として書き出す楽譜制作アプリです。依存ゼロ・単一 HTML で、 Android APK / Windows 10・11 / Ubuntu アプリとして配布されています。

テンプレートはレポート 「Δと」(Masaaki Yamaguchi, octave74) の音階理論に もとづきます: B♭・E♭ 長音階のとりうる音、2音階で 4〜5 オクターブをカバーする考え方、 G と A の和音、HANON 練習など。

  • シンセサイザー (スペクトルコード): 音色 = 倍音1〜8の振幅スペクトルを スライダーで設計 (プリセット: 純音/三角波/ノコギリ/矩形波/オルガン/ピアノ風)。 ADSR 付き加算合成 (PeriodicWave) で試聴・鍵盤・コードすべての音源になり、 出力はライブスペクトル (12音階の色の FFT) として映像化
  • 五行コード線: M / m / 7 / M7 / sus4 の5行 × 12音階のコード格子。 セルは根音の波長色。クリックでシンセ演奏 + 楽譜へ和音 (\zq) を挿入
  • モーツァルト・ビジョン: 音の周波数を約40オクターブ上げると可視光の周波数帯に 一致する物理対応 (例: A4 440Hz → 484THz ≒ 620nm 赤) で、楽譜を色の波長帯の映像として 表示 (試聴と同期して発光)。波長で着色された色鍵盤をクリックすると、その色 (=音) が 楽譜に書き込まれ、色から曲を制作できる
  • 曲→楽譜 (自動採譜): MIDI (.mid) は SMF 解析 (和音対応)、音声 (wav/mp3/ogg/m4a) は自己相関ピッチ検出 (単旋律・先頭60秒) で MusixTeX を自動生成。調号は長調15種への 当てはまりで推定
  • プレビュー対応コマンド: \NOtes…\en, \qu \ql \hu \hl \wh \cu \cl \zq, \sh \fl \na, \qp \hpause \pause, \bar, \generalsignature, \generalmeter (ト音記号・単一譜表)
  • 音高は MusixTeX 表記: a=A3, c=中央C (C4), j=C5, q=C6 …
  • 印刷用 PDF: musixtex -p score.tex (texlive-music)
