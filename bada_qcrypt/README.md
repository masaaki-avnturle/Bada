# ⚛🔐 Bada QCrypt — 量子暗号ソフト(量子プログラミング言語 Bada 版)

**これまでの論文とアプリケーションで積み上げてきた量子暗号を、「暗号処理そのものを量子プログラミング言語 Bada で書く」形に作り換えたソフトウェアです。**

旧版(Bada QuantOS の量子暗号アプリ / ZoneShield)では BB84 を確率則で**模擬**していました。本版では **BB84 量子鍵配送・ワンタイムパッド・検疫タグのすべてが Bada のプログラム**として同梱され、光子 1 個ずつが実際に状態ベクトル実行系のゲート列(X / H / Z / CNOT / 測定)を通ります。乱数すら `H q` → `measure q` の**量子乱数**です。プログラムは「Bada プログラム室」でそのまま読め、編集すればアプリの挙動がその場で変わります。

依存ゼロ・単一 HTML・完全オフライン(通信機能を一切持ちません)。

## 🧪 量子検疫室 — どんなウイルス感染でも解除する

大切なテキストやファイルを**量子封印**すると、ワンタイムパッド暗号文と**検疫タグ**(鍵付きハッシュ)の組で保管されます。

| 操作 | 内容 |
|:---|:---|
| **🔏 量子封印** | 封印時の姿を暗号文として保存し、検疫タグを添える |
| **🔬 検査** | いま手元にある現物のタグを再計算して照合。**1 ビットの改変でも検出**し、封印時から何バイト変わったか・最初の改変がどこかまで提示 |
| **♻ 解除** | 封印時のバイト列へ**完全復元**。テキストは画面に戻し、ファイルは清浄な現物を書き出す |

**ウイルスの種類・手口を問わないのは、ウイルスの正体を調べるのではなく「清浄だったときの姿」を基準に差分を見る方式だから**です。既知・未知・亜種・多態性を区別せず、封印後に加えられた改変はすべて検出され、解除で残らず取り除かれます。

> ### ⚠ 原理的な限界について(正直な注記)
>
> 任意のプログラムがウイルスか否かを判定する**万能ソフトウェアは存在しない**ことが数学的に証明されています(F. Cohen, 1987 — ウイルス判定の決定不能性)。
>
> したがって本ソフトが保証するのは **「封印済みのものに対する、あらゆる改変の検出と、封印時点への解除・復元」** であって、未封印のファイルを調べてウイルスかどうかを言い当てることではありません。守りたいものを**先に封印しておく**ことが前提の設計です。

## 🔑 BB84 量子鍵配送(Bada プログラム)

1. **量子乱数** — Alice のビットも基底も `H rng` → `measure rng -> v`、すなわち H|0⟩ の測定で得ます。
2. **符号化と送出** — ビットが 1 なら `X ph`、基底が X(×) なら `H ph` を掛けて光子を送出。
3. **盗聴 (Eve)** — チェックを入れると intercept-resend が入ります。Eve が `measure ph` した瞬間に光子は収縮し、**複製不可能定理**により痕跡が残ります。
4. **ふるいと QBER** — 基底一致位置だけを残し、前半を照合して量子ビット誤り率を推定。**QBER > 10% で盗聴と判定し、鍵を破棄**します。

盗聴時の QBER は理論値どおり **25% 付近**に集中します(テストで 12 回の平均が 0.25 前後であること、および毎回検出されることを検証しています)。

| 光子数 | 得られる鍵 | 所要 |
|:---|:---|:---|
| 256 | 約 8 バイト | 一瞬(実験用) |
| **4096**(既定) | 約 128 バイト | 約 0.1 秒 |
| 16384 | 約 500 バイト | 約 0.3 秒 |
| 65536 | 約 2 KB | 約 1 秒 |

鍵は**メモリ内のみ**に保持し、保存しません。本文が鍵より長いと鍵が巡回してワンタイムパッドの前提が崩れるため、その場合はアプリが明示的に警告します(完全性の検査と復元は引き続き有効です)。

## ⚛ Bada 言語(量子暗号方言)

| 分類 | 命令 |
|:---|:---|
| 量子 | `qubit a b` / `H q` / `X q` / `Z q` / `CNOT c t` / `measure q -> v` / `reset [q]` / `state` |
| 古典 | `let x = 式` / `let a[i] = 式` / `for i = 0 to n - 1 … end` / `while 式 … end` / `if 式 … else … end` / `print` |
| 演算子 | `+ - * / % == != < > <= >= and or not` |
| 関数 | `xor(a,b)` `mul32(a,b)` `floor(x)` `abs(x)` `min(a,b)` `max(a,b)` `len(配列)` |

測定は**ボルン則**に従って確率的に収縮し、測定後の状態は再規格化されます(一度測った量子ビットを測り直すと同じ値が出ます)。`Float64Array` の実振幅で 10 量子ビットまで。

```bada
# ベル状態 — もつれの相関
qubit q0 q1
H q0
CNOT q0 q1
state                 # (|00⟩+|11⟩)/√2
measure q0 -> a
measure q1 -> b
print "測定:", a, b   # 必ず一致する
```

## 🚀 使い方

1. [`index.html`](index.html) を「Download raw file」で保存 → ダブルクリック(インストール不要)
2. または [Releases](https://github.com/masaaki-avnturle/Bada/releases) から:

| プラットフォーム | ファイル |
|:---|:---|
| **Android** (APK) | `bada-qcrypt-debug.apk` |
| **Windows 10 / 11** | `BadaQCrypt-*-x64.exe`(NSIS インストーラ / ポータブル) |
| **Ubuntu** | `BadaQCrypt-*-x86_64.AppImage` / `BadaQCrypt-*-amd64.deb` |

### ⬇ GitHub Actions からダウンロードする

ビルドは [`qcrypt-app-build.yml`](../.github/workflows/qcrypt-app-build.yml) が実行します。**このブランチへ push するたびに自動でビルドが走り、3 種類すべてが Actions のアーティファクトとして残ります。**

1. リポジトリの **Actions** タブを開く
2. 左の一覧から **Bada QCrypt app build (Android APK + Windows EXE + Ubuntu)** を選ぶ
3. 最新の実行(緑のチェック)を開く
4. ページ下部の **Artifacts** から必要なものを選んでダウンロード

| アーティファクト名 | 中身 |
|:---|:---|
| `qcrypt-android` | `bada-qcrypt-debug.apk` |
| `qcrypt-windows` | `BadaQCrypt-1.0.0-x64.exe`(NSIS インストーラ)/ `BadaQCrypt-1.0.0-portable.exe` |
| `qcrypt-linux` | `BadaQCrypt-1.0.0-x86_64.AppImage` / `BadaQCrypt-1.0.0-amd64.deb` |

アーティファクトは **zip で固めて配布される GitHub の仕様**なので、ダウンロード後に展開してから実行してください。保存期間は既定で 90 日です。恒久的に配布したい場合は `qcrypt-v1.0.0` のようなタグを push すると、同じ成果物が Release へ添付されます。

**各プラットフォームでの実行**

- **Android**: APK は開発用の未署名(debug)ビルドです。端末の「提供元不明のアプリ / このソースを許可」を有効にしてインストールしてください。
- **Windows 10 / 11**: 署名していないため SmartScreen が出ます。「詳細情報」→「実行」で進めてください。インストール不要で使うならポータブル版が手軽です。
- **Ubuntu**: AppImage は `chmod +x BadaQCrypt-*.AppImage` の後に実行。deb は `sudo apt install ./BadaQCrypt-*.deb` で入ります。

**手順**:「🔑 鍵配送」で鍵を作る → 「✉ 暗号化」「🗄 量子金庫」「🧪 量子検疫室」で使う。鍵は保存されないので、**同じ鍵が要る操作(解除・復号)は同じセッションで行うか、鍵の 16 進を控えておいてください**。

## 🔒 セキュリティ上の位置づけ

教育・研究用の実装です。実運用の秘匿には、検疫タグの代わりに **HMAC-SHA256** 等の暗号学的 MAC を、鍵より長い本文には **AES-GCM** 等を使ってください。本ソフトの価値は、量子鍵配送と盗聴検出、そして「封印 → 検出 → 復元」という防御の考え方を、**Bada のプログラムとして読める形で**動かせることにあります。
