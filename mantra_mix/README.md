# 🕯 Mantra a tre — 声とピアノだけのミックス

**「Requiem BADA — CLVII · Mantra a tre nel 06:39」(ピアノ、動画 `tablet157.mp4` の音声) に、声の録音 (`20261106_185402.mp3`) を重ねて、楽器を一切付け加えずにミックスだけで 1 曲にしたもの。**

| ファイル | 内容 |
|:--|:--|
| [`mantra_mix.mp3`](mantra_mix.mp3) | ミックス (320 kbps / 11:49、−16 LUFS / −1 dBTP) |
| [`mantra_mix.mp4`](mantra_mix.mp4) | 元のピアノロール映像 (再エンコードなし) + ミックス音声 |
| [`make_mantra_mix.py`](make_mantra_mix.py) | 生成スクリプト (同じ入力からは常に同じ結果) |

## 足したもの / 足していないもの

- **足していない**: 新しい楽器、合成音、ドラム、ドローン、別の声。ピアノは切らず・動かさず・音程も変えていない。声も音程は変えていない。
- **足したのは処理だけ**: ノイズ除去、EQ、コンプレッサ、パン、リバーブ、ディレイ、ダッキング、マスタリング (ラウドネス正規化)。

## 構成 — 曲の 4 つの段落に合わせて声の距離を変える (♩=60、1 小節 = 4 秒)

声の録音は、息継ぎで区切った **32 のフレーズ**に分け、**録音の順番を保ったまま** 小節の頭に置き直した。

| 時刻 | 段落 (動画の字幕) | 声の扱い |
|:--|:--|:--|
| 0:00 | **I. 脈とマントラ** | 最初の 8 小節はピアノだけ。0:32 から **4 小節ごとに 1 フレーズ**。残響多め・高域を丸めて「遠く」に (ピアノより −4 dB) |
| 2:48 | **II. マントラが近づく** | **3 小節ごと**。残響を減らし高域を開いて近づく (ピアノとほぼ同じ大きさ) |
| 5:20 | **III. 頂点** | **a tre (3 声)** — 同じ声を **2 拍後 (左)・4 拍後 (右)** に追いかけさせるカノン。新しい声ではなく同じ録音のディレイ・コピー。声がいちばん前に出る (+1.5 dB) |
| 9:28 | **IV. 消える** | 最後のフレーズ (9:36) が **1 小節ごとのエコー**として左右に揺れながら残響に溶け、ピアノだけで終わる |

## 処理の内容 (`make_mantra_mix.py`)

1. **声のクリーンアップ** — 静かな部分から雑音スペクトルを推定して差し引く (スペクトル減算)、85 Hz ハイパス、260 Hz −2.5 dB (こもり)、3.2 kHz +3 dB (明瞭度)、9 kHz シェルフ −2 dB、コンプレッサ 3:1。
2. **配置** — 発話の頭を小節頭に合わせる。声の大きさは各段落のピアノの RMS を測って相対的に決める。
3. **空間** — 合成インパルス応答 (RT60 3.4 秒) の畳み込みリバーブを声に。ピアノにも同じ系統の残響を −14 dB でごく薄くかけ、二つの録音を同じ「部屋」に入れる。
4. **ダッキング** — 声が鳴っている間だけピアノを最大 −3.5 dB 下げる (アタック 30 ms / リリース 0.9 秒)。
5. **マスター** — 30 Hz ハイパス、2 パス `loudnorm` で −16 LUFS / −1 dBTP。末尾は残響が消えるまで 6 秒延長 (MP4 は映像の長さで終わる)。

## 使い方

```
pip install numpy scipy soundfile    # ffmpeg が PATH に必要
python3 mantra_mix/make_mantra_mix.py tablet157.mp4 20261106_185402.mp3 -o mantra_mix/mantra_mix
```

`--no-video` で WAV / MP3 のみ。素材の録音そのものはリポジトリに含めていない。
