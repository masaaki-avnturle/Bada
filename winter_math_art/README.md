# ❄ Bada 冬景 (Fuyukei) — 冬景色 × 数学 の 楽曲映像化アプリ

**楽曲を読み込むと、冬景色と数学を融合させた抽象画として映像化し、動画 (MP4 / WebM) に書き出すアプリケーション。** 参照動画 (`Requiem BADA — XCI · Canzone 08:53` のピアノロール映像) の構成 ── タイトル・小節番号・再生線・音名グリッド・コード名 ── を踏襲しつつ、背景の冬景色の一つひとつを **β–ζ 論文「ベータ関数とゼータ関数の構造的対応」の方程式群** と、これまでのレポートの **大域的部分積分多様体のエントロピー不変量 Ξ** で描いています。依存ゼロ・単一 HTML・完全オフライン動作。

## 🎼 方程式 → 冬景色 の対応

| 論文の結果 | 式 | 映像での姿 | 音楽との結び付き |
|:--|:--|:--|:--|
| **定理1** ベータ型関数等式 | ζ(s) = 2ˢπˢ⁻¹ sin(πs/2) · β(s,1−s)/Γ(s) · ζ(1−s) | 画面上辺の**霜** — s ∈ [−14.6, −0.35] の \|ζ(s)\|^0.3 を関数等式で解析接続して描く | 低音で霜が厚くなる |
| **系1** 自明な零点 | ζ(−2n) = 0 | 霜が途切れて**氷柱**になる位置 (−2, −4, …, −14 を表示) | — |
| **系2** 臨界線 | ξ(s) = ξ(1−s), 対称軸 Re s = ½ | 地平線 = 臨界線。**凍った湖**が空と山を s ↔ 1−s で鏡映する | 低音で氷面が揺れる |
| 臨界線上の ζ | Z(t) = e^{iθ(t)} ζ(½+it) (Riemann–Siegel) | **雪山**の稜線 = log(1+\|Z(t)\|)。非自明な零点 ρ で谷となり**灯り**が点る | 3 層が時間 t に沿って流れる |
| **定理3** エントロピー座標 | x(s) = e^{W(ζ(s))} = ζ(s)/W(ζ(s)) | **降雪量** ∝ x(s) | 平滑化した音量 E → s = 1.02 + 2.5(1−E)^1.5。大きい音ほど s → 1⁺、ζ(s) と x(s) が増え、雪が激しくなる |
| **定理4** 対角線上の解 | p(s) = arcsin(π/ζ(s))/π,  1 < s ≤ s* = 1.39425… | **オーロラ**の明るさ = 1 − 2p(s)。s > s* (ζ(s) < π) では消える | 音が大きい区間だけオーロラが現れる |
| **定理6** 共通座標 | β(p(s),1−p(s)) = ζ(s) = x(s) log x(s) | オーロラのカーテンの輪郭 = s ∈ (1, s*] に沿った log ζ(s) | — |
| **定理5** 修正正規化 | x(p,q) = e^{W(β(p,q))},  β(p,q)/(x log x) = 1 | 発音ごとに生まれる**雪の結晶**。音名 → 素数対 (p,q) (根音と完全5度: C→(2,19), B→(37,17) …)。大きさ ∝ √((x(p,q)−1)/(x(2,2)−1))、枝数 ← p、枝角 ← q | ピアノロールの音の高さに対応する横位置から降る |
| 式(3) 円関数 | β(s,1−s) = π/sin(πs) | 湖面の**氷のひび** (等高線) と、単位円 e^{iθ} としての**月** | — |
| **Ξ** (既提出レポート) | Ξ = β(H+1, M+1),  M = Σ p_i/(x_i log x_i)² | 空の**色相** (調: 短調 → 藍、長調 → 菫)。x_Ξ = e^{W(Ξ)} は定理5 で可解 | クロマ (12 音の分布) のシャノン情報量 H |

左下の**方程式オーバーレイ**は、その瞬間の s, ζ(s), x(s), p(s), 選ばれた素数対と β(p,q), x(p,q), Ξ, H, M, x_Ξ を毎フレーム表示します (チェックで消せます)。

## ✨ できること

- **楽曲の読み込み** — MP3 / WAV / M4A / AAC / OGG / FLAC、および音声付き動画 (MP4 / WebM / MOV) をドロップ、または「📂 曲を開く」
- **自動解析** (すべて自前実装・外部ライブラリなし)
  - FFT (基数2) → スペクトルピーク → 倍音抑制 → **音符** (ピアノロール)
  - クロマ → **コード** (maj / m / 7 / m7 / maj7 / sus4 / sus2 / dim、ヒステリシス付き)
  - Krumhansl–Kessler 調性プロファイル → **調** (日本語表記: ロ短調 など)
  - スペクトルフラックスの自己相関 → **テンポ** と**小節**
- **3 つの表示モード** — 冬景色 + ピアノロール (既定) / 冬景色のみ (抽象画) / ピアノロールのみ (参照動画風)
- **解像度・fps** — 1280×720 / 1920×1080 / 1080×1080 (正方形) / 1080×1920 (縦型)、30 / 60 fps
- **再生・全画面** — 再生しながら眺める (Space で再生/一時停止)
- **動画の書き出し** — `canvas.captureStream` + Web Audio を `MediaRecorder` で録画 (対応環境では **MP4 (H.264 + AAC)**、それ以外は **WebM**)。リアルタイム録画なので曲の長さと同じ時間がかかります
- **保存** — Android は SAF の保存ダイアログ、Windows / Ubuntu / Chrome / Edge はネイティブ保存ダイアログ、他はダウンロード
- **❄ デモ曲** — ロ短調 Bm–G–D–A の内蔵曲で、曲ファイルがなくても動作を確認できます

## 🧮 数学核 (index.html 内の純ロジック)

| 関数 | 内容 |
|:--|:--|
| `gammaR` / `lgammaR` / `betaR` | Γ (Lanczos + 相反公式)、log Γ、β(p,q) = Γ(p)Γ(q)/Γ(p+q) |
| `betaDiag(s)` | 式(3): β(s,1−s) = π/sin(πs) |
| `etaR` / `zetaR` | ディリクレ η (Borwein 法) → ζ(s) (s ≥ ½)。s < ½ は `zetaFE` |
| `zetaFE(s)` | **定理1** の関数等式 (β 明示形) による解析接続。s = −2n で**系1**により厳密に 0 |
| `theorem1RHS(s)` | 定理1 右辺 2ˢπˢ⁻¹sin(πs/2)·β(s,1−s)/Γ(s)·ζ(1−s) (検証用) |
| `hardyZ(t)` | **系2** の臨界線上: Riemann–Siegel 公式による Z(t) |
| `lambertW(x)` | Lambert W 主枝 (Halley 法) |
| `entropyX(c)` | **定理3 / 定理5**: x log x = c の唯一解 x = e^{W(c)} |
| `pOfS(s)` / `S_STAR` | **定理4**: p(s) = arcsin(π/ζ(s))/π、閾値 s* = 1.394253219… |
| `xOfPQ(p,q)` | **定理5**: x(p,q) = e^{W(β(p,q))} |
| `commonCoordinate(s)` | **定理6 / 7.4**: 連鎖 ζ(s) = β(p(s),1−p(s)) = x(s) log x(s) |
| `manifoldInvariant(w)` | **Ξ** = β(H+1, M+1) と x_Ξ = e^{W(Ξ)} |

## 🚀 使い方

1. `index.html` を開く (または APK / EXE / AppImage をインストール)
2. 曲をドロップ → 解析が終わるまで待つ (数秒)
3. **▶ 再生** で眺める、または **🎬 動画を書き出し** → 曲が終わると **💾 動画を保存**

## 📝 正直な範囲

論文と同じく、本アプリは**リーマン予想を証明していません**。雪山の谷の灯りは Riemann–Siegel 公式で見つかる Z(t) の符号変化 (= 臨界線上の零点) であり、「全ての非自明零点が臨界線上にある」ことを主張するものではありません。逐点恒等式 ζ(s) = β(p,q)/log x は論文第5節のとおり偽であり、アプリでは論文第6–8節の**定義方程式の読み方** (x(s), p(s), x(p,q) を解として選ぶ) のみを用いています。
