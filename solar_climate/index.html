仮説の検証: 「太陽フレアは 2 週間後の地上気温を動かすか」

直近 30 日の フレア指数 (C + 10·M + 100·X) と、選んだ地域の 日平均気温の偏差 (線形トレンド除去後) の相関を、 ラグ 0〜14 日 (フレアが先行) で計算します。NOAA の日別ファイルは直近 30 日分なので、ラグ 14 日の相関は約 16 組から計算されます。有意性は ブロック置換検定 (5 日ブロック, 2,000 回, 全ラグの最大 |r| で多重比較を補正) で判定します。

このアプリが実際に行っていること

1. 予報のスコトーマ (盲点) = 約 2 週間

大気はカオス系で、初期値の小さな誤差が約 2 週間で予報全体に広がります (Lorenz の予測可能性限界)。 「2 週間で天気が変わる」のは太陽フレアのせいではなく、この決定論的予報の地平線です。 本アプリはこの地平線より先を スコトーマ と呼び、そこでは予報を 30 年以上の再解析データから作る 気候値の確率予報 に切り替えます。 予報と気候値は、リードタイム L 日に対して重み w = max(0, 1 − L/16) で混ぜます (目安の重み付けであり、検証済みの予報スキルではありません)。 これが「いつの日でも」予測を出せる仕組みで、日付が遠いほど答えは確率になります。

2. 太陽フレアが地上の天気に与える影響

フレアの X 線・紫外線は高度 60 km 以上の電離圏で吸収され、短波通信の途絶やオーロラの原因になります。 一方、地表に届くエネルギーの変化はごくわずかです。11 年の太陽周期でも全太陽放射照度の変化は約 0.1% (放射強制力で約 0.2 W/m²) で、 2 週間で地域の天気を大きく動かすという観測的証拠はありません。これはアプリ内の 検証ラボ で、いつでも実データで確かめられます。

3. Γ 関数の大域的部分積分多様体 × Jones 多項式の熱感知

論文 exo-gamma.bada の実装を移植しています: Γ は Lanczos 近似で、部分積分の関数等式 Γ(z+1) = zΓ(z) を起動時に自己検証します。 熱感知は三葉結び目の Jones 多項式 V(t) = −t⁻⁴ + t⁻³ + t⁻¹ を t = eiθ で評価するもので、 元論文では惑星の平衡温度 100–1500 K を θ ∈ [0, π] に写します。本アプリでは地表気温 −40〜50 °C を θ ∈ [0, π] に写し、 |V|/3 を「熱感知指数」(0〜1) として各日に表示します。これは気温を可視化するための変換で、予測能力を足すものではありません。

4. データの出典

  • 太陽: NOAA Space Weather Prediction Center (GOES X 線, 惑星 Kp, 日別太陽指数, 27 日見通し)
  • 予報: Open-Meteo Forecast API / Ensemble API (ECMWF IFS 0.25° アンサンブル)
  • 気候値: Open-Meteo Historical API (ECMWF ERA5 再解析, 1991 年〜前年)
