# ☀️ Bada SolarCast — 太陽フレア × 気象 × 気候予測

**NOAA の太陽フレア実測、世界各地の予報、30 年以上の気候値を 1 画面にまとめ、どの日付でも確率で天気を予測するアプリ。**
単一 HTML・依存ゼロ。Android APK / Windows 10・11 EXE / Ubuntu AppImage・deb を GitHub Actions がビルドします。

## できること

| タブ | 内容 |
|:---|:---|
| ☀️ **太陽活動** | GOES X 線フラックス (フレアクラス A/B/C/M/X, 7 日グラフ)、惑星 Kp 指数 (G1〜G5)、F10.7・黒点数・日別フレア数 (30 日)、NOAA 27 日見通し |
| 🔎 **国の地域の検索** | 国 (39 か国 + 全世界) で絞り込み、市・町・県・州の名前で検索 (例: 北海道, Yorkshire, Texas)。候補を最大 10 件、都道府県/州・国・人口・標高つきで表示し、選ぶとその地域の予報へ。最近の検索は端末内に保存。「この国の地域を一覧」で国内の代表地域の今日・明日・明後日を 1 表で比較 |
| 🌍 **地域の予報** | 17 か国の代表都市 + 都市名検索。16 日予報に **Jones 熱感知指数** を付けて表示。**任意の日付**を選ぶと、予報 (ECMWF アンサンブル) と ERA5 気候値 (1991 年〜) を混ぜた降水・降雪・気温・霜の確率を出します |
| 🎄 **英国クリスマス** | ロンドン・エディンバラ・カーディフ・ベルファストなど 10 都市の 12/25。今年〜10 年先を選べます。当日の 15 日前からはアンサンブル予報が混ざります。過去 35 年のクリスマスの実績表つき |
| 🔬 **検証ラボ** | 「太陽フレアは 2 週間後の地上気温を動かすか」を実データで検証。フレア指数 (C+10M+100X) または F10.7 と、日平均気温の偏差のラグ相関 (0〜14 日) を、**ブロック置換検定** (多重比較を補正) で判定 |
| 📖 **仕組み** | 予報のスコトーマ、太陽と気象の関係、Γ × Jones の実装、データ出典 |

## 論文との対応と、正直な注記

| 論文の要素 | このアプリでの扱い |
|:---|:---|
| Γ 関数における大域的部分積分多様体 (`exo-gamma.bada`) | Lanczos 近似の `gammaFn`。部分積分の関数等式 Γ(z+1)=zΓ(z) を起動時に自己検証して「仕組み」タブに表示 |
| Jones 多項式の熱感知 | 三葉結び目 V(t)=−t⁻⁴+t⁻³+t⁻¹ を t=e^{iθ} で評価。元論文は平衡温度 100–1500 K を θ∈[0,π] に写すが、本アプリは地表気温 −40〜50 °C を写し、\|V\|/3 を各日の「熱感知指数」として表示。**気温の変換なので、予測能力は足しません** |
| 太陽フレアが 2 週間で気候を変える | 16 本の論文のどれにも、フレアと気象を結ぶ式はありません。フレアの X 線・紫外線は高度 60 km 以上の電離圏で吸収され、地上の天気を 2 週間で大きく変えるという観測的証拠もありません。そこで**予報には混ぜず**、検証ラボで仮説をいつでも実データで確かめられるようにしました |
| スコトーマ (盲点) | 大気のカオス性による**決定論的予報の地平線 (約 2 週間)** として実装。16 日より先は気候値の確率予報に切り替えます。予報の重みは w = max(0, 1 − L/16) (L = リード日数) で、目安の重み付けです |
| 永遠の気候予測 | 地平線より先のどの日付でも、同じ月日 ±3 日 × 30 年以上の再解析から確率を出します。**当日の天気を一点で当てるのではなく、確率で答えます** |

イギリスのクリスマスについて: 数か月前に 12/25 の天気を一点で当てる方法は、どの気象機関にもありません。このアプリは、12 月 10 日頃までは気候値の確率 (例: ロンドンで雨 ≥1 mm になる割合)、それ以降はアンサンブル予報を混ぜた確率を出し、当日に近づくほど答えが鋭くなります。

## 使い方 (ブラウザ版)

[`index.html`](index.html) を開き **「Download raw file」(⬇)** で保存 → ダブルクリックで起動。データの取得にはインターネット接続が必要です。

## ネイティブアプリ (APK / Windows / Ubuntu)

| プラットフォーム | ファイル |
|:---|:---|
| **Android** (APK) | `bada-solarcast-debug.apk` |
| **Windows 10 / 11** | `BadaSolarCast-*-x64.exe` (NSIS インストーラ) / `BadaSolarCast-*-portable.exe` |
| **Ubuntu / Linux** | `BadaSolarCast-*-x86_64.AppImage` / `BadaSolarCast-*-amd64.deb` |

ビルドは [`solarcast-app-build.yml`](../.github/workflows/solarcast-app-build.yml) が実行します:

- Actions の **Bada SolarCast app build** → 実行結果の **Artifacts** (`solarcast-android` / `solarcast-windows` / `solarcast-linux`) からダウンロード
- 手動実行 (**Run workflow**) も可能。`release_tag` を指定すると Release にも添付
- `solarcast-v*` タグを push → 3 プラットフォームをビルドして **GitHub Release に添付**

## テスト

```
node solar_climate/tools/engine-test.js
```

Γ の関数等式 / Jones 多項式の既知値 (\|V(1)\|=1, \|V(−1)\|=3) / フレアクラス / NOAA 形式のパーサ (X 線, Kp 新旧形式, 日別指数, 27 日見通し) /
Pearson・ラグ相関・置換検定 (埋め込んだ信号の検出と、独立系列・AR(1) 系列での偽陽性率 ≈5%) / スコトーマの境界と確率の混合 /
気候値とアンサンブル集計を検証します。

## データの出典

- NOAA Space Weather Prediction Center — services.swpc.noaa.gov
- Open-Meteo — Forecast / Ensemble (ECMWF IFS 0.25°) / Historical (ECMWF ERA5) / Geocoding API

気象警報や防災の判断には、各国の気象機関の公式情報を使ってください。
