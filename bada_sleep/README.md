# BadaSleep — 量子波動フィードバック 入眠ガイド

入眠（寝付き）を助ける Android アプリ。リポジトリ内の量子計算の考え方に基づき、
**量子状態ベクトル・シミュレータ**（`QuantumSim`）の **波動関数 |ψ|²** から
なめらかな呼吸ペースを生成し、ゆっくり遅くしていくことで眠りへ誘導します。

> ## ⚠️ これはリラックス補助アプリで、医療機器ではありません
> - 睡眠障害の診断・治療は行いません。
> - 「量子」は **古典コンピュータ上のシミュレーション**（実機の量子計算機では
>   ありません）。数量子ビットの状態ベクトルにゲートを掛けて時間発展させ、
>   その `|ψ|²` を呼吸ガイドの信号源に使っています。
> - 「脈拍タップ」は **手動入力** で、センサーによる実測ではありません。

## 仕組み

- **量子シミュレータ（本物の計算）**: 3量子ビット（8振幅）の波動関数を保持し、
  H / RX / RZ / CZ ゲートを適用。毎フレーム時間発展させて `P(|1⟩)` などの
  観測量を読み出します（`QuantumSim.kt`）。
- **呼吸オーブ**: 観測量で円が膨らむ/縮む＝吸う/吐くのガイド（`SleepView.kt`）。
  画面下に `|ψ⟩` の主要な振幅も表示（量子状態を可視化）。
- **ペースをゆっくりに**: 開始〜終了にかけて 約6→4 呼吸/分 へ減速し、入眠を促す
  ペースト・ブリージング。
- **手動バイオフィードバック**: 「脈拍タップ」で自分の脈に合わせて4回以上タップ
  すると BPM を推定し、開始ペースを個人化します（任意）。
- **セッション**: 分数を指定（既定12分）。終了時にそっとフェードして停止
  （「おやすみなさい」）。セッション中は画面を点灯維持。

- 表示名: **BadaSleep 量子波動** / パッケージ: `com.yamaguchi.sleep`

## APK のダウンロード（このリポジトリから）

- **いちばん簡単（ログイン不要・直リンク）** — Releases の `sleep-latest`：
  https://github.com/masaaki-avnturle/Bada/releases/download/sleep-latest/BadaSleep-debug.apk
- **Actions のアーティファクト**（要ログイン・zip・90日）: Actions →
  「Build BadaSleep APK」の最新実行 → Artifacts → `BadaSleep-apk`。

**インストール**: 「不明なアプリのインストール」を許可してから APK を開きます。

## ローカルビルド

```sh
cd bada_sleep
./gradlew assembleDebug   # -> app/build/outputs/apk/debug/app-debug.apk
```
AGP 8.5.2 / Gradle 8.7 / Kotlin 1.9.24 / compileSdk 34 / minSdk 26。
